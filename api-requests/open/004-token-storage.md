# 004. 토큰 저장 위치

- **종류**: 합의 · **담당**: 백엔드 + 프론트 공동
- **작성일**: 2026-08-29 · **필요 시점**: W1
- **막힘 여부**: 예 — 로그인·자녀 접속 화면을 만들 수 없다

## 왜 필요한가

자녀 토큰은 **30일 유효**이고 접속 코드 교환으로 발급된다. 탈취 시 영향이 크다. 저장 위치가 프론트 인증 흐름 전체를 결정한다.

## 결정할 것

**제안**: 자녀·학부모 모두 HttpOnly 쿠키

- PWA·iOS Safari에서 HttpOnly 쿠키 제약 확인 필요 (홈 화면 추가 시 쿠키 유지, ITP)
- 두 토큰은 역할이 다르고 상호 대체 불가 — 쿠키 이름·경로를 분리할지
- 크로스 오리진 여부(web:3000 ↔ api:8000)에 따라 `SameSite`·CORS 설정이 갈린다

**참조**: `docs/Stage0_API명세.md` 0절 인증
