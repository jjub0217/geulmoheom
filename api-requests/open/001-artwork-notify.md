## 왜 필요한가

아이가 묘사를 쓰면 삽화가 생성된다. 그 사이 아이가 보는 화면을 무엇으로 채울지가 통지 방식에 따라 갈린다. `docs/Stage0_API명세.md` 5절 `GET /artworks/{artwork_id}`.

## 결정할 것

**제안**: 폴링 우선, SSE는 SHOULD

- W1 이미지 모델 벤치의 **실제 생성 지연**. 3초 안쪽이면 폴링으로 충분, 10초를 넘으면 대기 화면 설계가 달라진다
- 아이가 기다리는 동안 보는 것 — 가이드 캐릭터 대사로 메울 수 있는 길이인가
- 폴링 간격·타임아웃·실패 시 재시도 횟수를 여기서 같이 정한다
