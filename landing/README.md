# landing — Fake Door 랜딩 (PRD F-2)

PM 담당, W1 오픈. 본 백엔드·DB와 분리된 정적 사이트.

- 서비스 소개 + 나침반 퀘스트 화면 목업 3장 + 성장 대시보드 목업
- 사전 가입 폼(이메일) + "주간 리포트 받기" 체크 + 요금 안내 (A안 9,900 / B안 14,900)
- 이벤트 4종: `visit`, `signup`, `report_optin`, `pricing_click` — 분석 툴로 직접 수집
- 합격선: `docs/검증가설_성공지표.md` 2.3

## 정직성 규칙 (필수)

Fake Door는 "곧 나온다"고 알리는 것이지 있는 척 속이는 것이 아니다. 학부모 신뢰가 제품의 전제이므로 첫 접점에서 오해를 남기지 않는다.

- 페이지 상단에 **"출시 준비 중"** 배지 상시 노출
- 사전 가입 버튼을 누르면 즉시: *"아직 준비 중이에요. 출시되면 가장 먼저 알려드릴게요."* — 가입 완료 화면과 확인 메일 양쪽에
- 가격 안내는 **"예정 요금"**으로 표기. 결제 유도·카드 입력 없음
- 화면 목업에는 "예시 화면" 워터마크
- 수집 항목은 이메일 + 리포트 수신 여부뿐. 자녀 정보는 묻지 않는다
