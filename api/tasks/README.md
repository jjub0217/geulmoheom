# api/tasks — 백엔드 진척 체크리스트

주차별 파일 하나. 백엔드가 **직접 만들고 직접 체크한다.** PM 승인 없이 쓴다.

```
cd api && claude
> /my-week W5      # <n> 은 docs/주차계획/ 의 최신 주차. 이 숫자를 그대로 쓰지 않는다
```

계획에서 자기 몫만 뽑아 체크리스트를 만든다. 이미 있으면 덮어쓰지 않고 차이만 알려준다.

## 여기는 계획이 아니다

**계획은 `docs/주차계획/`에 있다.** 이 폴더는 그 계획의 **진척만** 표시한다.

- **범위를 여기서 조용히 늘리거나 줄이지 않는다 — 새로 생기면 PM 에게 말한다.** **막지 않는다**:
  계약이 바뀌거나 실기기에서 결함이 나오면 **그것을 만난 세션의 파일에 먼저 앉는 것이 정상**이고,
  **`신설` + 날짜 + 근거 커밋을 적고 PM 에게 말한다**. 계획이 원본이라는 것은
  **「거기서 태어나지 않는다」가 아니라 「거기로 옮겨 간다」**는 뜻이다 (`api/CLAUDE.md` 와 같은 문장)
- 항목 번호는 주차 계획과 맞춘다. 갈라지면 주차 계획이 맞다
- 세부 순서·메모는 자유롭게 적는다. 그건 여기 것이다

## 표식 — `[x]` 와 `↗` 를 가른다

**`[x]` 는 내가 한 것에만 찍는다.** 상대가 한 일은 **상대 `tasks/` 가 SSOT** 다 —
여기서 같이 찍으면 **PM 의 `/progress-week` 이 한 일을 두 번 센다.**

**그런데 「안 찍는다」와 「없다」는 다르다.** 내 항목에 달려 있던 칸이 상대에게 갔으면
**그 자리에 자국이 남아야** 다음 세션이 「이건 어떻게 됐나」를 안 다시 판다.

| 표식 | 뜻 | 분모 |
|---|---|---|
| `[x]` | **내가 했다** | 든다 |
| `[ ]` | **내가 할 것인데 아직이다** | 든다 |
| **`↗`** | **내 몫이 아니라 저쪽으로 갔다** — 어느 항목으로 갔는지와 근거 커밋을 같이 적는다 | **저쪽에서 든다** |

**⛔ `⏭` 를 쓰지 않는다.** `docs/주차계획/` 에서 `⏭` 는 **「이번 주차에 안 한다」**(분모에서
뺀다)로 이미 쓰이고 있다. **여기 것은 대부분 「남이 했고 닫혔다」라 뜻이 반대**이고,
섞으면 **닫힌 일이 분모에서 조용히 빠진다.**

**2026-09-16 에 실제로 밟았다** — 백엔드가 `⏭` 로 넷을 적었고 **PM 이 읽다가 짚었다.**
그때는 사람이 알아봤지만 **다음 세션은 못 본다.**

## 왜 나눴나

**원래 이유는 두 개발자였다** — 주차 계획 하나를 둘이 같이 체크하면 `main` 직접 push 체제에서 push 거부가 잦다.
**2026-09-06 부터 1인이라 그 마찰은 없어졌다**(`adr/0008` — 한 사람이 모자 셋을 쓴다).

**그래도 나눠 둔다. 이유가 바뀌었다** — 이제는 **소유가 아니라 시야**다. 세션 셋이 같은 워킹 트리를
공유하므로, **자기 패키지 파일만 보면 「내가 무엇을 하는 중인가」가 섞이지 않는다.**
그리고 **PM 이 `/progress-week` 으로 여기서 진척을 긁어 간다** — 그 입력이 갈려 있어야 한다.

PM 작업은 `docs/주차계획/W<n>.md` 안에 그대로 있다 — PM이 그 파일 소유자라 겹치지 않는다.
