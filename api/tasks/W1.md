## 메모

<!-- 작업 중 알게 된 것. 계약·설계 결정은 여기가 아니라
     docs/api/미결.md 또는 api-requests/ 로 간다 -->

- 착수 시점 `api/` 상태: `pyproject.toml`(의존성 비어 있음) · `.python-version` 만 있음.
  1번은 의존성 추가부터 시작했다.
- **LangGraph 는 아직 안 넣었다.** Stage 1(GM 서사 그래프)에서 쓴다 — Stage 0 에 안 쓰는
  무거운 의존성이라 `uv sync` 만 느려진다. Stage 1 착수 때 추가.
- ruff `select` 에 **`G`(flake8-logging-format)** 를 넣었다. `logger.info(f"...{text}")` 를
  G004 로 잡는다 — 아이 원문 로그 유출을 기계로 막는 유일한 장치라 끄지 않는다.
- `[tool.uv] package = false` + pytest `pythonpath = ["."]` — 패키지 설치 없이 `app` 을 import 한다.
- 오류 응답은 `app/errors.py` 한 곳에서 만든다. `공통규약.md` 코드표 9종 + **`INTERNAL_ERROR`(500)**
  — 표에 없어서 추가했다. 없으면 미처리 예외가 FastAPI 기본 형식으로 나가 형식이 갈라진다. **PM 반영 대기**
- 아이 화면 문구 9종도 `app/errors.py`(`CHILD_MESSAGE`)에서 정했다. `DAILY_CAP_REACHED` 만 문서 예시
  그대로고 나머지는 새로 쓴 것 — **C-1 대사 세트(W2)에서 PM이 확정하면 그쪽을 따른다**
- **검증 오류의 `detail.fields` 에서 `input`·`ctx` 를 떨어뜨린다.** pydantic 기본 오류에는 아이가 보낸
  값이 그대로 들어 있어, 그냥 내보내면 마스킹 미들웨어를 지나기 전 원문이 응답으로 샌다.
  `tests/test_errors.py` 가 이걸 고정한다
- `docs_url` 은 `app_env == "dev"` 일 때만. pilot 에서 `/docs` 를 열어두지 않는다
- 초기 마이그레이션은 **Stage 0 테이블 8개만**. `chapters`·`sessions`(Stage 1)는 W6 에.
  안 쓰는 스키마가 먼저 굳는 것을 막는다 — 테스트로 고정했다
- Alembic 접속 URL 은 `alembic.ini` 가 아니라 `migrations/env.py` 가 `.env` 에서 읽는다.
  ini 에 적으면 접속 정보가 커밋된다
- `migrations/versions/` 는 ruff 검사 제외(생성물). 손으로 쓰는 `env.py` 는 계속 검사한다
- `engine(echo=False)` — 켜면 SQL 파라미터로 아이 원문이 로그에 찍힌다. 테스트로 고정
- **PRD 6장과 다르게 만든 것 2가지. PM 반영 대기**
  - `book_pages` 를 `page JSON{...}` 대신 평면 컬럼(`card_attempt_id` `artwork_id` `text` `tier`)으로.
    "카드별 최고 티어 upsert" 를 JSON 안에서 하면 유니크 제약을 걸 수 없다
  - `artworks` 를 `session_id` 대신 `card_attempt_id` 로. Stage 0 에는 세션 테이블이 없다
    (`session_id` 는 Stage 1 에서 추가)
- 마스킹 미들웨어는 **body 를 아예 읽지 않는 쪽**으로 만들었다. 읽고 가리는 것보다 강한 보장이고,
  가릴 필드를 하나 빠뜨리면 그게 곧 유출이라서다. 대신 요청마다 `request_id` 를 붙이고
  `X-Request-ID` 헤더로 돌려준다 — 원문 없이 로그와 요청을 잇는 수단
- `app/masking.py` 의 `mask_body` 는 **나중에 body 를 손에 쥐는 코드**(오류 리포터·디버그 덤프)용 거름망.
  `highlights` 와 `guide.line` 도 가린다 — 아이 문장을 그대로/인용해 담는 필드다
- **uvicorn 기본 액세스 로그를 껐다.** 요청 라인을 통째로 남겨 쿼리스트링 값이 찍힌다 —
  미들웨어를 우회하는 경로였다. 같은 정보는 우리 로그가 남긴다
- 헬스체크는 **`/healthz`(의존성 안 봄) · `/readyz`(Postgres·Redis 실측)** 둘로 나눴다.
  `/api/v1` 밖에 둔다 — 아이 화면 계약이 아니라 운영용이다
- `/readyz` 실패 응답에 예외 메시지를 싣지 않는다. asyncpg·redis 예외 문자열에는
  호스트·계정이 그대로 들어 있다. 남기는 것은 `up`/`down` 뿐
- **요청 로그가 아무 데도 안 나오고 있었다.** uvicorn 은 `uvicorn.*` 로거만 설정한다 —
  `app.*` 에 핸들러를 붙이지 않으면 `request_id` 로 요청을 되짚는 수단이 통째로 사라진다.
  `app/logging_config.py` 추가
- 포매터는 **허용 목록(`SAFE_EXTRA_KEYS`)에 있는 필드만** 찍는다. 실수로 원문을 `extra` 에
  실어도 출력으로 안 샌다. 테스트로 고정
- 목 응답은 `app/api/v1/` 에 `Stage0.md` 절 단위로 나눴다. 고정 값은 `_fixtures.py` 한 곳 —
  실구현이 들어오면 **그 파일만 지우면 된다**. 스키마(`app/schemas/stage0.py`)는 그대로 쓴다
- `outcome` 3분기는 **`X-Mock-Outcome` 헤더**로 강제한다. 상한 소진은 `X-Mock-Error: DAILY_CAP_REACHED`,
  삽화 상태는 `X-Mock-Status`. 셋 다 openapi 에 «목 서버 전용» 이라고 적어 뒀다 — 실서버에는 없다
- 토큰은 **존재 여부만** 본다. 서명 검증은 E-3/E-4 — 미결 11-2(토큰 저장) 전에 만들면 다시 짠다
- `make contracts` 의 프론트 절반은 따로 확인했다. `openapi-typescript 7.13.0` 이
  `/openapi.json` 을 읽어 1565줄 타입을 만들고, `outcome` 합타입도 살아 있다
- 환경 파일은 **`.env` 위에 `.env.{APP_ENV}` 를 덮어쓰는 체인**. `APP_ENV` 만은 파일이 아니라
  프로세스 환경 변수로 준다 — 어느 파일을 읽을지 정하는 값이라 파일 안에 적으면 늦다
- 비밀 값은 전부 `SecretStr`. 설정 객체가 로그·오류 리포트에 통째로 들어가도 값이 안 찍힌다
- **pilot 은 키가 비면 뜨지 않는다.** 조용히 뜨면 아이 문장을 받아 놓고 Evaluator 에서 터진다
- **필수 키 검사를 pydantic 검증기로 넣지 않았다.** `ValidationError` 메시지에 입력 dict 가
  통째로 실려서, 채워진 다른 키 값까지 트레이스백으로 나간다. 테스트가 이걸 잡았다.
  `get_settings()` 에서 **이름만** 담아 던진다
- 비용 알람은 `app/cost.py`. Redis 에 하루 누적, 한도 초과 시 **하루 한 번만** 경고.
  실측 확인: 한도 20 USD 에서 22.0 에 한 번 뜨고 23.0 에는 안 뜸.
  Redis 가 죽어도 예외를 삼킨다 — 비용 기록이 아이의 요청을 막지 않는다
- **아직 호출하는 곳이 없다.** W1 5번(LLM 스모크)·6번(이미지 벤치)이 첫 사용처다
- `.env` 에 `ANTHROPIC_API_KEY` 가 비어 있다. **5번 전에 채워야 한다**
- **2026-08-31 LLM 프로바이더 교체** — Anthropic `claude-opus-5` → Google Gemini(`google-genai`),
  **유료 티어**. 결정·근거·미결은 `docs/adr/0005`. 코드 쪽은 4번 브랜치에 함께 얹었다
  (`pyproject.toml` 의존성, `gemini_api_key`, `.env*.example`)
- **모델명은 코드에 기본값을 두지 않는다.** ADR 결정 2번이 "지금 정하지 않는다"인데
  임시값을 박으면 그게 사실상의 결정이 되어 W2 벤치 전에 굳는다. 테스트로 고정
- `PILOT_REQUIRED` 에 `evaluator_model` 을 넣었다 — 미정인 채로 파일럿이 뜨면
  첫 Evaluator 호출에서 터진다
- **5번 착수 전 선행 조건이 생겼다** (`adr/0005` 미결 표): **Gemini 약관에서 유료 티어의
  데이터 활용 조항을 확인하고 날짜·조항을 ADR에 덧붙이기 전까지 아이 원문을 API 에 보내지 않는다**
- **5번 실측 결과는 `api/benchmarks/W1-llm-smoke.md`.** 요약: `gemini-3.1-flash-lite`
  995ms·회당 $0.000161 로 최유력, `gemini-3.7-flash` 는 평균 11초라 Evaluator 탈락
  (PRD 4.5 의 1.5초 요구를 10배 초과). **확정이 아니라 W2 벤치 후보 압축이다**
- `thinking_budget=0` 을 **모델마다 다르게 받는다.** `gemini-3.5-flash-lite` 는 400 으로
  거부하고 `thinking_config` 를 빼야 돈다. 코드에서 분기해야 한다
- `gemini-2.5-flash-lite` 는 신규 사용자에게 404 — API 가 `3.5-flash-lite` 를 안내한다
- **스모크 숫자를 그대로 믿으면 안 된다.** 입력이 312~349 토큰뿐이고 실제 Evaluator 는
  예시셋 40개가 붙어 수천 토큰이 된다. 그러면 context caching 유무가 지배적이 되고
  지연도 는다 — `gemini-3.5-flash-lite` 는 caching 미지원이라 그때 불리해진다
- `app/cost.py` 의 첫 사용처가 생겼다 (`scripts/smoke_llm.py`). 스모크 3회 누적 $0.0117
