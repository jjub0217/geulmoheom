- 착수 시점 `api/` 상태: `pyproject.toml`(의존성 비어 있음) · `.python-version` 만 있음.

  무거운 의존성이라 `uv sync` 만 느려진다. Stage 1 착수 때 추가.
- ruff `select` 에 **`G`(flake8-logging-format)** 를 넣었다. `logger.info(f"...{text}")` 를
  G004 로 잡는다 — 아이 원문 로그 유출을 기계로 막는 유일한 장치라 끄지 않는다.
- `[tool.uv] package = false` + pytest `pythonpath = ["."]` — 패키지 설치 없이 `app` 을 import 한다.
- 오류 응답은 `app/errors.py` 한 곳에서 만든다. `공통규약.md` 코드표 9종 + **`INTERNAL_ERROR`(500)**
  — 표에 없어서 추가했다. 없으면 미처리 예외가 FastAPI 기본 형식으로 나가 형식이 갈라진다. **PM 반영 대기**

  `tests/test_errors.py` 가 이걸 고정한다

  ini 에 적으면 접속 정보가 커밋된다

- **PRD 6장과 다르게 만든 것 2가지. PM 반영 대기**
  - `book_pages` 를 `page JSON{...}` 대신 평면 컬럼(`card_attempt_id` `artwork_id` `text` `tier`)으로.

    쿠키는 포트를 구분하지 않아 다른 로컬 프로젝트와 충돌한다
  - **`SameSite` 는 배포 도메인 설계에 달렸다.** 포트는 site 구분에 안 들어가므로
    `localhost:3000` ↔ `:8000` 은 same-site 다(Lax 로 충분). 운영에서 api 를 web 과
    같은 등록가능 도메인 아래 두면 `Lax` 를 유지하고 **ITP 3rd-party 제약을 통째로 피한다**
  - 자녀 토큰 폐기는 **`children.token_version` 정수 컬럼**. JWT 는 회수가 안 되는데
    폐기 경로가 셋(코드 재발급·자녀 삭제·분실 신고)이다. 값을 올리면 그 자녀의 모든
    기기가 한 번에 끊긴다. Redis 블랙리스트보다 싸다 — 어차피 매 요청 `children` 을 읽는다.
    **스키마 변경이라 마이그레이션 필요. `/api/v1` 응답은 안 바뀌므로 명세 변경 아님**
