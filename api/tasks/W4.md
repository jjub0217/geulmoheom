- **다음 세션이 밟을 것 하나 — `Cache-Control: private` 을 빠뜨리면 Cloudflare 공유 캐시에
  아이 창작물이 남는다.** 그리고 **그 사고는 화면에 아무 증상이 없다** — 우리가 볼 수 있는
  자리가 없다. ③의 셋(쿠키 인증·남의 것 404·`private`)은 **하나만 흘려도 조용히 샌다.**
- **순서는 ①②③ 그대로다.** ①② 가 서야 ③ 이 돌려줄 것이 생긴다.
- **`SameSite=Lax` 가 `<img>` 서브리소스에 실리는지는 실기기 확인이다** — 배포 뒤,
  파일럿 전. `미결.md` 「검증 대기」(`ca19c2c`). **안 실리면 그림이 통째로 안 뜬다.**
- **R2 자격증명은 아직 없다.** 로컬 폴백으로 돌고, `test_지금은_설정이_비어_있다` 가
  **들어오는 날 깨진다** — 그게 알림 장치다.
- **문구가 통째로 새로 들어오는 주차다.** 테스트에 박힌 문자열이 제품을 붙잡는다
  (W3 에서 `[보안 필터]` 여섯 군데로 실제로 났다). **상수를 import 한다.**
