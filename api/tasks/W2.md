- **선행이 한 줄로 직렬이다.** 예시셋(PM) → 1 → 2 → 3. 병렬로 돌릴 수 있는 것은 **4번뿐**이다 —
  PM 이 예시셋을 쓰는 동안 4번을 먼저 한다
- **1번·4번 완료 (2026-09-07).** 실측은 `benchmarks/W2-evaluator-bench.md` ·
  `benchmarks/W2-character-gen.md`. 남는 것 둘을 2번에서 본다
  - **1.5초 여유가 139ms뿐이다.** 운영 형태 최대 1,361ms. 예시셋이 늘거나 카드 문맥이
    붙으면 다시 잰다
  - **암묵 캐싱이 안 걸렸다** (`cached_content_token_count` 0). 명시적 캐시를 붙이면
    입력 단가가 10분의 1이고 여유도 는다 — **2번에서 붙인다**
- **설정에서 죽은 키 둘을 뺐다** — `IMAGE_API_KEY` · `IMAGE_PROVIDER`. 선언만 되고
  코드 어디서도 안 썼다. `adr/0006` 이후 늘 `gemini_api_key` 와 같은 값이 된다.
  `PILOT_REQUIRED` 에는 대신 `image_model` 을 넣었다
- **W1 에서 넘어온 것이 이번 주 범위에 없다.** 인증 계약 재맞춤(토큰 body 제거 · 로그아웃 2종 ·
  `children.token_version` 마이그레이션)은 프론트가 안 움직여서 미룬 것이고, **PRD 8장에는
  W2 선행으로 적혀 있다.** 일정 재조정은 PM 3번으로 대표에게 올라간다 — 여기서 손대지 않는다
- **2번 완료 (2026-09-07).** 실측은 `benchmarks/W2-attempt-latency.md`. **계약은 안 바뀌었다** —
  `/openapi.json` 이 이전과 같아 프론트의 `make contracts` 결과가 그대로다
  - **루브릭 읽기·프롬프트 조립을 `app/rubric.py` 로 옮겼다.** 벤치 스크립트도 이걸 쓴다 —
    운영과 벤치가 다른 프롬프트를 쓰면 `W2-evaluator-bench.md` 의 97.5% 가 근거를 잃는다
  - **`highlights` 는 `descriptors` 로 만든다.** `signals` 는 「캄캄한」처럼 원형으로 와서
    문장의 「캄캄했지만」과 안 맞아 절반이 버려졌다. 종류(`kind`)만 신호에서 가져오고,
    **문장에 실제로 있는 조각만** 남긴다 (없는 말은 프론트가 덧칠할 자리를 못 찾는다)
  - **로그에는 등급을 남기고 문장 조각은 남기지 않는다.** `eval_result` 는 PRD 5장 그대로
    `grade, signal_count, latency_ms` 에 `eval_fallback` 을 더했다. `signals`·`descriptors` 는
    아이 문장 조각이라 원문과 같아서 `SAFE_EXTRA_KEYS` 에 넣지 않았다 — **목록에 없는 것이 곧 차단이다**
  - **`eval_fallback` 비율이 경보다.** 정상 판정에도 `none` 을 남겨 분모를 만들었다
  - **결과 연출 대사를 코드에 뒀다** (`attempts.py` `_결과대사`). PRD 4.0 「템플릿 치환」이고
    문서에 확정 문안이 없다. **PM 이 문구를 확정하면 그리로 옮긴다**
  - **아직 목인 것 셋** — `today` 카운트·`artwork`·`outcome=scaffold`/`blocked`.
    되묻기는 3번, PII·Moderation 은 `Stage0.md` 9절 3·4번이다. **지금은 G0 도 `basic` 결과로 나간다**
  - **명시적 context caching 은 안 붙였다.** 여유가 200ms 안팎으로 나와 급하지 않다.
    붙이면 입력 단가가 $0.25/M → $0.025/M 다 — **3번에서 카드 문맥을 얹을 때 함께 본다**
  - **로컬 `.env` 의 `EVALUATOR_MODEL` 이 비어 있다.** `.env.example` 만 채워졌다
    (`1e3c8c4`). 채우지 않으면 `unconfigured` 폴백으로 **전부 G1** 이 된다
