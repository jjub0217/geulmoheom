계획: `docs/주차계획/W2.md` 「작업 쪼갬 · 백엔드」 · 소요·상세는 그쪽에 있다
**범위를 여기서 바꾸지 않는다.** 계획이 틀렸으면 PM에게 말한다.

- [ ] **1. Evaluator 모델 확정** (`adr/0005`) — **선행: PM 1번 예시셋 40개**
  - [ ] 예시셋 40개를 **붙인 프롬프트**로 재측정 — W1 스모크(300토큰)는 근거가 못 된다
  - [ ] context caching 미지원 모델은 이 시점에 **탈락** (`gemini-3.5-flash-lite`)
  - [ ] `thinking_budget=0` 모델별 분기
  - [ ] **루브릭 일치율 80% 측정치 기록** — `adr/0005` 합격 조건
  - [ ] 확정 모델명·지연·단가를 `adr/0005` 에 기록 + `PILOT_REQUIRED` 의 `evaluator_model` 채움
  - [ ] 일치율이 80% 미만이면 **대표에게 직접 말했다** — 프로바이더 되돌림은 「대표 몫」(돈)
        (되돌리기 전에 **모델이 아니라 루브릭·예시셋을 먼저 의심한다**)
- [ ] **2. 묘사 평가**(백로그 B-1) — **선행: 1번**
  - [ ] Evaluator 호출 + **구조화 출력** — 등급 · 근거 태그 · 감지된 묘사어 (PRD 4.3절 루브릭)
        맞춤법·문법은 평가하지 않는다 · **등급 문자(G0~G3)는 응답에 넣지 않는다**
  - [ ] 타임아웃 3초 → 재시도 1회 → 실패 시 **G1 폴백** (`Stage0.md` 9절 5번 · 아이를 막지 않는다)
  - [ ] `POST /attempts` 배선 — `_fixtures.py` 고정 응답을 이 경로에서 걷어낸다
        **`X-Mock-Outcome` 헤더는 남긴다** (W3 화면 작업에서 아직 필요)
  - [ ] **응답 1.5초 이내 실측 확인** — 초과 시 어느 모델·어느 프롬프트 크기에서 넘는지 기록
- [ ] **3. 되묻기**(백로그 A-5) — **선행: 2번**
  - [ ] G0 판정 시 PRD 4.4절 템플릿 + 카드 명사 태그로 **질문 1개** 생성
  - [ ] `outcome=scaffold` 반환 · **카드 미소모**
  - [ ] `scaffold_count` 2회 후에도 G0 이면 **G1 취급으로 진행**
  - [ ] **톤 — 부정어 금지.** "부족해"·"다시" 를 쓰지 않는다. 호기심·요청 형식만
- [ ] **4. 캐릭터 표정 4종 재생성** (캐릭터 정본 확정 C-2 중 **생성 몫**)
  - [ ] 정본 `docs/캐릭터/캐릭터색상코드.png` 를 **레퍼런스 이미지로** 넣어 생성
        표정 3종(기본 / 나침반 반응 / 스캐폴딩) + 세션 종료 컷
  - [ ] **종횡비 명시 고정** — W1 벤치의 결함이 그것이었다
  - [ ] 산출물을 PM 에게 넘긴다. **`docs/캐릭터/` 에 직접 넣지 않는다** (PM 소유)
        판정·반영은 **PM(루트) 세션**에서 이어서 한다 — 아동 3명 선호 확인 포함
  - [ ] 학사모 · 파란 스카프 · 고글 · 크로스백이 정본과 맞는지 스스로 먼저 본다

- **선행이 한 줄로 직렬이다.** 예시셋(PM) → 1 → 2 → 3. 병렬로 돌릴 수 있는 것은 **4번뿐**이다 —
  PM 이 예시셋을 쓰는 동안 4번을 먼저 한다
- **W1 에서 넘어온 것이 이번 주 범위에 없다.** 인증 계약 재맞춤(토큰 body 제거 · 로그아웃 2종 ·
  `children.token_version` 마이그레이션)은 프론트가 안 움직여서 미룬 것이고, **PRD 8장에는
  W2 선행으로 적혀 있다.** 일정 재조정은 PM 3번으로 대표에게 올라간다 — 여기서 손대지 않는다
