  틀린 비밀번호를 **같은 401** 로 준다. 둘 다 계약인데 문서에 줄이 없다
- **`app/tokens.py` 를 `app/auth.py` 에서 떼어 놨다.** 로그아웃의 삭제 `Set-Cookie` 는
  서명이 필요 없고 **속성만 같으면 되는데**, 한 모듈에 섞으면 그 사실이 안 보인다.
  auth 는 쿠키 속성만, tokens 는 서명만 안다
- **`from app.db import engine` 을 쓰지 않는다.** 이름으로 들여오면 import 시점의 객체를
  붙잡아, 나중에 갈아끼우는 쪽과 **서로 다른 엔진을 보게 된다.** `app/api/system.py` 를
  모듈 참조로 고쳤다 — 테스트가 엔진을 갈아끼우는데 헬스체크만 옛 엔진을 보고 있었다
- **엔진을 만드는 자리를 `db.엔진만들기()` 하나로 모았다.** 테스트가 `create_async_engine` 을
  직접 부르면서 **`echo=False` 를 비껴갔다** — 그 한 줄이 아이 원문을 SQL 로그에서 막는
  장치인데(PRD 1.1b) 테스트 경로에만 없어졌다. 실제로 오늘 그렇게 됐고 기존 테스트가 잡았다
- **테스트 DB 를 매 실행 지우고 다시 만든다.** 남기면 `alembic_version` 이 최신이라
  마이그레이션이 아무 일도 안 하고 **옛 스키마 위에서 초록불**이 뜬다 — 오늘 실제로 밟았다
  (유니크로 바꾼 인덱스가 테스트 DB 에서만 유니크가 아니었다). 「조용히 절반만 되는」 그 부류다
- **CI 의 api 잡에 Postgres 를 붙였다** (`services.postgres`, 포트 5433 으로 로컬과 맞춤).
  Redis 는 안 붙였다 — 되묻기 카운터는 죽어도 아이가 계속 쓰게 만들어져 있고 테스트가
  그 경로를 직접 갈아끼운다. **첫 CI 실행에서 실제로 초록인지 봐야 한다**
- **의존성 둘이 늘었다** — `pyjwt`(HMAC 을 직접 안 짠다: `alg` 혼동·상수시간 비교가 손으로
  짜면 조용히 틀리는 자리다) · `argon2-cffi`(bcrypt 의 72바이트 조용한 잘림이 없다).
  **둘 다 무료고 돈이 나가지 않는다**
- **되묻기 Redis 키가 토큰 기준에서 자녀 ID 기준으로 바뀌었다.** 토큰 기준이면 아이가 다른
  기기로 들어오는 순간 횟수가 0 이 되어 **같은 카드에서 상한(2회)을 넘겨 되물을 수 있었다**
- **`PATCH /child/guide` 에는 PII 검사를 안 걸었다.** 여기는 **아이가 직접 쓰는 자리**라
  닉네임(학부모가 쓴다)과 달리 정규식만 걸면 아이가 지은 이름이 먼저 걸린다.
  **서버 2차(E-2, 5번)를 그대로 태워야 한다** — 거기서 붙인다
- **`pilot` 에서 검사가 꺼지면 사고다 — 런타임에서 한 번 더 닫았다** (PM 지적).
  `PILOT_REQUIRED` 가 `evaluator_model` 을 요구해 기동이 막히는 것이 앞단인데,
  **그 결합에만 기대지 않는다.** 설정 목록이 바뀌어도 아이가 안 뚫리게 `_검사없음()` 이
  `app_env == "pilot"` 이면 막는 쪽으로 닫고 `error` 로 남긴다. 테스트 둘이 앞뒤를 잡는다
