# app/assets — 제품이 런타임에 읽는 에셋

**`docs/` 의 정본이 아니라 제품이 내보내는 파일**이 여기 들어온다.

| 파일 | 무엇 | 정본 |
|---|---|---|
| `기본삽화.png` | 삽화 생성이 실패했을 때 아이에게 나가는 그림 (B-3 `fallback`) | 사양은 `docs/장면카드_초안.md` 「기본 삽화 1장」 |

**가이드 레퍼런스는 여기 없다.** `app/artwork.py` 가 `docs/캐릭터/캐릭터색상코드.png`
정본을 런타임에 읽고 정면 1면만 잘라 쓴다 — 잘린 사본을 두면 대표 검수로 정본이
바뀔 때 갈라지고, **갈라진 쪽이 실제로 아이에게 나가는 그림을 정한다.**

## 기본삽화.png

**「실패한 그림」으로 보이면 안 된다.** 어둡거나 비었거나 물음표·자물쇠 같은 기호가
들어가면 **아이가 자기 문장이 부족했다고 읽는다.** 아이는 이것도 자기 그림으로 받는다.

**등급을 말하지 않는다** — 티어 접미어 없이 뽑는다. 붙이면 G3 를 쓴 아이가
`basic` 삽화를 받아 잘못된 등급 신호를 읽는다.

**같은 파이프라인으로 만든다** (`scripts/gen_fallback_art.py`). 화풍이 카드 삽화와
갈리면 아이가 알아보고, 그러면 **주소를 한 개로 통일한 것이 무의미해진다.**

현재 것은 2026-09-08 에 뽑은 후보 10장 중 `fallback-044` 다 (PM 선정).
