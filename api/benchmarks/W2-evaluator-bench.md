# W2 Evaluator 모델 확정 — 예시셋 40개 재측정

측정일 2026-09-07 · 실행 `PYTHONPATH=. uv run python scripts/bench_evaluator.py both` · 유료 티어
기준: PRD 4.5 「Evaluator — 1.5초 이내」 · 합격선 일치율 80% (`docs/adr/0005`)
예시셋: `docs/루브릭_예시셋.md` (커밋 `cacda91`, 카드 대표 검수 반영본)

**W1 스모크를 대체한다.** 그쪽은 입력 312~349토큰짜리 최소 프롬프트라 확정 근거가 못 됐다
(`W1-llm-smoke.md` 「주의」). 여기서는 예시셋 40개를 실제로 붙여 **1,766토큰**으로 쟀다.

## 판정 — `gemini-3.1-flash-lite` 확정

일치율 **97.5%**(합격선 80%) · 지연 최대 **1,361ms**(요구 1,500ms) · 회당 **$0.000518**.
상위 모델을 부르지 않았다. 「가장 좋은 것」이 아니라 「쓸 만한 것」을 고르는 것이 이 벤치의 목적이다.

## 방법 — 왜 두 번 쟀나

예시셋 40개가 few-shot 으로 프롬프트에 들어가는데 **같은 40개로 일치율을 재면 답이 문제지에 적혀 있다.**
PM 문서의 최초 절차가 그랬고, 2026-09-07 에 고쳐 두 모드로 나눴다.

| 모드 | 프롬프트 | 무엇을 읽나 |
|---|---|---|
| **`loo`** (leave-one-out) | 재는 문장을 빼고 **39개** | **일치율은 이 수치로 판정한다** |
| **`all`** | 40개 그대로 | 운영과 같은 형태라 **지연·단가는 이쪽이 실측** |

프롬프트는 **루브릭·판정 경계·예시셋을 전부 문서에서 읽어** 조립한다 (`scripts/bench_evaluator.py`).
코드에 복사하지 않는다 — 복사하면 문서와 갈라지고, **갈라진 쪽이 실제로 아이를 판정한다.**
PRD 4.3 절 번호가 바뀌면 스크립트가 즉시 실패한다. 조용히 옛 루브릭으로 도는 것이 최악이다.

예시는 **등급을 번갈아** 배치한다. 문서 순서대로 넣으면 프롬프트 끝 10개가 전부 G3라 최근 예시
쪽으로 쏠린다. 무작위 셔플은 쓰지 않는다 — 매 호출 순서가 달라지면 caching 이 깨지고 재현도 안 된다.

## 알게 된 것

- **틀린 것은 한 문장뿐이다.** G0 「때린다」를 G1로 봤다. 3자·대상 없음이라 루브릭상 G0인데
  「때린다」를 행동 동사로 읽었다. **인접 오판이고 건너뛴 오판은 0건**이라 루브릭 자체는 흔들리지 않았다
- **비전투 일치율이 100%다.** 예시셋이 막으려던 전투 편향은 나타나지 않았다. 오히려 유일한
  오판이 전투 문장 쪽이다
- **`loo` 에서만 1.5초를 한 번 넘었다**(1,538ms). 운영은 프롬프트가 고정된 `all` 형태이고
  거기서는 최대 1,361ms 로 40회 모두 통과했다. **다만 여유가 139ms뿐이다** — 예시셋이 더
  늘거나 카드 문맥이 붙으면 다시 볼 것
- **caching 적중이 0이다.** `all` 모드에서도 `cached_content_token_count` 가 0으로,
  암묵 캐싱이 걸리지 않았다. 지금 회당 단가는 **캐싱 없이 나온 값**이라 더 나빠질 일은 없다.
  명시적 캐시를 붙이면 입력 1,791토큰의 단가가 $0.25/M → $0.025/M 로 떨어진다 — B-1 에서 볼 것
- **회당 단가가 W1의 3.2배다** ($0.000161 → $0.000518). 입력이 312 → 1,766토큰으로 늘어서다.
  예상된 방향이고 절대액은 여전히 작다

## 절감액 갱신 (`adr/0005` 미결)

파일럿 1 기준 아동 10~30명 × 하루 5장 × 14일 = 700~2,100회.

| | 회당 | 파일럿 총액 |
|---|---|---|
| **`gemini-3.1-flash-lite` (예시셋 포함 실측)** | **$0.000518** | **$0.36 ~ $1.09** |

**이 수치가 확정치다.** W1 값은 예시셋이 빠져 있어 쓰지 않는다.

## 남는 것

- **`EVALUATOR_MODEL` 을 `.env` 에 채워야 한다.** `PILOT_REQUIRED` 에 들어 있어
  비어 있으면 pilot 이 뜨지 않는다. `.env.example` 은 이 커밋에서 채웠다
- **명시적 context caching 은 아직 안 붙였다.** B-1(묘사 평가) 구현에서 붙인다 — 단가가
  10분의 1이 되고, 1.5초 여유 139ms 도 늘어난다
- **홀드아웃 측정은 W3 PM 몫이다** (카드 14·17·19·20). `loo` 는 갈음이지 일반화 측정이 아니다 —
  39개 예시가 여전히 프롬프트에 있다
