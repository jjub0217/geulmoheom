# E-2 서버 2차 NER — 비용 실측 (대표 요청)

측정일 2026-09-08 · 실행 `PYTHONPATH=. uv run python scripts/bench_ner.py` **2회**
모델 `gemini-3.1-flash-lite` · 문장 6개 곱하기 2회 = **12회 호출 · 총 $0.0008**

> **여기는 실측 기록이다. 판정은 「대표 몫」이다** (돈이 나가는 것).
> 문장은 전부 지어낸 것이다 — 실제 아동 문장이 아니다 (PRD 1.1b).

## 대표가 볼 세 숫자

| | 값 |
|---|---|
| **① 아이 문장 1건당 증분** | **$0.000060** (입력 156토큰 · 출력 14토큰 평균) |
| **② 파일럿 1 총액 증분** | 10명 **$0.06** · **30명 $0.19** (2주 · 하루 5장 · 재시도·되묻기 1.5배 가정) |
| **③ 지금 대비** | 회당 $0.000898 → **$0.000958. +6.7%** |

**호출 수는 둘에서 셋으로 1.5배가 되는데 비용은 +6.7% 다.** NER 프롬프트가 156토큰으로
평가(1,766토큰)의 9% 밖에 안 돼서다. **호출 수와 비용이 같이 늘지 않는다.**

②의 바탕: 현행 회당 = 평가 $0.000518(`W2-evaluator-bench.md`) + 검사 $0.00038
(`W3-safety-structure.md`). 30명 기준 시도 수 = 30명 × 14일 × 5장 × 1.5 = 3,150건.
**총 LLM 비용은 $2.83 → $3.02.** 삽화 생성은 여기 안 들어 있다.

**지연은 안 잰다** — 검사 호출과 같은 모양(짧은 지시 + 한 문장, 구조화 출력, thinking 0)이라
`W3-safety-structure.md` 의 **「병렬이면 +13ms」** 가 그대로 적용된다. p50 은 805~873ms 로
검사(989ms)와 같은 자리다. 셋을 같이 던지면 느린 쪽에 묻힌다.

## 비용보다 큰 것이 나왔다 — 잡아야 할 절반을 정규식이 이미 잡는다

| 문장 | 정규식(`app/pii.py`) | NER 1회차 | NER 2회차 |
|---|---|---|---|
| 나는 **별빛초등학교** 3반이야 | **잡는다** (`school`) | ✗ 놓침 | ✓ |
| **김민준**이랑 같이 동굴로 들어갔다 | 안 잡는다 | ✓ | ✓ |
| 나침이가 은빛 검을 들고 달려갔다 | 안 잡는다 | ✓ 통과 | ✓ 통과 |
| 그림자늑대 크라운이 울부짖었다 | 안 잡는다 | ✓ 통과 | ✓ 통과 |
| 마법학교 교장 선생님이 문을 열어줬다 | 안 잡는다 | ✓ 통과 | ✓ 통과 |

**학교명 전체 꼴은 정규식이 결정적으로 잡는다.** NER 은 같은 문장을 **두 번 중 한 번
놓쳤다.** 즉 학교 쪽은 **중복이면서 더 불안정하다.**

**NER 이 혼자 하는 일은 실명뿐이다.** 「김민준」은 정규식이 손대지 않고(그래야 한다 —
넓히면 「나침이」가 걸린다) NER 이 두 번 다 잡았다.

**정확도는 이 표본으로 판정하지 않는다.** 12회 호출은 단가를 재기에 충분하고 정확도를
재기에는 턱없다. **흔들린다는 사실 자체만 기록한다** — 붙이기로 정해지면 **E-1 처럼
시나리오를 만들어 따로 재야 한다.**

## 프로바이더 호출 말고 다른 길이 있나 — 절반은 있다

| | 대안 | 값 |
|---|---|---|
| **학교명** | **이미 정규식이 한다.** 더 넓히려면 교육부 공개 학교 목록(약 12,000개) 사전 대조 | **호출 0.** 목록을 갱신·배포해야 하고, 줄임꼴(`○○초`)까지 넣으면 「마법약초」가 걸리는 그 문제로 되돌아간다 |
| **실명** | 성씨+이름 사전 대조 | **못 쓴다.** 아이가 지은 이름과 못 가른다 — 「나침이」·「크라운」이 걸린다. 정규식을 실명으로 넓히지 않은 이유 그대로 |
| | 로컬 한국어 NER 모델(KoELECTRA 등) | **호출 0 이지만** 의존성·모델 파일·CPU 추론이 붙고, **판타지 이름 오탐 문제는 그대로다.** 이 머신은 지금도 스왑을 5.9G 쓰고 있다 |
| | **자녀 닉네임·가이드 이름 화이트리스트** | **호출 0.** 서버가 이미 아는 값이라 **오탐을 줄이는 데는 바로 쓴다.** 다만 감지 자체는 못 한다 — 대안이 아니라 **어느 쪽을 골라도 같이 붙일 것** |

**결론: 실명만 프로바이더 호출이 유일한 실용 경로다.** 학교명은 이미 호출 없이 되고 있다.

**그래서 선택지가 셋이다.**
1. **NER 을 실명만으로 좁혀 붙인다** — 프롬프트에서 학교를 빼면 토큰이 더 줄어 ①이 내려간다
2. **둘 다 시킨다** — 학교는 정규식과 이중이 된다. 미탐을 줄이지만 **불안정한 쪽이 하나 더 얹힌다**
3. **실명 검사를 파일럿 1 뒤로 미룬다** — 지금 잡히는 것은 전화·메일·주소·학교명 넷이고,
   **실명은 파일럿 참가 아동 10~30명 사이에서만 오간다.** 값과 위험을 대표가 잰다

**1번을 권한다.** 값이 $0.19 로 작고, 학교 쪽 중복·불안정을 안 들이고, 실명은 다른 길이 없다.
**다만 이건 권고이고 판정이 아니다.**
