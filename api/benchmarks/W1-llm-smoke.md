# W1 LLM 스모크 — Gemini 후보 실측

측정일 2026-09-01 · 실행 `PYTHONPATH=. uv run python scripts/smoke_llm.py` · 유료 티어
기준: PRD 4.5 「Evaluator — 1.5초 이내, 저비용, few-shot 분류, 구조화 출력」 · `docs/adr/0005`

**이것은 모델 확정이 아니다.** W2 벤치(B-2, 예시셋 40개)에 올릴 후보를 좁힌 것이다.

## 방법

PRD 4.3 루브릭을 시스템 프롬프트로, 같은 표의 **예시 문장 4개**(G0~G3 각 1개)를 입력으로
구조화 출력(`{grade, signals, descriptors}`)을 받았다. 모델마다 워밍업 1회 후 4회 측정.

**아이가 실제로 쓴 문장은 쓰지 않았다.** 유료 티어도 남용 탐지 목적의 제한적 로깅이 있어
(`adr/0005`), 스모크에는 문서의 예시 문장만 넣었다.

## 결과

| 모델 | 평균 | 최대 | 회당 $ | 루브릭 일치 | context caching |
|---|---|---|---|---|---|
| `gemini-3.7-flash` | 11,030ms | 18,651ms | 0.000902 | 4/4 | $0.075 |

| `gemini-3.5-flash-lite` | 909ms | 1,100ms | 0.000194 | 4/4 | **없음** |

가격은 2026-09-01 확인, **2026-12-31까지** 기준(이후 인상이 예고된 모델이 있다).

## 알게 된 것

- **`gemini-3.7-flash` 는 Evaluator 후보에서 탈락한다.** 판정은 4/4로 정확하지만 평균 11초,
  최대 18.7초로 1.5초 요구를 10배 넘는다. `thinking_budget=0` 을 줬는데도 출력 토큰이
  24~317로 요동쳐, 사실상 추론을 계속한다. Stage 1 GM 후보로는 다시 볼 만하다(품질 > 속도)
- **`gemini-3.5-flash-lite` 는 `thinking_budget=0` 을 400 INVALID_ARGUMENT 로 거부한다.**
  `thinking_config` 를 빼면 정상 동작한다. 모델마다 다르므로 코드에서 분기해야 한다
- **`gemini-3.5-flash-lite` 는 context caching 을 지원하지 않는다.** PRD 4.5가 "few-shot
  예시셋은 context caching"이라 못 박았으므로 그 자체가 감점이다. 아래 「주의」 참조
- **`gemini-2.5-flash-lite` 는 신규 사용자에게 404** 다. API 가 `gemini-3.5-flash-lite` 를
  안내한다. 후보에서 뺐다

## 주의 — 이 숫자를 그대로 믿으면 안 되는 이유

입력이 **312~349 토큰**뿐이다. 실제 Evaluator 는 여기에 **예시셋 40개**(PRD B-1: 등급별
10개 이상)가 붙어 수천 토큰이 된다. 그러면

- 회당 비용에서 **입력이 지배적**이 된다 → context caching 유무가 결정적이다
- 지연도 늘어난다. 지금 1초인 모델이 1.5초를 넘길 수 있다

**W2 벤치는 반드시 실제 예시셋을 붙인 프롬프트로 재측정해야 한다.**

## 절감액 (`adr/0005` 미결 「절감액 실측」)

파일럿 1 기준 아동 10~30명 x 하루 5장 x 14일 = **700~2,100회**.

| | 회당 | 파일럿 총액 |
|---|---|---|
| `gemini-3.1-flash-lite` (실측) | $0.000161 | **$0.11 ~ $0.34** |
| 종전 `claude-opus-5` (PRD 9장 #1 추정) | — | $30 |

절감률은 크지만 **절대액은 $30 → $0.3 수준**이다. 위 「주의」대로 예시셋을 붙이면 회당
비용이 오르므로, W2 재측정 전까지 이 숫자를 확정으로 쓰지 않는다.

## W2 로 넘기는 것

1. 예시셋 40개를 붙인 프롬프트로 `gemini-3.1-flash-lite` · `gemini-3.5-flash-lite` 재측정
2. 루브릭 일치율 80%(B-2) 판정 — 여기 4/4는 표본이 4개라 신호가 못 된다
3. context caching 적용 후 회당 비용·지연 재측정
4. Stage 1 GM 후보는 별도 (W6 전). `gemini-3.7-flash` 를 품질 기준으로 다시 본다
