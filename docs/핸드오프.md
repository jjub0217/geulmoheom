## 3. 오늘 배운 것 — 다시 안 겪게

- **⭐ 변수를 하나만 남기지 않으면 물을 수조차 없다.** 쿠키 결함을 쫓다 하루를 썼는데 **결함이 아니었다** — **재발급이 원인**이었고, 그 전 회차는 **재발급과 앱 종료가 섞여 있었다.** 통제된 시험 한 번이 갈랐다
- **⭐ 증거 없이 인증 경로를 고치면 「고쳤다」가 주장이 된다** (백엔드). `Expires` 를 넣자는 후보가 있었는데 **안 친 판단이 맞았다**
- **주석이 틀린 전제를 담으면 다음 사람이 그 전제로 판단한다** — `artwork.py` 주석 하나가 백엔드를 틀리게 했고(표본에서 두 장을 빼자고 했다), 프론트도 같은 부류를 자기 주석에서 찾았다
- **축 ⑰ 이 여덟 사례가 됐다** — 「재는 조건이 다른데 이름이 같다」. 오늘만 **배포 확인을 루트 경로로 한 것**(PM)과 **픽스처가 지키려는 상태를 한 번도 안 만든 것**(프론트)이 붙었다
- **PM 이 실수한 것 넷** — ① **화면을 안 보고 「재발급 경고가 학부모 화면에 없다」**고 두 세션에 말했다(있었다) ② **승인을 메시지로 전달**해 백엔드가 거절했다(세 번째다) ③ **`/healthz` 200 으로 「서버가 산다」**를 넘겼는데 **DB 를 한 번도 안 지났다** ④ **`GET /book/today` 에 `author` 를 넣으라**고 했는데 **계약에 없었다**(기억으로 말했다)

## 4. 열린 것 — 대표·사용자 몫

- **⏳ GitHub Actions 가 결제 문제로 09-09부터 안 돈다.** **개발은 안 막지만** 백엔드 1번의 완료 조건 ③(CI 에서 초록)이 여기 걸려 있다. **09-10 에 실측이 하나 생겼다** — `main` 의 타입 검사가 반나절 깨져 있었고 **패키지 경계를 넘는 변경이라 각자 도는 검사로는 안 걸렸다**
- **⏳ 가입 조건이 정해진 게 없다** — 비밀번호 한 글자도 통과한다. **안전 정책이라 대표 몫.** 파일럿 3명은 사용자가 계정을 만들어 주므로 급하지 않다
- **⏳ 학부모 로그인 화면이 없다** — 화면은 `/parents/signup` 하나뿐이고 **가입만** 한다. 서버엔 `POST /parents/login` 이 있는데 **부르는 화면이 없다.** 쿠키가 풀리면 다시 들어갈 길이 없다
- **⏳ 고아 학부모 행** — 500 이 나던 동안 `commit()` 이 먼저라 계정이 남았다. **구조는 고쳤다**(`flush()` → `issue()` → `commit()`). **남은 행 정리는 사용자가 백엔드 세션에서 직접 말해야** 하고 **External DATABASE_URL 이 필요하다**
