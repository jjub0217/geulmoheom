> **휘발성 문서다.** 세션이 바뀔 때 덮어쓴다. **결정과 계획은 여기 없다** — 여기 있는 것은 「지금 무엇이 돌고 있고 다음에 무엇을 집어야 하는가」뿐이다. 내용이 오래 남아야 하면 `주차계획/` · `adr/` · `api/` 로 옮기고 여기서 지운다.

**1장만 2026-09-08 오후 기준이다. 2~8장은 아직 09-07 밤 그대로다.**

> **⚠ 2~8장을 지금 그대로 읽지 마라.** 그 사이에 **W3 이 7/7 로 닫혔고, 대표 판정 다섯이 회수됐고, 사후 알릴 셋이 나갔다.** 3장 「다음에 집을 것」과 6장 「열려 있는 것」은 **거의 다 지나간 것**이다. **지금 참인 것은 1장과 `주차계획/W4.md` 다.** 2~8장은 PM 세션이 실제로 바뀔 때 통째로 다시 쓴다 — **여기까지가 이 문서가 휘발성이라는 뜻이다.**

## 1. 지금 이 순간

**작성 2026-09-08 오후 · W4 정식 첫날**

|---|---|
| **백엔드** (`api/`) | **닫혔다. W3 을 7/7 로 끝냈다.** 다음은 **새 세션**에서 `git pull --rebase` → `/my-week W4` |

> **⚠ 개발 서버를 다시 띄우지 마라.** `make dev-api` 가 **이전 세션에서 백그라운드로 돌고 있다**(`--reload`). Postgres·Redis 도 **15시간째 healthy**. **확인부터** — `curl -sk https://api.geulmoheom.test:8000/openapi.json` 이 200 이면 그대로 쓴다. **다시 띄우면 포트 8000 이 충돌한다.** `docker` 는 `~/.docker/bin` 에 있을 수 있다.
>
> **메모리는 괜찮다.** 2026-09-08 에 「빡빡하다」가 **두 번 잘못 올라갔다** — `top` 의 `unused` 를 보고 판단한 것이고, 실제 메모리 압력은 여유가 있다. **새 세션 전에 닫을 앱 없다.**
>
> **`api/` 워킹 트리는 깨끗하다.** 보이는 미커밋은 **전부 프론트 것**이니 **`git add` 에 경로를 박는다.**

**새 api 세션이 첫날에 밟을 것 하나 — 「검사 명령을 파이프에 태우지 않는다.」**
`make contracts-check | tail -1 && git commit` 은 **파이프의 종료코드가 `tail` 것**이라, 검사가 실패했는데 커밋이 그대로 나갔다. **W4 첫 항목이 삽화(B-3)라 바로 밟는다** — 응답 스키마가 바뀌고 `types.gen.ts` 재생성이 따라붙는다. **독스트링 한 줄만 고쳐도 `/openapi.json` 이 바뀐다.** 단독으로 돌리고 종료코드를 눈으로 본 다음 커밋한다.

**삽화(B-3)는 「그림만 만들면 되는 것」이 아니다** — **삽화 프롬프트도 출력 검사를 통과해야 나간다**(E-1 양방향). W3 에서 「검사할 모델 출력이 아직 없어 B-3 로 옮긴다」고 한 그 자리라, **B-3 를 칠 때 출력 검사가 같이 선다.** 완료 조건은 `주차계획/W4.md` 「범위」 표에 있다.

## 3. 다음에 집을 것 — 우선순위 순

1. **백엔드 — W3 를 마저 닫는다. `F-1` → `E-2 서버` → `E-4`.** 그다음 W4 백엔드(**삽화 B-3** → 카드 DB → 나머지), **속도 제한은 그 뒤**(파일럿 전이면 된다).
   **순서를 오늘 두 번 바꿨다. 지금 것이 최종이고 이유는 `주차계획/W4.md` 「순서 권고」에 있다** — ① W3 을 온전히 닫아야 **수요일 재측정이 깨끗하다** ② **`E-4` 가 프론트 셋을 연다**
2. **프론트 — 아이 로그아웃**(선행 찬 유일한 것) → 그 뒤 **`E-4` 까지 대기**. `E-4` 가 닫히면 **학부모 자녀 관리 화면 + ③④** 가 한 번에 열린다
3. **PM — 프리테스트 모집** (**선행 없음**). 설계는 `docs/프리테스트_설계.md` 에 끝났다. **만 10~12세 3명 · 남녀 섞어서 · 글쓰기를 특별히 좋아하는 아이만 모으지 않는다.**
   **모집을 시작할 때 대표에게 「중단 조건」을 함께 보낸다** — 「이게 나오면 파일럿 일정을 다시 짠다」는 **일정 판정이라 대표 몫**이고, **만나기 전에 공유해야 나중에 판정이 선다.** C-2 가 그걸 안 해서 사후에 근거를 바꿔야 했다
4. **PM — 대사 세트(C-1).** **선행: A0-3 화면.** 화면이 서면 `문구.md` 에 확정해 내려준다. `_결과대사` 가 그때 닫힌다

## 4. W5 계획을 세울 때

- **덜어낸 것 둘** — **화풍 일관성(B-5)**(C-2 이관분 포함) · **서버까지 붙는 E2E+CI**. E2E 는 **두 번째로 미룬 것이라 W5 에서는 더 못 민다**
- **볼 축 여섯이 `주차계획/W4.md` 「하지 않는 것」에 이유까지 적혀 있다.** ⓪이 가장 값이 크다 —
  **⓪ 완료 판정 문장을 항목으로 되짚는다.** 오늘 누락 셋(아이 로그아웃 · 자녀 인증 화면 · 학부모 자녀 관리 화면)이 **전부 「완료 판정에는 있는데 항목에는 없는」 것**이었고 **다른 항목의 선행으로만 존재**했다. **동사마다 담당 항목이 있는지 세면 셋 다 걸렸다.** 나머지 축은 **어긋난 뒤에 잡는** 장치인데 이건 **어긋나기 전에 세는** 것이다

## 5. 오늘 배운 것 — 「장치」에 대해

**「조용히 어긋나거나 원인이 엉뚱한 데를 가리키는」 사고가 열 번 넘게 났다.** 다섯 부류로 갈린다.

- **장치가 못 잡는 것** — 한글 토큰 · env 이름 · Makefile 배관 · 계약 드리프트 · vitest 별칭 · `make certs` 절반 실행 · **모델만 고치고 마이그레이션을 안 남긴 것** · **테스트 DB 가 옛 스키마를 들고 초록불이 뜬 것**
- **장치 자체가 틀린 것** — CI 경로 필터가 검사 자체를 고치는 커밋을 안 돌린 것 · E2E 의 「버튼 하나뿐」이 개발 오버레이까지 센 것 · `make contracts` 가 서버가 죽어도 초록인 것
- **장치가 제품을 붙잡는 것** — E2E 가 `[보안 필터]` 를 여섯 군데에 박아둬 **문구를 바꾸는 날 테스트가 제품을 막았다**
- **PM 쪽에서 나온 것** — **코드가 `docs/` 문서 다섯을 런타임에 읽는데 CI 가 문서 변경에 api 테스트를 안 돌렸다.** `docs/**` 를 필터에 넣어 닫았고 **다음 문서 커밋에서 `api → success` 가 실제로 도는 것까지 확인**했다
- **장치가 사람이 못 볼 것을 잡은 것** (유일한 좋은 쪽) — `maxLength` 가 `onChange` 보다 먼저 잘라 **붙여넣은 코드에서 숫자가 조용히 사라지는** 버그. **손으로 또박또박 치면 절대 안 나온다**

**장치를 세울 때마다 「이 장치는 자기 자신과 자기 밖의 것을 어떻게 다루나」를 한 번 묻는다.** 오늘 그 질문이 CI 구멍과 라벨 구멍을 잡았다.

## 7. PM 이 오늘 낸 실수 — 같은 걸 또 하지 않게

- **W3 잔여를 W4 로 흡수하려 했다** → 같은 항목이 두 체크리스트에 생기고 **수요일 재측정이 망가진다.** 사용자가 잡았다
- **누락 셋** — 아이 로그아웃 · 자녀 인증 화면 · 학부모 자녀 관리 화면. **전부 「완료 판정에는 있는데 항목에는 없는」 것.** 앞의 둘은 프론트가 잡았다
- **계획 문서에서 담당과 크기가 갈렸다**(C-1·A0-3), **편집하다 문장을 깨뜨렸다**(순서 권고 줄) → **둘 다 프론트가 잡았다**
- **「라벨이니 아이 원문이 아니다」로 로그 규칙을 제안했다** → `category` 는 **모델이 자유롭게 채우는 필드**라 원문이 샐 수 있다. 백엔드가 잡았다
- **계약 문서에 틀린 줄을 넣었다** — 「로그아웃하면 다른 기기도 끊긴다」. **옛 문장이 「구현 상태」와 「설계」를 한 문장에 담고 있었는데 앞을 뒤집으며 뒤까지 뒤집었다.** 백엔드가 잡았다. → **구현 상태와 설계를 한 문장에 쓰지 않는다**
- **대표에게 「프론트가 비어 시간이 빈다」고 썼다** → **1인이라 프론트가 비어도 시간은 안 빈다.** W4 를 연 실익은 **순서를 바꾼 것**이지 병렬이 아니다
- **핸드오프에 「api 는 세션과 함께 죽는다」로 적었다** → 안 죽는다. **다시 띄우면 포트 충돌.** 백엔드가 잡았다

**오늘 PM 실수를 잡은 것은 거의 전부 상대 세션이었다.** 혼자였으면 다 통과했다.
