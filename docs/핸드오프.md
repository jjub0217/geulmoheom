## 2. 대표 판정 — **대기 중인 것이 하나 새로 생겼다**

**받은 것 둘** (2026-09-09 밤, 한 번에 올려 한 번에 받았다)
- **예산** — 「이번 주에만 3,500원 더. 다음 주부터는 4,000원 안 넘게」. `adr/0010` 「예외 하나」
- **판정 기준** — 「1주차 대 2주차」 → **「전반 대 후반」** 승인. `검증가설_성공지표.md` 반영

**⛔ 새로 생긴 것 하나 — 배포처를 Vercel 로 바꾸는 것**
- **`adr/0007` 은 「Cloudflare Pages + Cloudflare Registrar」다.** 그리고 **Vercel 을 근거를 들어 기각**했다 — 「벤더가 하나 더 늘고, R2 와 계정이 갈리고, 이길 근거가 없다」
- **사용자가 「도메인은 버셀로」라고 정했고 프론트가 그 형태로 발판을 세웠다**(`7fdb693`). **아직 아무것도 안 올렸다** — 되돌리는 비용이 지금은 0 이다
- **배포처는 「돈이 나가는 것」이라 대표 몫이다**(`adr/0008` 결정 3 ①). **ADR 로 뒤집어야 한다** — 새 ADR 을 쓰는 것은 **판정을 받은 뒤**다. 안 받은 것을 채택으로 적지 않는다

**⚠ 대표에게 「알리는 것」은 이제 커밋 메시지로 간다** (2026-09-09, 루트 `CLAUDE.md`). **대표가 커밋과 메모를 전부 읽는다.** **판정만 직접 올린다** — 알림과 판정은 다르다.

## 3. 다음에 집을 것 — 순서가 정해져 있다

**1순위 (09-10) — 파일럿을 여는 둘. 이것 말고는 파일럿을 안 막는다**
- **삽화 — ⛔ 신규 생성 없음** (2026-09-09 확정). **`api/out/` 의 기존 `legendary` 를 재사용**하고, **해당 `card+tier` 가 없으면 같은 카드의 `legendary` 로 폴백**한다. **굽는 코드가 캐시 미스에서 돌지 않게 막는 것**까지가 이 항목이다
- **NER 미탐·전체 정확도** — 아이 50명이 쓰면 **실명이 실제로 들어온다**

**2순위 (09-10~11) — 배포.** `CLAUDE.md` 의 「배포는 개발을 마친 뒤에」에서 **「개발」의 단위는 Stage 0** 이다.
**형태는 `주차계획/W5.md` 「배포 형태」 절에 있다** — **`vercel.json` rewrites 로 같은 오리진에 프록시하는 안이 유력**하고, **버셀만으로도 Supabase 로도 api 가 안 간다**는 것까지 근거가 적혀 있다.

**3순위 — 나머지 여섯을 파일럿 전에 최대한 당긴다.** 서버 E2E+CI · 화풍 · 책 제목 · 화면 정돈 · 훑기 축 다섯.

**⚠ 09-11~19 는 비는 시간이 아니다.** **파일럿 중에 나오는 것을 고치는 것이 주 업무**다. **실기기 한 번에 일곱이 나왔는데 아이 50명이 9일 쓰면 그보다 많이 나온다.** **전반에 막혀 있으면 데이터가 망가지므로 그날 고쳐야 한다.** 그래서 3순위를 미리 당긴다.

## 4. 어제·오늘 실기기 세션이 찾은 일곱 — **다시 안 겪게**

**전부 검사 154개가 초록인 상태에서 나왔고 전부 사람이 눈으로 봐서 나왔다.**

1. **CORS 대소문자** — `scutil` 이 준 호스트명에 대문자가 있는데 **브라우저는 `Origin` 을 소문자로 정규화해 보낸다.** **`curl` 로는 절대 안 걸린다 — `Origin` 을 안 보낸다**
2. **⛔ 아이가 들어갈 문이 하나도 없었다** — 홈 화면 아이콘이 `start_url: "/"` 로 열려 **401 막다른 화면**이 됐고, 탭에서는 **우리가 코드 입력을 일부러 막아 뒀다**. 401 → 인증 화면 갈래를 넣어 풀었다
3. **삽화가 57% 잘려** 나갔다 — `aspect-4/3` + `object-cover` 에 0.58 세로 그림
4. **다크 모드에서 나침반이 통째로 죽어** 있었다 — 바늘이 배경과 거의 같은 색
5. **나침반이 두 구간 다 안 움직였다** — 「가득 = 30」이었는데 **PRD 는 「30자 넘으면 밝아짐」이라는 문턱만 정했다.** 30 에서 멈춰 **H2 합격선 150자 구간에 신호가 없었다**
6. **「나침반」이 소개 없이 튀어나왔다** — 소개하는 자리가 **튜토리얼(Stage 1)**이라 **Stage 0 에는 온보딩이 없는데 대사가 온보딩을 전제**했다
7. **진행 대본에 「계정을 세워 둔다」가 통째로 없었다** — **사용자가 「학부모 화면이 뭐야」라고 물어서 드러났다.** 만든 사람이 어디로 들어가는지 몰랐다

## 5. 오늘 세운 규칙 넷 — 다음 세션이 지켜야 한다

- **세션 간 메시지는 기록이 아니다** (루트 `CLAUDE.md`). **결정·판정·범위가 메시지로 정해지면 받은 쪽이 「어느 문서에 적히나」를 되묻는다.** **하루에 넷을 밟았고 넷 다 받은 세션이 찾았다** — 보내는 쪽은 하나도 못 찾았다
- **③(안전·프라이버시 경로) 알림은 커밋 메시지로** (루트 `CLAUDE.md`). **첫 줄에 드러나야 하고 「무엇을 왜 그렇게 정했다」를 쓴다.** **진척 파일에 「대표에게 직접 말했다」 체크박스를 만들지 않는다**
- **배포는 개발을 마친 뒤에** (루트 `CLAUDE.md`)
- **목·픽스처도 `문구.md` 를 읽는다. 예시를 박지 않는다** (`문구.md` 0장)

## 6. 오늘 PM 이 낸 실수 — 같은 걸 또 하지 않게

**전부 다른 세션이나 사용자가 잡았다. 혼자였으면 다 통과했다.**

- **메시지로만 말하고 문서에 안 적었다 — 넷.** `sketch_url` 항목 · 「화면 구성이 엉성하다」 · 화풍 판정의 주어 · **그 축을 세우라는 지시 자체**(`grep` 0건이었다)
- **대표 몫을 좁혔다 — 셋을 한꺼번에.** 「1/3 이하」(안전 계량) · 검수본 스케치 수정 · 주차 범위. **오후에 $0.34 로 한 번 좁혔다가 거절당하고도 그랬다**
- **`out/` 의 시각만 보고 「최신이니 다시 안 구워도 된다」고 했다** — 그 빌드는 **다른 대상을 향한 것**이었다. **「최신인가」와 「무엇을 향해 구웠나」는 다른 물음이다**
- **`lsof` 로 「연결이 없다」를 보고 성급히 물렸다** — 스냅샷이라 근거가 약하다고 했는데 **실은 맞는 신호였다**
- **`svh` 후보를 냈는데 이미 가진 숫자로 걸러졌다** — **폭이 맞다는 것이 오히려 `svh` 를 정상으로 지목한다.** 확인할 수 있는 숫자로 확인 안 하고 후보를 냈다
- **사용자가 안 한 말을 사용자 것으로 만들어 채점을 요구했다** — 「엉성하다」 한 마디를 다섯 항목으로 쪼개 놓고 **그 다섯을 되짚어 달라고 했다.** 사용자가 「그 다섯이 뭔지 모르겠다」고 했다
- **W4 에 항목을 계속 세웠다** — 오늘만 여섯 넘게. **상당수가 「막지 않는데 W4 에 세운 것」**이었고 **결국 W5 로 옮겼다**
