## 5. 오늘 배운 것 — 「장치」에 대해

오늘 **「조용히 어긋나거나 원인이 엉뚱한 데를 가리키는」 사고가 여덟 번** 났다. 네 부류로 갈린다.

- **장치가 못 잡는 것** — 한글 토큰 · env 이름 · Makefile 배관 · 계약 드리프트 · vitest 별칭 · `make certs` 절반 실행
- **장치 자체가 틀린 것** — CI 경로 필터가 검사 자체를 고치는 커밋을 안 돌린 것 · E2E 의 「버튼 하나뿐」이 개발 오버레이까지 센 것 · `make contracts` 가 서버가 죽어도 초록인 것
- **장치가 제품을 붙잡는 것** (새 부류) — E2E 가 `[보안 필터]` 를 여섯 군데에 박아둬 **문구를 바꾸는 날 테스트가 제품을 막았다.** 프론트 문장 그대로: **「박아두면 문구가 바뀌는 날 테스트가 제품을 붙잡는다」**
- **PM 쪽에서 나온 것** (오늘 처음) — **코드가 `docs/` 문서 다섯을 런타임에 읽는데 CI 가 문서 변경에 api 테스트를 안 돌렸다.** 내 커밋이 서버를 깨뜨려도 초록이었다. `docs/**` 를 필터에 넣어 닫았고, **다음 문서 커밋에서 `api → success` 가 실제로 도는 것까지 확인**했다

**장치를 세울 때마다 「이 장치는 자기 자신과 자기 밖의 것을 어떻게 다루나」를 한 번 묻는다.** 오늘 그 질문이 CI 구멍과 라벨 구멍 둘을 잡았다.

## 7. PM 이 오늘 낸 실수 — 같은 걸 또 하지 않게

- **W3 잔여를 W4 로 흡수하려 했다** → 같은 항목이 두 체크리스트에 생기고 **수요일 재측정이 망가진다.** 사용자가 잡았다. **안 끝난 일을 다음 주로 옮기면 지켜진 것처럼 보인다**
- **계획 문서에서 담당과 크기가 갈렸다** (C-1·A0-3) → **형태를 바꾼 첫날에 났고 프론트가 잡았다.** 선행만 한 곳으로 모으는 것으로는 안 된다
- **「라벨이니 아이 원문이 아니다」로 로그 규칙을 제안했다** → `category` 는 **모델이 자유롭게 채우는 필드**라 원문이 샐 수 있다. 백엔드가 잡았다. **같은 실측(이름이 세 가지로 왔다)을 보고도 「이름 아닌 것도 올 수 있다」로 잇지 못했다**
- **대표에게 「프론트가 비어 시간이 빈다」고 썼다** → **1인이라 프론트가 비어도 시간은 안 빈다.** 같은 사람이 백엔드를 하고 있다. W4 를 연 실익은 **순서를 바꾼 것**이지 병렬이 생긴 게 아니다
