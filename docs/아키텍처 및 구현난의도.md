## 2. 시스템 아키텍처 (확정 스택)

### 2.1 구성

| 층 | 선택 | 역할 |
|---|---|---|
| **클라이언트** | Next.js (App Router) PWA — **정적 빌드**, TailwindCSS, Zustand (`adr/0007`) | 태블릿 가로 우선 반응형 UI, 타이핑 애니메이션, 클라이언트 1차 PII 마스킹, 서사 스트리밍 수신 |
| **백엔드** | **FastAPI** (Python) | API, 세션·잠금 로직, 이벤트 로깅, 학부모 계정·동의 |

| **LLM** | **Google Gemini, 유료 티어** (`adr/0005`). 모델명은 W2 벤치로 확정 (PRD 4.5) | GM / Evaluator / 상태 추출기 / Safety |

### 2.2 요청 흐름

**Stage 0 — 그림이 되는 이야기 (LLM 1회 호출)**
```
클라이언트 ── 입력(1차 PII 마스킹) ──> FastAPI
  ├─ 2차 PII 검사 (NER)
  ├─ 입력 Moderation
  ├─ Evaluator (등급 + 묘사어 태그)          ← 유일한 LLM 호출
  │     └─ G0 → 스캐폴딩 템플릿 조립 (LLM 없음) → 응답
  ├─ 캐릭터 대사 템플릿 치환 (LLM 없음)
  ├─ 이미지 생성 큐 (비동기, 티어별 프롬프트) → S3
  ├─ 이벤트 로깅 → Postgres
  └─ 응답 (등급 → 티어, 하이라이트, 대사) ── 삽화는 완료 시 푸시
```

**Stage 1 — TRPG** (**⛔ 2026-09-17 실제와 맞췄다** — 아래 「달랐던 넷」)
```
[잠금 확인] → 입력 Moderation → PII → Evaluator → [G0이면 되묻기·여기서 반환]
     → GM 서사 생성(비스트리밍) → 출력 Moderation
     → [핵심 씬이면 프롬프트 출력 검사 → 이미지 굽기는 백그라운드]
     → 상태 추출기(매 턴) → 요약기(3턴마다) → Postgres 저장 → 로깅 → 응답
GM 컨텍스트 = 시스템 프롬프트 + 챕터 뼈대 + 상태 JSON + 서사 요약 + 최근 3턴 원문
```

**⛔ 종전 그림과 달랐던 넷** (계약 SSOT 는 `docs/api/Stage1.md` 2절이다)
- **잠금이 제일 앞이다** — 하드 피니시(D-1)·일일 턴 상한(D-2)을 **프로바이더 호출보다 앞에서** 본다. 뒤에 두면 **잠긴 아이 때문에 검사·평가·GM 호출이 나가고 그 결과는 화면에 안 뜬다**
- **Moderation 이 PII 보다 앞이다** — 종전 그림은 반대였다
- **되묻기가 여기서 반환한다** — `G0` 이면 **GM 에 안 간다.** **⚠ 그래서 아이가 딴소리를 하면 `문구.md` 1.23(복귀 문구)이 아니라 1.12(되묻기)가 나간다** — `미룬것.md` 에 섰다
- **스트리밍이 아니다** — `app/gm.py` 가 `generate_content` 다. **그래서 「첫 토큰 3초」(PRD 7장)를 아예 못 잰다**(`adr/0005` 82행)

**⚠ 상태는 Redis 가 아니라 Postgres 다** (`chapters.state`). PRD A-2 는 「Redis 유지 · 완결 시 스냅샷」인데 **완료 조건이 「껐다 켜도 이어진다」**라 휘발 저장과 안 맞았다. 백엔드가 알렸고 PM 이 받았다 (`e8c832b`).

### 2.3 데이터 보관 원칙 (`페르소나정의.md` 7.4)

* 아동 입력 원문은 **로그에 저장하지 않는다**. `events`는 수치·등급·태그만
* Stage 0 `card_attempts` 원문은 파일럿 동의 하에 별도 보관, 파일럿 종료 시 파기
* ~~Stage 1 턴 원문은 챕터 완결 시 요약 스냅샷만 남기고 Redis에서 파기~~ **← ⛔ 2026-09-16 에 사실이 아니게 됐다**
  **Stage 1 턴 원문은 `chapter_turns.text` 에 남는다** — **파기하지 않는다.** 이유는 **A-7** 이다: **「챕터 완결 = 책 한 장 · 문장은 아이 원문 그대로, AI 보정 없음」**(비전 2장). **파기하면 책이 빈다.**
  **⭐ 원칙이 뒤집힌 것이 아니라 이 줄이 원칙을 좁게 적었던 것이다** — PRD 1.1b 가 이미 **「아이 원문은 로그가 아니라 창작물 — 책 콘텐츠로 보관, 로그·APM에는 미기록」**으로 정해 뒀다. **Stage 0 `card_attempts.text` 와 같은 자리**이고 바로 윗줄이 그것이다.
  **원문이 가도 되는 곳은 셋뿐이다** — `card_attempts.text` · `chapter_turns.text` · `book_pages.text` (`api/CLAUDE.md`, 2026-09-16 사용자가 직접 열었다). **로그·APM·예외 메시지·이벤트 payload 는 그대로 금지다.**
  **⚠ 파기는 없어진 게 아니라 다른 자리다** — **90일 비활성 파기 배치(E-5)** 가 덮는다(아래).
