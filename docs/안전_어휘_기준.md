# 안전 어휘 기준 — 판타지 전투 허용 범위 및 Moderation 경계 (v1)

작성일: 2026-08-29 · 대상: `MVP_PRD.md` E-1 · 상태: **초안, 파일럿 로그로 조정**

## 1. 원칙
- 판타지 모험에서 **싸움은 허용**, **고통의 묘사는 차단**. 기준은 행위가 아니라 결과의 묘사 수준
- 설득·관찰·돌봄·회피는 전투와 **동등한 정상 행동**이다. Moderation은 물론 Evaluator·GM도 이를 소극적 행동으로 취급하지 않는다
- 오탐(안전한 입력을 막음)은 아이의 흐름을 끊고 글쓰기 울렁증을 건드린다. 미탐(유해 입력을 통과)은 학부모 신뢰를 깬다. **Stage 0은 미탐 0건을 우선**하되, 오탐은 화이트리스트로 줄인다
- 차단 시 절대 "나쁜 말"이라고 하지 않는다. GM 캐릭터가 "나침반이 그 말은 못 알아듣네. 다르게 말해줄래?"로 되묻는다 (턴 미소모)

## 1b. 검증 대상 — Gemini 내장 안전 필터 (2026-08-31 추가)

LLM 프로바이더가 Gemini로 바뀌면서 안전 필터가 API 호출에 내장된다 (`adr/0005`). **아래 2장 화이트리스트를 필터 임계값으로 재현할 수 있는지가 W2 판정 항목**이다.

- **판정 기준**: 3장 차단 카테고리에서 **미탐 0건**을 유지하면서, 2장 화이트리스트 어휘의 오탐이 허용 범위에 들어오는가
- **못 넘기면**: 별도 Moderation 단계를 유지한다 (PRD E-1 현재 구조). 기준을 낮춰 통과시키지 않는다
- **가장 위험한 어휘**: 「전투 동사」의 *베다·찌르다·때리다*, 「무기」의 *폭탄*, 「마법」의 *저주·폭발*. 판타지 맥락을 필터가 읽지 못하면 여기서 오탐이 몰린다
- 1장이 적어둔 실패 모드가 그대로 적용된다 — **오탐은 아이의 흐름을 끊고 글쓰기 울렁증을 건드린다**. `outcome: blocked` 남발은 곧 H2 검증 실패다

| 범주 | 어휘 |
|---|---|
| 전투 동사 | 물리치다, 쓰러뜨리다, 무찌르다, 막다, 밀어내다, 붙잡다, 묶다, 가두다, 쫓아내다, 겨누다, 휘두르다, 베다, 찌르다(무기 대상), 던지다, 쏘다(화살·마법), 부수다(물건), 때리다(괴물·문) |
| 무기·도구 | 검, 단검, 활, 화살, 방패, 지팡이, 창, 도끼, 망치, 밧줄, 그물, 횃불, 폭탄(마법), 함정 |
| 마법 | 불꽃, 번개, 얼음, 폭발, 저주, 봉인, 소환, 변신, 투명 |
| 결과 | 도망치다, 기절하다, 사라지다, 항복하다, 무너지다, 쓰러지다, 잠들다, 돌이 되다 |
| 위험 상황 | 절벽, 떨어지다, 빠지다, 갇히다, 쫓기다, 물리다(동물), 다치다(경상) |

| **관찰·추리** | 살펴보다, 엿듣다, 숨다, 기다리다, 따라가다, 흉내내다, 비교하다, 알아채다 |

## 3. 차단 (블랙리스트) — 카테고리와 경계

| 카테고리 | 차단 예 | 허용 경계 (이건 통과) |
|---|---|---|
| **유혈·신체 훼손** | 피가 튀다/흐르다, 살점, 뼈가 부러지는 소리, 팔·다리·목을 자르다, 내장, 눈알 | "괴물이 쓰러졌다", "검에 맞은 괴물이 연기가 되어 사라졌다" |
| **고문·잔혹** | 천천히 고통을 주다, 괴롭히며 즐기다, 불로 지지다, 산 채로 | "가두다", "묶어서 마을로 데려가다" |
| **죽음 직접 묘사** | 죽여버리다, 시체, 죽은 몸을 ~하다 | "물리치다", "쓰러뜨리다", "사라지다", "봉인하다" |
| **자해·자살** | 스스로 다치다, 뛰어내리다(의도적), 죽고 싶다 | "절벽에서 떨어질 뻔했다" (사고) |
| ↳ | **이 카테고리만 뒤 처리가 다르다** — 아이에게 「어른에게 말해줘」 한 줄 · 기록 · 보호자 주간 리포트. **PRD E-1 「자해·자살 신호 처리」를 따른다** (2026-09-07 대표 판정) | |
| **선정** | 신체 부위 성적 언급, 옷을 벗기다 | "갑옷을 벗다", "투구를 벗다" |
| **비속어·혐오** | 욕설, 외모·장애·인종·성별 비하 | "바보 도깨비", "멍청한 괴물" (가벼운 놀림, 대상이 가상 존재) |
| **현실 폭력 전이** | 총, 칼로 사람을(현실 맥락), 학교·친구·가족에 대한 폭력 | 판타지 무기로 괴물·악당 대상 |
| **PII** (E-2 담당) | 실명, 학교명, 주소, 전화번호, 사진 요청 | 닉네임, "우리 마을"(가상) |

## 4. 회색 지대 — 판정 규칙

| 입력 | 판정 | 이유 |
|---|---|---|
| "똥을 던진다", "방귀로 물리친다" | **허용** | 초등 유머. 막으면 오탐으로 이탈 유발. GM은 웃으며 받아줌 |
| "괴물을 죽인다" | **허용 + 서사 치환** | 입력은 통과시키되, GM 서사는 "물리쳤다/쓰러졌다"로 표현. 아이 입력을 막지 않음 |
| "피가 조금 났다" (경상, 자기 자신) | **허용** | 모험 중 경상은 자연스러움. 출혈 강조·반복 시 차단 |
| "친구 ○○를 때린다" | **차단** | 현실 인물·현실 폭력. PII 검사도 동시 발동 |
| "무섭다, 도망가고 싶다" | **허용** | 감정 표현은 묘사의 일부. G2 이상 근거가 됨 |
| "아무것도 안 한다", "가만히 있는다" | **허용 (G0~G1)** | 안전 문제 아님. Evaluator가 처리 |
| 게임 은어 ("개쩐다", "존잼") | **허용** | 비속어 경계 아래. 단, 욕설 어근 포함 시 차단 |

## 5. 출력(AI 생성물) 검사 — Stage 1 GM 서사
- 입력이 통과했어도 **GM 서사는 3장 블랙리스트 전체 카테고리**를 재검사
- 차단 시 재생성 최대 2회, 실패 시 사전 작성한 안전 서사("탐험가의 행동에 괴물이 주춤하며 물러났다")로 대체
- 이미지 프롬프트는 서사보다 엄격 — 무기 접촉 장면 생성 금지, "대치·준비 자세·승리 후" 컷만 허용
- **모든 삽화에 가이드 캐릭터를 함께 넣는다** (2026-09-01 W1 이미지 벤치 관찰). 가이드 없이 생성한 위기 장면(c01)은 뿔 달린 거대 실루엣이 어두운 숲을 가득 채워 만 10~12세 기준으로 **경계에 가까웠다.** 가이드가 함께 있으면 톤이 확연히 부드러워진다.
  즉 **가이드 주입은 화풍 일관성(B-5) 장치이자 공포 톤 완화 장치**다. 지연·비용을 이유로 빼지 않는다. 뺄 일이 생기면 위기 유형 카드부터 톤을 다시 검사한다

## 6. 로그 및 조정
- 모든 차단은 `moderation_blocked` (direction, category, hash) — 원문 미저장
- 파일럿 1주차 종료 시 차단 로그 전수 검토 → 오탐 카테고리는 2장 화이트리스트에 추가, 미탐 신고는 3장에 추가
- 목표: 파일럿 2주차 오탐률 5% 미만, 미탐 신고 0건
