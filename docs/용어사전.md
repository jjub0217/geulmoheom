# 글모험 용어 사전 (Ubiquitous Language)

> 기획·디자인·코드·대화에서 **같은 것은 같은 말로** 부른다. 이 표에 없는 말로 요청이 오면 먼저 여기에 등록한다.
> 세 열을 구분한다 — **아이 화면**(UI·캐릭터 대사에 쓰는 말) / **내부 용어**(문서·회의·PR에서 쓰는 말) / **코드 식별자**(API·DB·이벤트명). 열을 넘어 섞어 쓰지 않는다. 특히 **내부 용어를 아이 화면에 노출하지 않는다.**

## 1. 사람과 역할

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 탐험가 | 아동 / 학생 / 플레이어 | `child` | 만 10~12세 사용자. 캐릭터는 항상 "탐험가"라고 부른다 |
| (이름은 아이가 지음, 기본 "나침이") | GM 캐릭터 / 가이드 | `guide` | 래서판다 탐험가-학자. Game Master 에이전트의 얼굴. 퀘스트 밖 대화 없음 |
| 부모님 | 학부모 / 보호자 | `parent` | 계정 생성·동의·결제 주체. 관찰자. 대시보드는 P1 |
| — | 운영자 | — | 파일럿 기간 온보딩·로그 확인. UI 없음 |
| — | 플레이 원형 A / B | `archetype: action\|narrative` | A 행동·성취 지향(이민준), B 서사·관계 지향(김서윤). 성별 구분이 아님 |
| 문장술사 | 최상위 칭호 | `title: spellwright` | 전설 티어 누적·연재 작가 등록 시 부여. 서재에 "문장술사 ○○의 책" |

## 2. 플레이 단위

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 장면 / 카드 | 장면 카드 | `card` | Stage 0의 단위. 스케치 삽화 + 한 줄 상황 + 명사 태그. 서사 연결 없음 |
| (버튼: "다시 써보기") | 시도 / 재시도 | `attempt`, `retry_of` | 카드 1장에 대한 입력 1회. 재시도는 일일 카운트 미소모 |
| 오늘의 모험 | 세션 | `session` | 접속~종료 화면까지. Stage 0은 카드 5장, Stage 1은 챕터 1개 |
| 모험 / 이야기 | 챕터 | `chapter` | Stage 1의 단위. 8~12턴, 15~20분. 도입-위기-**시련**-완결 |
| — | 턴 | `turn` | 챕터 안의 입력 1회. 선택지 클릭도 턴 |
| (서사 속에서만 등장) | 시련 | `trial` | 챕터의 고비. **"보스"라고 부르지 않는다.** 힘·설득·관찰·돌봄 4경로로 통과 |
| — | 4경로 | `trial_path: force\|persuade\|observe\|care` | 시련 통과 방식. 경로에 따른 보상 차별 없음 |
| — | 뼈대 | `beat_sheet` | 챕터의 사전 작성 구조. GM은 이 위에서 생성 |

## 3. 평가와 보상

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| **(절대 노출 안 함)** | 등급 | `grade: G0\|G1\|G2\|G3` | Evaluator 판정. 로그·내부 전용. **화면·API 응답에 넣지 않는다** |
| 기본 / 희귀 / 전설 | 티어 | `tier: basic\|rare\|legendary` | 아이가 보는 삽화 품질 단계. G0·G1→기본, G2→희귀, G3→전설 |
| "이 단어들이 나침반을 움직였어" | 묘사어 하이라이트 | `highlights` | Evaluator가 감지한 형용사·부사·절. 입력문 위에 표시 |
| 나침반이 밝아진다 / 흐려진다 | 나침반 반응 | `guide.expression: compass_bright\|compass_dim` | 등급의 시각적 표현. 나침반은 **아이 문장에만 반응**한다는 세계관 장치 |
| (질문으로만 등장) | 되묻기 = 스캐폴딩 | `scaffold` | G0 시 GM이 질문 1개로 되묻는 것. 턴 미소모, 최대 2회. **부정어 금지** |
| 스킬 보너스 | 스킬 보너스 | `bonus` | Stage 1. 등급 → 행동 결과 가중치. 전투·설득·관찰·돌봄 모두 |
| — | Evaluator | `evaluator` | 등급을 판정하는 에이전트. Stage 0의 유일한 LLM 호출 |
| — | 루브릭 / 예시셋 | — | Evaluator 판정 기준 + few-shot. 절반 이상 비전투 |

## 4. 책과 공유

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 내 책 | 내 책 | `book`, `book_pages` | 아이 개인의 책. Stage 0은 카드 페이지, Stage 1은 챕터 페이지. **"앨범"은 폐기된 이름** |
| (페이지) | 책 페이지 | `page` | 삽화 + 아이 원문 + 페이지 번호. 문장은 **원문 그대로**, AI 보정 없음 |
| 부모님께 보내기 | 책 내보내기 / PDF | `book_export` | Stage 1 A-7. 학부모 계정에서 다운로드 |
| 서재 | 공유 서재 | `library` | P1 S-1. 완성한 책을 **모든 사용자**에게 공개하는 공간. "내 책"과 다르다 |
| 칭찬 스티커 / 별점 | 정형 반응 | `reaction` | 서재의 유일한 피드백 수단. 자유 댓글 없음. 세션 안에서만 표시, 푸시 없음 |
| 다음 편 | 연재 / 시즌 | `series` | P1 S-2. 별점·완독 성취 → 다음 시즌 오픈 |
| — | 원문 | `text` | 아이가 쓴 문장 그 자체. **로그가 아니라 창작물** — 책 콘텐츠로 보관, 로그·APM 미기록, 라벨링 활용만 동의 |

## 5. 시간과 제한

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| "오늘의 모험 끝" / "내일 또 보자" | 하드 피니시 | `hard_finish`, `locked` | 세션 종료 후 당일 잠금. 자동 재생·무한 스크롤 없음 |
| 오늘 남은 카드 | 일일 카드 제한 | `daily_cap` (Stage 0) | 하루 5장. 재시도·되묻기 미소모 |
| — | 일일 턴 상한 | `daily_cap` (Stage 1) | 하루 15턴. 연습 모드 카드와 카운터 공유 |
| (없음) | 자정 해제 | `resets_at` | 기기 로컬 자정. 클라이언트 타임존 헤더로 서버가 계산 |

## 6. 모드와 단계

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 나침반 퀘스트 | Stage 0 | `stage0` | 파일럿 1용 슬라이스. 카드 20장, 하루 5장. **"연습"이라고 부르지 않는다** |
| 나침반 깨우기 | 튜토리얼 | `tutorial`, `T1~T3` | Stage 1 이후 신규 사용자 첫 5~7분. 카드 3장, 잠금 없음, 관문 없음 |
| 나침반 연습 | 연습 모드 | `practice` | Stage 1 이후 기존 사용자 선택 모드. Stage 0 루프 그대로. (내부 용어에만 "연습"을 허용하고 아이 화면에서는 "나침반 연습"으로만 쓴다) |
| 모험 | Stage 1 / TRPG | `stage1` | 본편. GM 서사·상태·챕터·하드 피니시 |
| — | 파일럿 1 / 2 | — | Stage 0 / Stage 1 각각의 2주 검증. N≈10~30, 남녀 50:50 |
| — | P0-a / P0-b / P1 / P2 | — | 백로그 우선순위. P0-a=Stage 0, P0-b=Stage 1 |

## 7. 안전

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| "나침반이 그 말은 못 알아듣네" | 차단 | `outcome: blocked` | Moderation·PII 차단. **카테고리·사유를 아이에게 말하지 않는다.** 턴 미소모 |
| `[보안 필터]` | PII 마스킹 | `pii_masked` | 실명·학교·주소·연락처. 클라이언트 1차 + 서버 2차 |
| — | 입출력 양방향 Moderation | `moderation_blocked: in\|out` | 아이 입력과 AI 출력(서사·이미지 프롬프트) 모두 검사 |
| — | 화이트리스트 / 블랙리스트 | — | `안전_어휘_기준.md`. 판타지 전투 허용 어휘 / 차단 카테고리 |
| — | 안전망 | `S-0` | 서재를 열기 전에 먼저 만드는 공유 안전 장치 일체 |

## 8. 쓰지 않는 말 (폐기·금지)

| 말 | 이유 | 대신 |
|---|---|---|
| AI 퀘스트 메이커 | 초기 작업명. AI를 앞세움 | 글모험 |
| 보스 | 전투 편향 | 시련 |
| 앨범 | 책 개념 도입 전 이름 | 내 책 |
| 연습하기 / 학습 / 채점 / 점수 (아이 화면) | 학습지 어감. 비전 5장 | 퀘스트 / 나침반 / 티어 |
| 성공률 | 전투 판정 어감 | 행동 결과 |
| "부족해" / "다시 써" / "틀렸어" / "더 길게" (GM 대사) | 부정어. 글쓰기 울렁증 | 질문 형식 되묻기 |
| 유저 / 회원 (아이 화면) | 서비스 냄새 | 탐험가 |

## 9. 운영 규칙
- 새 용어가 필요하면 **먼저 이 문서에 등록**하고 코드 식별자까지 정한 뒤 구현한다
- 아이 화면 문구는 이 표의 "아이 화면" 열과 GM 대사 세트(PRD C-1)에서만 가져온다
- PR 리뷰에서 열을 넘은 용어(예: 화면에 "등급")가 보이면 리뷰 코멘트가 아니라 **차단 사유**다
- 이 문서는 `docs/` 소유자(PM)가 관리하되, 등록 요청은 누구나 PR로
