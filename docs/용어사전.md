# 글모험 용어 사전 (Ubiquitous Language)

> 기획·디자인·코드·대화에서 **같은 것은 같은 말로** 부른다. 이 표에 없는 말로 요청이 오면 먼저 여기에 등록한다.
> 세 열을 구분한다 — **아이 화면**(UI·캐릭터 대사에 쓰는 말) / **내부 용어**(문서·회의·PR에서 쓰는 말) / **코드 식별자**(API·DB·이벤트명). 열을 넘어 섞어 쓰지 않는다. 특히 **내부 용어를 아이 화면에 노출하지 않는다.**

## 1. 사람과 역할

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 탐험가 | 아동 / 학생 / 플레이어 | `child` | 만 10~12세 사용자. 캐릭터는 항상 "탐험가"라고 부른다 |
| (이름은 아이가 지음, 기본 "나침이") | GM 캐릭터 / 가이드 | `guide` | 래서판다 탐험가-학자. Game Master 에이전트의 얼굴. 퀘스트 밖 대화 없음 |
| 부모님 | 학부모 / 보호자 | `parent` | 계정 생성·동의·결제 주체. 관찰자. 대시보드는 P1 |
| — | 운영자 | — | 파일럿 기간 온보딩·로그 확인. UI 없음 |
| — | 플레이 원형 A / B | `archetype: action\|narrative` | A 행동·성취 지향(이민준), B 서사·관계 지향(김서윤). 성별 구분이 아님 |
| 문장술사 | 최상위 칭호 | `title: spellwright` | 전설 티어 누적·연재 작가 등록 시 부여. 서재에 "문장술사 ○○의 책" |
| **지은이** | **작가명** | `author` | **아이 책 표지에 찍히는 이름** (2026-09-10 대표 판정). 값은 `children.nickname` 을 그대로 쓴다 — **별도 컬럼이 아니다.** **중복을 막지 않는다**<br>**「작가」를 아이 화면에 쓰지 않는다** — 위 「문장술사」 줄의 **연재 작가 등록**(P1)과 같은 말이 된다. 그건 **칭호를 받는 것**이고 이건 **모든 아이의 책에 늘 있는 것**이라 뜻이 다르다. 책 표지의 말은 **「지은이」**다<br>**내부에서 「작가명」이라 부르는 것은 대표가 그 말로 제안했기 때문**이고, 화면에는 안 나간다 |

## 2. 플레이 단위

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| 장면 / 카드 | 장면 카드 | `card` | Stage 0의 단위. 스케치 삽화 + 한 줄 상황 + 명사 태그. 서사 연결 없음 |
| — | 카드 식별자 | `card_id` = `c01`~`c20`, 튜토리얼은 `t1`~`t3` | **`c` + 2자리.** `장면카드_초안.md` 표 첫 열(`#`)은 **목록 번호이지 식별자가 아니다.** 계약(`api/Stage0.md`)·DB·프론트 타입은 전부 `c01` 표기를 쓴다 |
| (버튼: "다시 써보기") | 시도 / 재시도 | `attempt`, `retry_of` | 카드 1장에 대한 입력 1회. 재시도는 일일 카운트 미소모 |
| 오늘의 모험 | 세션 | `session` | 접속~종료 화면까지. Stage 0은 카드 5장, Stage 1은 챕터 1개 |
| 모험 / 이야기 | 챕터 | `chapter` | Stage 1의 단위. 8~12턴, 15~20분. 도입-위기-**시련**-완결 |
| — | 턴 | `turn` | 챕터 안의 입력 1회. 선택지 클릭도 턴 |
| (서사 속에서만 등장) | 시련 | `trial` | 챕터의 고비. **"보스"라고 부르지 않는다.** 힘·설득·관찰·돌봄 4경로로 통과 |
| — | 4경로 | `trial_path: force\|persuade\|observe\|care` | 시련 통과 방식. 경로에 따른 보상 차별 없음 |
| — | 뼈대 | `beat_sheet` | 챕터의 사전 작성 구조. GM은 이 위에서 생성 |

## 3. 평가와 보상

| 아이 화면 | 내부 용어 | 코드 | 정의 |
|---|---|---|---|
| **(절대 노출 안 함)** | 등급 | `grade: G0\|G1\|G2\|G3` | Evaluator 판정. 로그·내부 전용. **화면·API 응답에 넣지 않는다** |
| 기본 / 희귀 / 전설 | 티어 | `tier: basic\|rare\|legendary` | 아이가 보는 삽화 품질 단계. G0·G1→기본, G2→희귀, G3→전설 |
| (화면 문장 없음) | 묘사어 하이라이트 | `highlights` | Evaluator가 감지한 형용사·부사·절. 입력문 위에 표시. **2026-09-08 정정 — 이 자리에 「이 단어들이 나침반을 움직였어」가 적혀 있었는데 그건 개념 설명이지 화면에 나가는 문장이 아니다.** 어느 말이 통했는지는 **`guide.line` 이 말한다**(「'살금살금'이 나침반을 움직였어!」). **한 줄 더 두면 같은 말이 두 목소리로 겹친다** — 하이라이트는 **덧칠만 하고 말을 얹지 않는다** (`문구.md` 1.9) |
| 나침반이 밝아진다 / 흐려진다 | 나침반 반응 | `guide.expression: compass_bright\|compass_dim` | 등급의 시각적 표현. 나침반은 **아이 문장에만 반응**한다는 세계관 장치 |
| (질문으로만 등장) | 되묻기 = 스캐폴딩 | `scaffold` | G0 시 GM이 질문 1개로 되묻는 것. 턴 미소모, 최대 2회. **부정어 금지** |
| 스킬 보너스 | 스킬 보너스 | `bonus` | Stage 1. 등급 → 행동 결과 가중치. 전투·설득·관찰·돌봄 모두 |
| — | Evaluator | `evaluator` | 등급을 판정하는 에이전트. Stage 0의 유일한 LLM 호출 |
| — | 루브릭 / 예시셋 | — | Evaluator 판정 기준 + few-shot. 절반 이상 비전투 |

## 9. 운영 규칙
- 새 용어가 필요하면 **먼저 이 문서에 등록**하고 코드 식별자까지 정한 뒤 구현한다
- 아이 화면 문구는 이 표의 "아이 화면" 열과 GM 대사 세트(PRD C-1)에서만 가져온다
- **낱말은 이 사전, 문장은 `문구.md` 다.** 화면에 그대로 나가는 말은 거기가 SSOT 이고 코드가 따라온다 — **목소리 규칙**(가이드 반말 / 앱 존댓말 / 겹치면 `guide.line` 만)도 그 문서 0장에 있다
- **학부모 화면 문구는 전문 용어를 쓰지 않는다.** 정책은 「숨기지 않고 고지한다」고 했지(`페인_가이드라인정책.md` 2.3) **「전문 용어로 고지한다」고 하지 않았다** — **읽어도 모르면 고지가 아니라 알리바이다.** PRD·ADR 문장을 그대로 옮기지 않는다 (✗ 「Google Gemini API 로 전송」). **아이 화면 열의 어휘도 여기서는 쓰지 않는다** — 학부모는 탐험가가 아니라 계정·동의·결제 주체다 (1장). 2026-09-07 학부모 동의 화면(E-4)에서 대표가 잡아 확정
- 커밋 전 `git diff` 검토에서 열을 넘은 용어(예: 화면에 "등급")가 보이면 **커밋을 멈춘다.** PR이 없으므로 이것이 유일한 관문이다 (`작업흐름.md` 5장)
- 이 문서는 **PM 모자**가 관리한다. 다른 모자 세션(`api/`·`web/`)에서 고치지 않고, 필요하면 PM 세션에 넘긴다

## 10. 백로그 코드 — 사람에게 말할 때

`A0-2`·`F-2` 같은 것은 **문서끼리 연결하려고 붙인 색인 번호**다. 아이 화면 / 내부 용어 / 코드 식별자 어디에도 속하지 않는다.

**대화에서는 사람 말을 앞세우고 코드는 괄호로 붙인다.** 코드를 앞세우면 듣는 쪽이 매번 백로그를 열어야 한다.

> ✓ "**랜딩페이지**(백로그 F-2)가 막혀 있습니다"

### 「Fake Door」가 그냥 랜딩페이지와 다른 점

**F-2를 「랜딩페이지」라고만 부르면 만들 때 목적이 사라진다.** 보통 랜딩페이지는 *이미 있는 제품*을 팔지만, 이건 **아직 없는 제품의 문만 만들어 놓고 몇 명이 두드리는지 세는 실험**이다. 그래서 화면 목업·가격 2안·이벤트 4종이 붙어 있고, 합격선이 있다 (`검증가설_성공지표.md` 2.3).

| 재는 것 | 합격선 | 무엇을 아나 |
|---|---|---|
| 방문 → 사전 가입 | 5% 이상 | 관심이 있나 |
| 가입자 중 「주간 리포트 받기」 | 50% 이상 | 학부모 대시보드가 값어치가 있나 |
| 가입자 중 가격 클릭 | 30% 이상 | 돈 낼 생각이 있나 |

**마케팅이 아니라 측정 도구다.** 가설 H5(결제)를 검증한다.
