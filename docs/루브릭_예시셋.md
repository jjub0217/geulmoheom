# 묘사 평가 루브릭 예시셋 (백로그 B-2)

작성일: 2026-09-07 · 대상: `MVP_PRD.md` 4.3 루브릭 · 주차: W2
**루브릭 본문은 `MVP_PRD.md` 4.3절이다. 이 문서는 그 루브릭의 few-shot 예시셋이다** — 루브릭과 어긋나면 4.3절이 맞다.

## 이 문서를 어떻게 쓰나

- **Evaluator 프롬프트에 few-shot으로 상시 포함된다.** 매 호출마다 LLM 프로바이더로 전송된다
- 그래서 **전부 창작 문장이다. 실제 아이 문장은 단 한 개도 넣지 않는다.** 라벨링 동의(`parents.labeling_consent`)는 「보관된 원문을 운영자가 라벨링에 쓰는 것」에 대한 동의이지 **그 문장이 매 호출 제3자에게 전송되는 것**에 대한 동의가 아니다. 층위가 다르다 (PRD 1.1b v4 · B-2)
- 파일럿 1주차의 실제 입력으로 하는 것은 **루브릭 재조정**이지 예시셋 교체가 아니다

## 만든 규칙

| | |
|---|---|
| 개수 | **등급별 10개 · 총 40개** |
| 눈높이 | 만 10~12세가 실제로 쓸 법한 문장. 어른 문체 금지 |
| **비전투 비율** | **각 등급 절반 이상**(실제로는 7~8개). 전투 묘사만 높은 등급을 받는 편향을 막는다 — 비전 3장 원칙 ④, 페르소나 3.5의 두 원형 |
| 장면 | 전부 `장면카드_초안.md`의 실제 카드에 붙였다. 카드 번호를 적어 둔다 |
| `signals` | 판정 근거 태그. 출력 형식은 `{grade, signals, descriptors}` (4.3절) |

**「비전투」는 싸우지 않는 답 전부**다 — 설득·관찰·돌봄·감정·회피. 「전투」는 힘으로 밀어붙이는 답이다.

행동 + 방법 + 감각·감정·의도 중 **2개 이상**. 묘사어 3개 이상, 복문, 이유·감정 포함. **장면이 그려진다.** 삽화는 「전설」 티어.

| # | 카드 | 입력 | 유형 |
|---|---|---|---|
| 1 | 01 그림자 | 나뭇가지 부러지는 소리에 심장이 쿵 내려앉았지만, 나는 숨을 죽인 채 안개 속으로 천천히 손을 뻗어 그림자가 무엇인지 확인해 본다 | 비전투 |

## 판정 경계 — 헷갈리는 지점

예시셋만으로는 안 잡히는 것들이다. **프롬프트에 규칙으로 함께 넣는다.**

| 상황 | 판정 |
|---|---|
| 긴 단답 (`싸운다`×4) | **G0.** 길이는 보조 신호다 |
| 초5 수준 오타·띄어쓰기 (`살금 살금`, `무서웠지만`) | **감점 없음.** 맞춤법·문법은 평가하지 않는다 |
| 뼈대를 벗어난 창의적 입력 (`갑자기 우주선을 탄다`) | **등급대로 판정한다.** 이탈을 이유로 낮추지 않는다 — 흡수는 서사의 몫 |
| 형용사는 많은데 행동이 없음 (`안개가 자욱하고 무서운 숲이다`) | **G0.** 행동이 없으면 묘사가 아무리 많아도 대행/단답이다 |
| 행동 2개 + 묘사 0개 (`문을 열고 들어간다`) | **G1.** 행동 개수는 등급을 올리지 않는다 |
| 감정만 (`너무 무서워`) | **G0.** 행동 없음 |
| 감정 + 행동 + 방법 (G3 2번) | **G3.** 감정은 그 자체로 등급을 올리지 않고 **행동에 붙었을 때** 올린다 |

## 일치율 측정 (PRD 8장 W2 검증 · 합격선 80%)

1. 위 40개를 Evaluator에 넣고 판정을 받는다
2. 이 문서의 등급과 대조해 일치 개수를 센다
3. **80% 미만이면 모델이 아니라 루브릭·예시셋을 먼저 의심한다** — 예시셋이 루브릭과 어긋나 있으면 어떤 모델도 못 맞춘다
4. 등급별로 나눠 본다. **인접 등급 오판(G2↔G3)과 건너뛴 오판(G0↔G2)은 무게가 다르다** — 후자가 나오면 루브릭 자체가 흔들린 것이다
5. **비전투 문장의 일치율을 따로 센다.** 전체는 넘는데 비전투만 낮으면 그것이 곧 전투 편향이고, 이 예시셋이 막으려던 실패다

**측정 결과는 `adr/0005`에 기록한다** — 모델 확정의 근거가 된다.
