## 3단계는 공정한 비교가 아니었다

**기존 세트에는 「나침반이 흐려질 때」 그림이 사실상 없다.** 1번(조용)과 5번(흐려짐)을 픽셀로 비교하면 **평균 차이 2.6/255** — 눈으로는 같은 그림이다. 신규 2번과 6번은 **15.2**로 확연히 다르다.

즉 3단계에서 아이들은 **「기본 얼굴 vs 시무룩한 얼굴」**을 고른 것이다. 기본 얼굴이 이기는 것은 당연하다. **상태 비교로는 성립하지 않고, 얼굴 선호로만 읽어야 한다.**

**이것이 오히려 신규를 채택해야 하는 기능적 근거다.** 되묻기 화면은 "나침반이 흐려졌다"는 신호로 아이에게 한 번 더 쓰라고 말한다. 기존 세트로는 **그 신호가 화면에서 구분되지 않는다.**

**1차와 완전히 같은 갈래다.** 장비를 근거로 든 표는 두 번 다 100% 신규, 얼굴을 근거로 든 표는 두 번 다 100% 기존이다.

**더 중요한 것 — 아이마다 「보는 축」이 고정돼 있다.** A·C 는 두 번 다 장비를 봤고, B·D 는 두 번 다 얼굴을 봤다. **4명 × 2회 = 8표 전부 자기 축을 유지했다.** B 는 1차와 2차에 **거의 같은 문장**을 말했다("얼굴이 동글동글" · "털이 복슬복슬").

**되돌리기는 물리적으로는 갔다.** 1판 → 2판에서 채도 0.523 → 0.569, 명도 0.563 → 0.646 으로 **더 밝고 선명해졌다**(백엔드가 의도한 방향). **그런데도 표가 한 장도 안 움직였다.**

## 판정 — 2판을 정본으로 확정한다. 얼굴 축은 W4 로 넘긴다

**① C-2 완료 조건은 못 넘겼다. 그대로 적는다.** 조건이 「신규 선호 확인」인데 1차 6:6, 2차 2:2 다. **두 번 다 확인되지 않았다.**

**② 그런데 기존은 애초에 후보가 아니었다.** 기존 세트는 「조용할 때」와 「흐려질 때」의 픽셀 평균 차이가 **2.6/255** — 눈으로 같은 그림이다. **네 상태를 표현하지 못한다.** 되묻기 화면이 "나침반이 흐려졌다"로 말을 거는데 그림이 안 바뀐다. **비교 대상이 될 수 없는 것을 비교하고 있었다.**

**③ 그래서 확정하되, 「이겼다」고 적지 않는다.** 정본은 2판이다. 근거는 선호가 아니라 **기능(상태 구분)과 장비**다 — 장비는 8표 중 신규 근거의 전부이고, 아이 절반이 그것으로 골랐다.

**④ 3판은 만들지 않는다.** 두 판을 실제로 밝게 밀었는데 표가 하나도 안 움직였다. 같은 방향으로 한 번 더 미는 것은 **같은 결과를 한 번 더 사는 것**이다.

**⑤ 남은 얼굴 축은 W4 화풍(B-5)으로 이관한다.** 삽화 화풍을 정할 때 **같은 문제가 그대로 온다** — 셀셰이딩이냐 부드러운 톤이냐. 캐릭터만 따로 고치면 삽화와 또 갈린다. **거기서 한 번에 정한다.**

**⑥ 기존 파일은 그때까지 남긴다.** 지우지 않는다.

## 발견 — 제품 설계에 쓸 것

- **아이는 그림에서 보는 것이 서로 다르고, 그게 바뀌지 않는다.** 한쪽은 **무엇을 할 수 있는 캐릭터인가**(장비·역할)를 보고, 다른 쪽은 **어떤 느낌인가**(얼굴·표정)를 본다. 8표 전부 일관했다
- **이 갈래가 성별과 겹쳤다** — 남아 둘이 장비, 여아 둘이 얼굴. **n=4 다. 단정하지 않는다.** 다만 페르소나 두 원형(행동·성취 / 서사·관계)이 갈리는 자리와 같은 방향이라, **파일럿 1의 「성별·플레이 원형별 H2 분리」에서 다시 본다**
- **D 가 「나침반도 잘 보여서 뭘 하려는 친구인지 바로 알 것 같다」고 했다.** 기존 `default` 는 나침반이 파랗게 빛난다. 우리는 **「조용할 때」의 나침반은 조용해야 한다**는 이유로 2판 후보 1 을 골랐는데, 아이 눈에는 **잘 보이는 나침반이 캐릭터를 설명해 준다.** W4 화풍에서 **「조용하되 눈에 띄게」**를 풀어야 한다
