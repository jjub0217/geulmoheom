### 11-4. 자정 기준 — 일일 상한 리셋 · **W3** (A0-5 구현 시점)

제안: 클라이언트 타임존 헤더(`X-Timezone`), 서버 계산 (2절 참조)

- 일일 상한은 **MVP 필수 가드레일**이다. 클라이언트가 보낸 타임존을 그대로 믿으면 **헤더를 바꿔 상한을 우회**할 수 있다
- 대안: 서버 KST 고정 / 자녀 생성 시점에 타임존을 확정해 저장 후 변경 불가
- 밤 11시 50분에 시작한 세션이 자정을 넘길 때의 처리도 함께 정한다
- **학부모 화면의 「오늘 썼어요」도 같은 경계를 본다** (2026-09-08 추가). `card_store.오늘시작()` 한 자리로 모았다 — **갈라지면 「오늘 했다는데 카드가 안 준다」가 된다.** **이 미결을 정할 때 학부모 화면도 같이 움직여야 한다** — 아이 쪽만 자녀 타임존으로 옮기면 **그날 두 화면이 다른 하루를 센다**

## 이미 합의된 것

| 항목 | 합의 |
|---|---|
| 삽화 도착 통지 | 폴링. 첫 폴링 3초 뒤 · 2초 간격 · 15초 타임아웃 · `failed`면 즉시 중단. **SSE는 Stage 0에서 안 만든다.** `Stage0.md` 5절 |
| web 배포 형태·도메인 | 정적 빌드 + Cloudflare Pages + api를 web과 같은 등록가능 도메인 아래. `adr/0007` · `공통규약.md` 「배포 형태와 오리진」 |
| 캐릭터 대사·표정 | 서버가 `guide` 객체로 내려준다. 프론트는 `expression` → PNG 매핑만 (`docs/캐릭터/표정/` 4종). **제출 전 상태는 프론트가 정하되 표정 4종을 쓰지 않는다** — `Stage0.md` 3절 |
| **삽화 URL 접근 (11-7)** | **api 가 프록시한다. 버킷은 비공개다** (2026-09-08 대표 판정). `GET /artworks/{id}/image` 가 **쿠키 인증 뒤에** 저장소에서 읽어 돌려준다 — **이미 있는 인증을 그대로 쓰고 `private` 이 이름이 아니라 실제가 된다.** 난수 키 방식은 **「아무도 URL 을 모른다」에 기대는데 그건 우리가 통제하지 못하는 가정**이라 탈락. **규모가 커지면 서명 URL 로 옮긴다 — 파일럿 뒤에 다시 본다.** 계약은 `Stage0.md` 5절 |
| **서버 2차 NER 의 범위 (11-6)** | **실명만 NER 로 검사한다. 학교명은 서버 정규식에 맡긴다** (2026-09-08 대표 판정). 근거: 학교명은 **정규식이 결정적으로 잡는데 NER 은 두 번 중 한 번 놓쳤다** — 중복이면서 불안정하다. 비용은 파일럿 30명 **$0.19**(현행 +6.7%)로 판정 요인이 아니었다. **자녀 닉네임·가이드 이름 화이트리스트를 함께 붙인다.** **정확도는 아직 안 쟀다** — 붙인 뒤 시나리오로 따로 잰다. 실측 `api/benchmarks/W3-ner-cost.md` |
| **서버 2차 PII 감지 시 (11-5)** | **가리고 진행한다. 막지 않는다** (2026-09-08 대표 판정). 뒤집은 것이 아니라 **`Stage0.md` 9절의 어긋난 한 줄을 맞춘 것** — PRD E-2 는 처음부터 「마스킹 후 처리」였고 클라이언트 층은 2026-09-07 대표 판정으로 이미 「가리되 막지 않는다」였다. **`○○○` 가 책에 인쇄되는 것을 함께 받아들였다.** 차단 응답의 `reason` 에서 `pii` 를 뺐다 — `Stage0.md` 4절 (c)·9절 3번 |
| 토큰 저장 위치 (11-2) | **HttpOnly 쿠키** `__Host-gm_parent` / `__Host-gm_child` · `Lax` · `Path=/` · `Domain` 미부착. 토큰은 응답 body에 없다. JWT 절대 30일 + 쿠키 슬라이딩, 폐기는 `children.token_version`. `공통규약.md` 「인증 쿠키」 |

**11-2에서 갈라져 나온, 여기서 끝나지 않는 것 셋** — 미결이 아니라 **후속 작업**이다. 담당 문서가 정해져 있다.
