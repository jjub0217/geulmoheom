# 아직 정하지 않은 것

**결정할 때 무엇을 고려하는지**를 담는다. 결정이 나면 이 문서에서 지우고 `Stage0.md` 또는 `공통규약.md` 본문에 반영한다.
**언제 정하는지는 `docs/주차계획/`이 정한다** — 여기를 보고 스스로 골라 착수하지 않는다.

**이 문서가 줄어드는 것이 곧 진척이다.**

### 11-4. 자정 기준 — 일일 상한 리셋 · **W3** (A0-5 구현 시점)

제안: 클라이언트 타임존 헤더(`X-Timezone`), 서버 계산 (2절 참조)

- 일일 상한은 **MVP 필수 가드레일**이다. 클라이언트가 보낸 타임존을 그대로 믿으면 **헤더를 바꿔 상한을 우회**할 수 있다
- 대안: 서버 KST 고정 / 자녀 생성 시점에 타임존을 확정해 저장 후 변경 불가
- 밤 11시 50분에 시작한 세션이 자정을 넘길 때의 처리도 함께 정한다

## 이미 합의된 것

| 항목 | 합의 |
|---|---|
| 삽화 도착 통지 | 폴링. 첫 폴링 3초 뒤 · 2초 간격 · 15초 타임아웃 · `failed`면 즉시 중단. **SSE는 Stage 0에서 안 만든다.** `Stage0.md` 5절 |
| web 배포 형태·도메인 | 정적 빌드 + Cloudflare Pages + api를 web과 같은 등록가능 도메인 아래. `adr/0007` · `공통규약.md` 「배포 형태와 오리진」 |
| 캐릭터 대사·표정 | 서버가 `guide` 객체로 내려준다. 프론트는 `expression` → PNG 매핑만 (`docs/캐릭터/표정/` 4종). **제출 전 상태는 프론트가 정하되 표정 4종을 쓰지 않는다** — `Stage0.md` 3절 |
| 토큰 저장 위치 (11-2) | **HttpOnly 쿠키** `__Host-gm_parent` / `__Host-gm_child` · `Lax` · `Path=/` · `Domain` 미부착. 토큰은 응답 body에 없다. JWT 절대 30일 + 쿠키 슬라이딩, 폐기는 `children.token_version`. `공통규약.md` 「인증 쿠키」 |

**11-2에서 갈라져 나온, 여기서 끝나지 않는 것 셋** — 미결이 아니라 **후속 작업**이다. 담당 문서가 정해져 있다.

| 무엇 | 어디로 | 언제 |
|---|---|---|
| `app.`/`api.` IP 대역 실측 (`dig`, IPv4 ≥16비트 공유) — **30일 성패가 여기 달렸다** | 배포 후 백엔드 | 도메인 등록 이후 |
