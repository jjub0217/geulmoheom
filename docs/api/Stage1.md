## 1. 챕터 — 시작과 이어하기

### `POST /chapters` → 챕터를 연다

**요청 본문 없음.** 아이 쿠키로 누구인지 안다.

**⛔ 하루에 한 챕터다** (D-1 하드 피니시). 이미 오늘 완결했으면 **`409 CHAPTER_DONE_TODAY`**.
**진행 중인 챕터가 있으면 새로 안 연다** — 그것을 돌려준다. **⭐ 아이가 새로고침해도 이야기를 잃지 않는다.**

```json
{
  "chapter_id": "uuid",
  "chapter_key": "ch01",
  "turn": 0,
  "beat": "intro",
  "narrative": "…GM 도입 서사 150~300자…",
  "choices": [{ "id": "c1", "label": "…" }, { "id": "c2", "label": "…" }],
  "state": { "hero": {...}, "location": "…" },
  "turns_left": 12,
  "artwork": { "id": "uuid", "status": "pending", "url": null }
}
```

**`state` 는 PRD 4.2 의 부분집합만 나간다** — **`summary`·`recent_turns`·`grades` 는 안 나간다.**
**⛔ 이유가 둘이다** — ① **`recent_turns` 에 아이 원문이 들어 있고 그건 책 콘텐츠지 화면 상태가 아니다**(PRD 1.1b) ② **`grades` 를 내보내면 화면이 그것을 점수로 그리게 된다**(금지어).

### `GET /chapters/current` → 지금 상태

**진행 중인 챕터가 없으면 `404 NO_ACTIVE_CHAPTER`.** 응답 모양은 위와 같다.

## 2. 턴 — 선택지든 자유 묘사든 한 자리로 받는다

### `POST /turns`

```json
{ "chapter_id": "uuid", "choice_id": "c1" }
```
또는
```json
{ "chapter_id": "uuid", "text": "은빛 검을 들고 괴물의 다리를 재빨리 벤다" }
```

**⛔ 둘 중 정확히 하나다.** 둘 다 오면 `422`, 둘 다 없어도 `422`.
**⭐ 엔드포인트를 안 가른다** — **가르면 화면이 두 갈래를 따로 그리게 되고, A-3 이 「선택지와 자유 묘사를 한 입력창에」로 쓰여 있다.**

**⚠ `choice_id` 로 온 턴도 등급이 매겨진다** — **선택지 라벨을 그 아이의 입력으로 평가한다.**
**⛔ 그래야 「고르기만 해도 된다」가 안 된다** — 선택지는 **막힌 아이의 길**이지 **쓰기를 건너뛰는 길**이 아니다(비전 1장). **다만 G0 스캐폴딩은 안 띄운다** — 고른 것을 되물으면 뜻이 없다.

**서버 처리 순서** (`Stage0.md` 의 `/attempts` 와 같은 뼈대다)

1. **입력 Moderation** → 차단이면 `422 UNSAFE_INPUT`, **평가·GM 호출 안 함**
2. **PII 마스킹** — 마스킹된 문장만 프로바이더로 나간다
3. **일일 턴 상한 확인** → 넘으면 `429 TURN_LIMIT` (4절)
4. **Evaluator** → `grade` G0~G3 (PRD 4.3)
5. **G0 이면** 스캐폴딩 질문을 돌려주고 **턴을 안 소모한다** (PRD 4.4 · `Stage0.md` 되묻기와 같다)
6. **GM 호출** — 등급·보너스·뼈대·상태·요약을 실어 (PRD 4.1)
7. **⛔ GM 출력 Moderation** — 차단이면 **한 번만 다시 부르고**, 또 차단이면 `502 GM_UNSAFE`
8. **상태 추출기** — GM 출력에서 체력·아이템·위치 변화를 뽑는다 (**GM 호출과 분리**, PRD A-2)
9. **요약기** — 최근 3턴은 원문, 그 이전은 3~4문장 (PRD A-2)
10. **`is_key_scene` 이면 삽화를 굽는다** — `Stage0.md` 5절 그대로
11. **턴 로그** — **⛔ 아이 원문은 로그에 안 남는다**(PRD 1.1b). 등급·경로·소요만

```json
{
  "turn": 6,
  "beat": "trial",
  "grade": "G2",
  "bonus": 1,
  "scaffold": null,
  "narrative": "…",
  "choices": [...],
  "state": {...},
  "turns_left": 6,
  "artwork": { "id": "uuid", "status": "pending", "url": null },
  "chapter_done": false
}
```

**`scaffold` 가 오면 `narrative` 는 `null` 이고 턴이 안 는다.**

## 3. 시련 — 네 경로가 동등하다

**⛔ 「보스」라는 낱말을 응답·코드·식별자 어디에도 쓰지 않는다** (`용어사전.md` 8장 금지어). **`beat` 값은 `trial` 이다.**

**뼈대마다 네 경로의 해결 조건을 사전 정의한다** (PRD A-4). **GM 이 아이 입력이 어느 경로인지 판별해 그 경로로 전개한다.**

| 경로 | 코드 |
|---|---|
| 힘 | `force` |
| 설득 | `persuade` |
| 관찰 | `observe` |
| 돌봄 | `care` |

**⛔ 경로에 따른 차별이 없다** — **등급·삽화 티어·완결 여부 전부.** **설득으로 넘은 시련도 힘으로 넘은 것과 같은 티어**다(PRD A-4).
**⚠ 이것이 페르소나 2원형(A 이민준 / B 김서윤)이 걸린 자리다.** **한 경로가 더 좋은 그림을 받으면 그 원형이 불리해진다.**

**통과 판정은 등급이 정한다** (PRD A-4) — **G2 이상 1턴 · G1 2턴 · G0 스캐폴딩.**
**응답에 `trial_path` 와 `trial_progress` 가 실린다.** **⛔ 진행도를 숫자로 화면에 그리지 않는다** — 서사로 말한다.

## 4. 일일 턴 상한 (D-2)

**`A0-5` 의 확장이다. 새 장치를 만들지 않는다.**

- **한 챕터 8~12턴** (PRD A-4). **`turns_left` 가 매 응답에 실린다**
- 넘으면 **`429 TURN_LIMIT`** — 본문에 `문구.md` 의 잠금 문장
- **⛔ 스캐폴딩(G0)은 턴을 안 먹는다** — 되묻기가 상한을 깎으면 **막힌 아이가 더 빨리 잠긴다**
- **⛔ 재시도로 우회되지 않는다.** **Stage 0 에서 `retry_of` 가 상한을 안 보던 구멍**(`attempts.py`)이 열려 있었다 — **여기서 같은 구멍을 내지 않는다.** 검사로 짝지어 세운다

## 5. 완결과 책 (A-4 · D-1 · A-7)

**시련을 넘고 완결 비트에 닿으면 `chapter_done: true`.**

### `GET /chapters/{id}/summary` → 완결 화면

**하드 피니시다** (D-1). **⛔ 「이어서 더 하기」를 응답에 넣지 않는다.** 없는 것이 결정이다(페르소나 7.1).

### 책 — **`A0-4` 가 그대로 받는다**

- **챕터 완결 = 책 한 장.** 기존 `GET /books/…` 에 챕터 쪽이 더해진다
- **⛔ 문장은 아이 원문 그대로. AI 보정 없음**(비전 2장)
- **`GET /books/{id}/pdf`** — 완결본 내보내기. **⚠ 아이 원문·삽화만 들어간다**

## 6. 새 오류 코드 — **넷뿐이다**

| 코드 | 상태 | 언제 |
|---|---|---|
| `NO_ACTIVE_CHAPTER` | 404 | 진행 중인 챕터가 없다 |
| `CHAPTER_DONE_TODAY` | 409 | 오늘 몫을 끝냈다 (하드 피니시) |
| `TURN_LIMIT` | 429 | 턴 상한 |
| `GM_UNSAFE` | 502 | GM 출력이 두 번 차단됐다 |

**나머지는 `공통규약.md` 표 그대로다.** **⛔ 아이 화면에 나가는 문장은 `문구.md` 가 SSOT** — 여기 적힌 코드 이름을 화면에 그리지 않는다.
