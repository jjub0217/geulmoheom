## 1. 챕터 — 시작과 이어하기

### `POST /chapters` → 챕터를 연다

**요청 본문 없음.** 아이 쿠키로 누구인지 안다.

**⛔ 하루에 한 챕터다** (D-1 하드 피니시). 이미 오늘 완결했으면 **`409 CHAPTER_DONE_TODAY`**.
**진행 중인 챕터가 있으면 새로 안 연다** — 그것을 돌려준다. **⭐ 아이가 새로고침해도 이야기를 잃지 않는다.**

```json
{
  "chapter_id": "uuid",
  "chapter_key": "ch01",
  "turn": 0,
  "beat": "intro",
  "narrative": "…GM 도입 서사 150~300자…",
  "choices": [{ "id": "c1", "label": "…" }, { "id": "c2", "label": "…" }],
  "state": { "hero": {...}, "location": "…" },
  "turns_left": 12,
  "artwork": { "id": "uuid", "status": "pending", "url": null }
}
```

**⛔ 명세 변경 (2026-09-16) — `artwork` 는 `null` 일 수 있다** (`ArtworkRef | None`). **백엔드가 제안했고 PM 이 받았다.**
**이어받는 판에는 아직 구운 그림이 없을 수 있다** — 핵심 씬은 **1턴·9턴 둘뿐**이고(`챕터뼈대_초안.md`) **나머지 여덟 턴에는 새 그림이 없다.** **필수로 두면 서버가 없는 것을 지어내야 한다.**
**⚠ 화면은 「없음」을 그릴 수 있어야 한다** — 액자를 비우는 것이 아니라 **직전 핵심 씬 그림을 그대로 두는 쪽**이 맞다. **자리는 프론트 8번.**

**`state` 는 PRD 4.2 의 부분집합만 나간다** — **`summary`·`recent_turns`·`grades` 는 안 나간다.**
**⛔ 이유가 둘이다** — ① **`recent_turns` 에 아이 원문이 들어 있고 그건 책 콘텐츠지 화면 상태가 아니다**(PRD 1.1b) ② **`grades` 를 내보내면 화면이 그것을 점수로 그리게 된다**(금지어).

### `GET /chapters/current` → 지금 상태

**진행 중인 챕터가 없으면 `404 NO_ACTIVE_CHAPTER`.** 응답 모양은 위와 같다.

**⛔ 다만 「오늘 이미 끝냈다」는 404 가 아니라 `409 CHAPTER_DONE_TODAY` 다** (2026-09-16 보강, 백엔드가 짚었다).
**종전 계약은 404 하나뿐이었고, 그러면 끝낸 아이가 「지금 이어갈 이야기가 없어요」를 본다** — **사실은 끝낸 것이고, 화면이 잠금을 그릴 수 없다.** **없는 것과 끝낸 것은 다르다.**

## 2. 턴 — 선택지든 자유 묘사든 한 자리로 받는다

### `POST /turns`

```json
{ "chapter_id": "uuid", "choice_id": "c1" }
```
또는
```json
{ "chapter_id": "uuid", "text": "은빛 검을 들고 괴물의 다리를 재빨리 벤다" }
```

**⛔ 둘 중 정확히 하나다.** 둘 다 오면 `422`, 둘 다 없어도 `422`. **(이건 형식 오류라 진짜 `422` 다 — 위 차단과 다르다.)**
**⭐ 엔드포인트를 안 가른다** — **가르면 화면이 두 갈래를 따로 그리게 되고, A-3 이 「선택지와 자유 묘사를 한 입력창에」로 쓰여 있다.**

**⚠ `choice_id` 로 온 턴도 등급이 매겨진다** — **선택지 라벨을 그 아이의 입력으로 평가한다.**
**⛔ 그래야 「고르기만 해도 된다」가 안 된다** — 선택지는 **막힌 아이의 길**이지 **쓰기를 건너뛰는 길**이 아니다(비전 1장). **다만 G0 스캐폴딩은 안 띄운다** — 고른 것을 되물으면 뜻이 없다.

**서버 처리 순서** (`Stage0.md` 의 `/attempts` 와 같은 뼈대다)

1. **입력 Moderation** (상한 확인 뒤) → **차단이면 오류가 아니라 `200` + 차단 결과**다. **평가·GM 호출 안 함**
   **⛔ 2026-09-16 정정 — PM 이 `422 UNSAFE_INPUT` 으로 적었던 것이 틀렸다.** 백엔드가 **6절(「새 코드는 넷뿐」)과 어긋난다**고 짚어서 봤더니, **어긋난 쪽이 2절이었다.**
   **`Stage0.md` 가 이미 정해 뒀다** — 차단은 **`(c) 차단` 정상 응답**이고 `reason` 은 **`moderation` 하나**다(2026-09-08 대표 판정, `pii` 를 뺐다). **오류 코드가 아니다.**
   **⛔ 그리고 그게 아이에게 중요하다** — `Stage0.md` 148행: **「차단 시 아이가 쓴 문장을 지우지 않는다. 입력창에 그대로 남긴다.** **이유도 모른 채 공들여 쓴 글이 사라지면 그것 자체가 벌로 읽힌다」**(2026-09-07 확정). **422 로 내면 화면이 오류 갈래로 가고 그 규칙이 깨진다.**
   **문구는 1.11 차단 문구**(`guide.line`)다. **새 오류 코드를 만들지 않는다 — 6절의 넷이 맞다.**
2. **PII 마스킹** — 마스킹된 문장만 프로바이더로 나간다
**⛔ 0. 일일 턴 상한 확인이 맨 앞이다** → 넘으면 `429 TURN_LIMIT` (4절)
   **⛔ 2026-09-16 정정 — PM 이 3번째로 적었던 것을 맨 앞으로 옮긴다.** 백엔드가 `/attempts` 와 어긋난다고 짚었고 **그쪽이 맞다.**
   **돈이다** — **뒤에 두면 잠긴 아이 때문에 검사·평가·GM 호출이 나가고 그 결과는 화면에 안 뜬다.** **유료 호출 셋이 버려진다.**
   **그리고 `/attempts` 가 이미 맨 앞에서 본다** — 이 절이 스스로 **「`/attempts` 와 같은 뼈대」**라 불러 놓고 순서를 달리 적었다
4. **Evaluator** → `grade` G0~G3 (PRD 4.3)
5. **G0 이면** 스캐폴딩 질문을 돌려주고 **턴을 안 소모한다** (PRD 4.4 · `Stage0.md` 되묻기와 같다)
6. **GM 호출** — 등급·보너스·뼈대·상태·요약을 실어 (PRD 4.1)
7. **⛔ GM 출력 Moderation** — 차단이면 **한 번만 다시 부르고**, 또 차단이면 `502 GM_UNSAFE`
8. **상태 추출기** — GM 출력에서 체력·아이템·위치 변화를 뽑는다 (**GM 호출과 분리**, PRD A-2)
9. **요약기** — 최근 3턴은 원문, 그 이전은 3~4문장 (PRD A-2)
   **⛔ 매 턴 요약하지 않는다 — 3턴마다 한 번이다** (2026-09-16 사용자 판정 · 돈)
   **PRD 가 매 턴을 요구하지 않는다** — 「최근 3턴은 원문」이 조건이고 **그 밖을 언제 압축하는지는 안 정했다.**
   **⛔ 그런데 「3턴마다」를 순진하게 하면 구멍이 난다.** 요약이 `1..N-3` 만 덮는데 갱신이 밀리면
   **요약에도 없고 원문 3턴에도 없는 턴**이 생긴다.
   **✅ 그래서 요약은 「그 시점까지 전부」를 덮는다** — 갱신 턴 `M`(3의 배수)에서 **`1..M` 전체**를 요약한다.
   원문 창은 **최근 3턴** 그대로.

   | 턴 | 마지막 갱신 `M` | 요약이 덮는 것 | 원문 | 구멍 |
   |---|---|---|---|---|
   | 7 | 6 | `1..6` | 5·6·7 | **없다** (5·6 이 겹칠 뿐) |
   | 8 | 6 | `1..6` | 6·7·8 | **없다** |
   | 9 | 9 | `1..9` | 7·8·9 | **없다** |

   **⭐ 겹치는 것은 해가 없다** — 토큰이 조금 늘 뿐이고 **GM 이 같은 것을 두 번 읽는다고 나빠지지 않는다.**
   **⛔ 구멍은 해가 있다** — 그 턴에 아이가 한 일이 GM 컨텍스트에서 통째로 사라진다.

   **⛔ 상태 추출기는 매 턴 그대로다.** 체력·아이템·위치 **변화를 놓치면 상태가 틀어진다** — 요약과 다르다.

   **돈** — 15턴 기준 요약 호출이 **15회 → 5회**. 아이 한 명 하루 **약 21원 → 약 14원**
   (환율 1달러≈1,400원 대략값).
10. **`is_key_scene` 이면 삽화를 굽는다** — `Stage0.md` 5절 그대로
11. **턴 로그** — **⛔ 아이 원문은 「로그」에 안 남는다**(PRD 1.1b). 로그 이벤트에는 **등급·경로·소요만**
    **⛔ 2026-09-16 — 이 줄이 애매해서 백엔드가 `chapter_turns` 에 원문 칸을 안 만들었다. PM 문장 탓이다.**
    **가르는 선은 「로그냐 책 콘텐츠냐」다** — `api/CLAUDE.md` 가 그 선을 이미 적어 뒀다: **「원문이 가도 되는 곳은 `card_attempts.text` 단 하나다. 그건 로그가 아니라 아이의 책 콘텐츠다.」**
    **✅ Stage 1 턴의 아이 문장도 책 콘텐츠다** — **A-7 이 「챕터 완결 = 책 한 장 · 문장은 아이 원문 그대로, AI 보정 없음」**이다. **책을 세우려면 그 자리가 있어야 한다.**
    **⛔ 여기서 금지되는 것은 `logger`·APM·예외 메시지·오류 리포터**이고 **DB 의 책 콘텐츠 칸이 아니다.**
    **⏳ 다만 `api/CLAUDE.md` 8행이 「단 하나」로 쓰여 있어 한 낱말을 고쳐야 한다** — **그 파일은 사용자가 그 세션에서 직접 말해야 고쳐진다.** **9번(A-7) 착수 전에 필요하다.**

```json
{
  "turn": 6,
  "beat": "trial",
  "scaffold": null,
  "narrative": "…",
  "choices": [...],
  "state": {...},
  "turns_left": 6,
  "artwork": { "id": "uuid", "status": "pending", "url": null },
  "chapter_done": false
}
```

**`scaffold` 가 오면 `narrative` 는 `null` 이고 턴이 안 는다.**

**⛔ 2026-09-16 정정 — `grade` 와 `bonus` 를 응답에서 뺐다. PM 이 적었던 것이 틀렸다.**
**`용어사전.md` 3장이 등급을 「화면·API 응답에 넣지 않는다」로 못 박아 뒀고, Stage 0 가 실제로 그렇게 서 있다** — `/attempts` 는 **`grade → tier` 매핑 뒤 `tier` 만** 내보내고 `grade` 는 `card_attempts` 와 로그에만 있다.
**⛔ `bonus` 가 더 위험하다** — **정수라 화면이 그대로 숫자로 그린다.** 그게 **「점수」**이고 8장 금지어다.
**⭐ 화면이 그것들로 그릴 게 없다** — **서사가 등급을 말하고**(「같은 행동을 G0 과 G3 로 넣으면 결과 서사가 다르다」), **시련 진행은 `trial_progress` 가**, **보상은 삽화 티어가** 말한다. **`용어사전.md` 가 그 셋을 이미 갈라 뒀다.**
**⚠ 등급은 사라지지 않는다** — `chapter_turns.grade` 와 로그 이벤트에 그대로 남는다. **나가는 자리만 막는다.**

## 3. 시련 — 네 경로가 동등하다

**⛔ 「보스」라는 낱말을 응답·코드·식별자 어디에도 쓰지 않는다** (`용어사전.md` 8장 금지어). **`beat` 값은 `trial` 이다.**

**뼈대마다 네 경로의 해결 조건을 사전 정의한다** (PRD A-4). **GM 이 아이 입력이 어느 경로인지 판별해 그 경로로 전개한다.**

| 경로 | 코드 |
|---|---|
| 힘 | `force` |
| 설득 | `persuade` |
| 관찰 | `observe` |
| 돌봄 | `care` |

**⛔ 경로에 따른 차별이 없다** — **등급·삽화 티어·완결 여부 전부.** **설득으로 넘은 시련도 힘으로 넘은 것과 같은 티어**다(PRD A-4).
**⚠ 이것이 페르소나 2원형(A 이민준 / B 김서윤)이 걸린 자리다.** **한 경로가 더 좋은 그림을 받으면 그 원형이 불리해진다.**

**통과 판정은 등급이 정한다** (PRD A-4) — **G2 이상 1턴 · G1 2턴 · G0 스캐폴딩.**
**응답에 `trial_path` 와 `trial_progress` 가 실린다.** **⛔ 진행도를 숫자로 화면에 그리지 않는다** — 서사로 말한다.

## 5. 완결과 책 (A-4 · D-1 · A-7)

**시련을 넘고 완결 비트에 닿으면 `chapter_done: true`.**

**⛔ 12턴에 닿으면 시련을 못 넘었어도 `chapter_done: true` 다** (2026-09-16 PM 판정). **GM 이 서사로 넘겨준다** — `문구.md` **1.24**. **「못 넘었다」로 끝내면 A-7 이 「챕터 완결 = 책 한 장」이라 12턴을 다 쓴 아이만 책이 빈다 — 제일 많이 쓴 아이가 제일 적게 받는다.**
**⛔ 그렇다고 똑같지 않다 — 보상은 등급이 정한다.** 12턴까지 `G1` 만 낸 아이는 **`basic`** 을 받는다. **차이는 삽화 티어에서 나지 완결 여부에서 나지 않는다.**

### `GET /chapters/{id}/summary` → 완결 화면

**하드 피니시다** (D-1). **⛔ 「이어서 더 하기」를 응답에 넣지 않는다.** 없는 것이 결정이다(페르소나 7.1).

### 책 — **`A0-4` 가 그대로 받는다**

- **챕터 완결 = 책 한 장.** 기존 `GET /books/…` 에 챕터 쪽이 더해진다
- **⛔ 문장은 아이 원문 그대로. AI 보정 없음**(비전 2장)
- ~~**`GET /books/{id}/pdf`** — 완결본 내보내기~~ **← ⛔ 2026-09-16 삭제. PM 이 적었던 것이 틀렸다**
  **`백로그.md` A-7 과 `주차계획/W7.md` 9번은 「프론트가 PDF 출력」인데 내가 계약에 서버 엔드포인트를 적었다** — **셋 다 스펙 층이라 층위로 안 갈리고**, 프론트가 **고치지 않고 먼저 알렸다.**
  **✅ 판정 — 프론트가 인쇄로 낸다** (`window.print()` + 인쇄 전용 CSS). **새 엔드포인트가 없다.**
  **근거** — **A-7 이 규모 `S`** 로 쓰여 있고 **서버 굽기(PDF 라이브러리 + 삽화 임베드 + 새 엔드포인트)는 S 가 아니다.** 그리고 **9번은 「덜어낼 2순위」**인데 **거기에 백엔드 일을 새로 얹는 것은 순서에 안 맞는다.**
  **⚠ 아는 값을 적어 둔다 — 「PDF 파일」이 아니라 「인쇄 대화상자」다.** iPad Safari 는 거기서 **「PDF 로 저장」**이 되지만 **부모가 그 한 단계를 해야 한다.** **베타에서 그 한 단계가 막는지 본다.**
  **⛔ 자리는 아이 화면 「내 책」이다** — `용어사전.md` 가 아이 화면 문구를 **「부모님께 보내기」**로 등록해 뒀고 **그건 아이가 누르는 말**이다.
  **⚠ 같은 줄의 「학부모 계정에서 다운로드」는 아직 못 한다 — 학부모 책 화면이 없다**(`web/src/app/parents/` 에 `login`·`signup` 뿐). **그 화면을 만드는 것은 A-7 의 S 규모 밖**이라 미룬다.

## 6. 새 오류 코드 — **넷뿐이다**

| 코드 | 상태 | 언제 |
|---|---|---|
| `NO_ACTIVE_CHAPTER` | 404 | 진행 중인 챕터가 없다 |
| `CHAPTER_DONE_TODAY` | 409 | 오늘 몫을 끝냈다 (하드 피니시) |
| `TURN_LIMIT` | 429 | 턴 상한 |
| `GM_UNSAFE` | 502 | GM 출력이 두 번 차단됐다 |

**✅ 문구는 `문구.md` 2.1 에 내려왔다** (2026-09-16). **⛔ 둘은 `guide.line` 을 같이 싣는다** — `CHAPTER_DONE_TODAY` → **1.20**, `TURN_LIMIT` → **1.10**. `DAILY_CAP_REACHED` 와 같은 모양이다.
**나머지 둘(`NO_ACTIVE_CHAPTER`·`GM_UNSAFE`)은 안 싣는다** — **모험의 흐름이 아니라 고장**이고, **가이드가 고장을 말하기 시작하면 가이드 말이 신호가 아니라 잡음이 된다.**

**⛔ `TURN_LIMIT` 은 `RATE_LIMITED` 문구를 쓰지 않는다** — `문구.md` 2.1 이 **「429 가 두 번째 자리를 얻으면 갈라야 한다」**를 예고해 뒀고 **이것이 그 자리**다. **「15분 뒤에」가 그대로 나가면 아이가 15분 뒤에 눌러 보고 또 막힌다.**

**나머지는 `공통규약.md` 표 그대로다.** **⛔ 아이 화면에 나가는 문장은 `문구.md` 가 SSOT** — 여기 적힌 코드 이름을 화면에 그리지 않는다.
