# 화면 문구

> **이 문서가 SSOT 다. 코드가 따라온다.** 여기 없는 문구를 코드에서 새로 짓지 않는다 — 필요하면 **여기 먼저 등록**하고 구현한다 (`용어사전.md` 9장과 같은 규칙).
>
> **`용어사전.md` 와 층이 다르다.** 사전은 **무엇을 뭐라 부르나**(용어), 여기는 **화면에 그대로 나가는 말**(문장)이다. 문장에 쓰는 낱말은 사전을 따른다.

**작성 2026-09-07 · PM 확정.** 근거: 대표 일정 판정(「대사 세트를 입력 화면·결과 연출과 **같이** 만든다」, `MVP_PRD.md` 8장) — **입력 화면이 2026-09-07 에 섰다.**

## 0. 목소리 — 누가 말하는가

**세 계열이다. 섞지 않는다.**

| 계열 | 말투 | 나가는 자리 | 예 |
|---|---|---|---|
| **가이드** | **반말** | `guide.line` · 클라이언트가 아이에게 주는 즉시 피드백 | 「내일 또 보자」 |
| **앱** | **존댓말** | `error.message` · 버튼 · 라벨 · 상태 표시 | 「오늘 카드를 다 썼어요」 |
| **학부모 화면** | **존댓말 · 전문 용어 없음** | `/parents/*` 전부 | 「아이가 쓴 문장은 구글의 AI(Gemini)로 보내져 평가됩니다.」 |

**한 화면에 가이드와 앱이 같이 나오면 `guide.line` 만 보여준다.**
일일 상한 소진 시 409 응답에 `error.message`(「오늘 카드를 다 썼어요」)와 `guide.line`(「내일 또 보자」)이 **함께 실린다** (`api/Stage0.md` 103행). 결과 연출(A0-3)이 서면 **한 화면에 존댓말과 반말이 나란히 뜬다** — 그때 고르지 않고 여기서 정한다.

**왜 하나로 통일하지 않았나.** 가이드가 서버 오류·권한 오류까지 말하면 **PRD C-1 「역할 경계」**(퀘스트 진행·되묻기·격려·종료 인사만)를 넘는다. 캐릭터가 앱 사정을 아는 존재가 되는 쪽이 **말투가 갈리는 것보다 세계관을 크게 깬다.**

## 1. 아이 화면 — 가이드 목소리 (반말)

### 1.1 개인정보를 가렸을 때 (E-2)

**가림 글자는 `○○○`** — **길이와 무관하게 고정 3자.** 가린 길이를 드러내지 않는다.

| 종류 | 코드 (`PiiKind`) | 문구 |
|---|---|---|
| 전화번호 | `phone` | 전화번호는 안 써도 돼서 가렸어! |
| 메일 주소 | `email` | 메일 주소는 안 써도 돼서 가렸어! |
| 사는 곳 | `address` | 사는 곳은 안 써도 돼서 가렸어! |
| 학교 이름 | `school` | 학교 이름은 안 써도 돼서 가렸어! |

**`[보안 필터]` 에서 2026-09-07 에 바꿨다.** 이유 셋 —
① **「보안 필터」는 만 11세가 몰라도 이상하지 않은 전문 용어**다. 학부모 화면에 세운 기준(`용어사전.md` 9장)을 아이 화면에 돌려도 같은 말이 된다.
② **이 글자는 입력창에만 있는 게 아니라 아이 책에 인쇄된다.** 마스킹된 텍스트가 그대로 책 콘텐츠로 저장되기 때문이다(`api/Stage0.md` 4절). **비전 2장이 「책 문장은 아이 원문 그대로」라고 한 그 책**에 시스템 용어가 박힌다.
③ **아이가 읽고 판단하는 대상이다.** 대표 판정으로 이 글자는 **아이가 지울 수 있는 평범한 글자**로 만들었다 — 그러면 아이는 **지울지 말지를 정해야 한다.** 모르는 말이면 그 판단을 할 수 없다.
`□□` 는 글자 깨짐으로 보이고 `…` 는 말줄임으로 읽혀 탈락시켰다.

**지킬 것 셋**
- **혼내지 않는다.** 「안 돼」가 아니라 **「안 써도 돼」**다 — 아이는 규칙을 어긴 것이 아니다
- **무엇을 가렸는지만 말한다.** 왜 위험한지 설명하지 않는다. 겁주는 순간 아이는 쓰기를 줄인다
- **가린 자리는 아이가 지울 수 있다.** 지워지지 않는 덩어리로 만들지 않는다 (`web/src/lib/pii.ts`)

### 1.2 자해·자살 신호 (E-1)

> **지금 마음이 많이 힘들면, 옆에 있는 어른한테 꼭 말해줘.**

- **한 줄만 말하고 이어 말하지 않는다.** 설득하지 않는다 — 가이드는 상담자가 아니라 게임 마스터다 (`MVP_PRD.md` E-1 「자해·자살 신호 처리」)
- **표정은 일반 차단과 같은 것을 쓴다.** 이 상황을 위한 표정을 새로 만들지 않는다 — 표정이 따로 생기면 아이가 **자기 신호가 특별히 취급됐다는 것을 알아챈다**
- **이 문안을 바꾸는 것은 「대표 몫」이다** (안전 정책). PM 이 다듬지 않는다. 여기 적힌 것은 2026-09-07 대표 판정 문장 그대로다

### 1.3 아직 없는 것 — W4 (A0-3 · C-1)

**일반 차단 문구 · 되묻기 · 결과 대사(`_결과대사`) · 삽화 대기 · 종료 인사**는 **결과 연출(A0-3)과 같이 만든다.** 화면 없이 먼저 쓰면 두 번 손댄다 — 대표 일정 판정이다.

**자해 문구만 먼저 확정한 이유**: 대표 판정으로 **문장이 이미 정해져 있어** 화면을 봐도 달라질 것이 없다.

## 2. 아이 화면 — 앱 목소리 (존댓말)

### 2.1 오류 문구 (`api/app/errors.py` 의 `CHILD_MESSAGE`)

| 코드 | 문구 |
|---|---|
| `UNAUTHORIZED` | 다시 한 번 들어와 주세요 |
| `FORBIDDEN_ROLE` | 여기는 지금 들어갈 수 없어요 |
| `NOT_FOUND` | 찾는 것이 여기 없어요 |
| `VALIDATION_ERROR` | **잠깐 문제가 생겼어요. 다시 한 번 해볼까요** |
| `DAILY_CAP_REACHED` | 오늘 카드를 다 썼어요 |
| `CARD_ALREADY_DONE_TODAY` | 이 장면은 오늘 이미 다녀왔어요 |
| `CONSENT_REQUIRED` | 부모님 확인이 먼저 필요해요 |
| `RATE_LIMITED` | 조금만 천천히 가볼까요 |
| `UPSTREAM_TIMEOUT` | 나침반이 잠깐 느려요. 조금 뒤에 다시 해볼까요 |
| `INTERNAL_ERROR` | 잠깐 문제가 생겼어요. 조금 뒤에 다시 해볼까요 |

**아홉은 잠정본 그대로 확정했고 `VALIDATION_ERROR` 하나만 고쳤다.** 종전 「한 번만 더 확인해 주세요」는 **아이에게 무엇을 확인하라는 것인지 알려주지 않으면서 아이 탓으로 읽힌다.** 422 가 뜨는 실제 경우는 **프론트가 형식을 잘못 보낸 것**이라 아이가 고칠 것이 없다.

**지킬 것**
- **원인을 아이에게 돌리지 않는다.** 금지어(부족해·다시 써·틀렸어·점수·채점) 이전에 **탓하는 구조**를 쓰지 않는다
- **기계용 식별자는 `code` 에만.** `message` 에 코드·필드명·기술 용어가 섞이지 않는다 (`api/공통규약.md` 「오류 형식」)
- **아이 입력 원문을 문구에 되담지 않는다** (PRD 1.1b)

### 2.2 버튼 · 라벨

| 자리 | 문구 |
|---|---|
| 묘사 입력 후 제출 | **보내기** |

**「보내기」를 그대로 확정한다.** 버튼은 **누르면 무슨 일이 일어나는지** 말하는 자리다. 세계관 어휘(「떠나기」·「나침반에 보내기」)를 넣으면 어감은 살지만 **동작이 흐려진다.** 어느 금지어에도 걸리지 않는다.

**확정은 「바꾼다」가 아니라 「이제 잠정이 아니다」다.** 코드에 붙은 「잠정」 주석을 걷어낸다.

## 3. 학부모 화면

**기준은 `용어사전.md` 9장이다** — 전문 용어를 쓰지 않고, **아이 화면 열의 어휘도 쓰지 않는다.** 「탐험가」 같은 말이 나오면 **검증하러 온 학부모**에게 진지함이 깎인다.

### 3.1 동의 화면 고지 (E-4) — 확정본

> 1. 아이가 쓴 문장은 구글의 AI(Gemini)로 보내져 평가됩니다.
> 2. 구글이 이 문장으로 AI를 학습시키지는 않습니다. 다만 나쁘게 쓰이는지 확인하려고 일정 기간 보관합니다.
> 3. 실명·학교 이름·연락처는 보내기 전에 걸러냅니다.

**근거는 `MVP_PRD.md` E-4 MUST 와 `페인_가이드라인정책.md` 2.3 이고 여기서 지어낸 문장이 아니다.**

**왜 이렇게 썼나 — 셋**
- **「API」를 뺐다.** 학부모에게 아무 정보도 주지 않는다. 대신 **「구글」을 앞에 뒀다** — 알아야 할 사실은 **「우리 밖으로, 구글이라는 회사로 간다」**다. 정확한 이름(Gemini)은 괄호로 남긴다. **제3자 위탁 고지라 수탁자명이 있어야 한다**
- **「AI 학습」이라는 명사구를 쓰지 않는다.** 학부모의 핵심 불안이 「AI 가 대신 써준다」라서 **부정문 안에 넣어도 그 단어만 기억에 남는다.** 그래서 「학습시키지는 않습니다」로 **동사형**을 쓴다
- **「남용 탐지」를 풀었다.** 업계 말이라 **누가·무엇을·왜** 하는지로 바꿨다

**화면 규칙 셋** (문구가 아니라 배치지만 같이 지킨다)
- **어느 체크박스도 미리 체크하지 않는다**
- **필수 동의와 라벨링 동의를 하나로 묶지 않는다** (PRD 1.1b). 앞은 거부하면 이용할 수 없고 **뒤는 거부해도 그대로 쓸 수 있다.** 묶으면 **거부할 수 없는 것을 거부할 수 있는 척**하게 된다
- **고지를 링크 뒤에 숨기지 않는다.** 「어디로 가고 얼마나 남는가」는 화면에 문장으로 있다

### 3.2 자녀 인증 화면 — 설치 안내 (E-3)

**목소리는 「앱」(존댓말)이다. 가이드가 말하지 않는다.**
근거 둘 — ① **요구하는 행동이 어른의 것**이다(홈 화면에 추가). ② **가이드는 퀘스트 안에서만 말한다** (`MVP_PRD.md` C-1 「역할 경계」). 아이가 아직 안 들어왔으니 가이드가 말을 걸 자리가 아니다.
**학부모 화면 계열의 기준을 함께 지킨다** (`용어사전.md` 9장) — 전문 용어를 쓰지 않는다.

**브라우저 탭에서 열렸을 때. 코드 입력을 열지 않고 이것만 보여준다** (`api/공통규약.md` 181).

> **홈 화면에 추가한 다음 열어주세요.**
>
> 접속 코드는 한 번만 쓸 수 있어요. 여기서 입력하면 새 코드를 다시 받아야 해요.
>
> **아이폰·아이패드** — 아래 공유 버튼을 누르고 「홈 화면에 추가」
> **안드로이드** — 오른쪽 위 메뉴를 누르고 「홈 화면에 추가」

**갈래 둘 중 이쪽이 「막는 쪽」이다. 지킬 것 넷**
- **왜 안 되는지를 먼저 말한다.** 「접속 코드는 한 번만」이 빠지면 **막는 화면으로만 읽힌다.** 이유를 알면 학부모가 스스로 다음 행동을 고른다
- **「PWA」·「스탠드얼론」·「설치」 같은 말을 쓰지 않는다.** 화면에서 실제로 보이는 글자(「홈 화면에 추가」)로만 말한다
- **아이를 탓하지 않는다.** 잘못 연 것이 아니라 **아직 준비가 안 된 것**이다
- **코드 입력칸을 흐리게라도 보여주지 않는다.** 보이면 누른다

### 3.3 자녀 인증 화면 — 코드 입력 (E-3)

**홈 화면 앱에서 열렸을 때.** 3.2 와 같은 화면의 다른 갈래이고 **목소리도 같다 — 앱(존댓말).**

| 자리 | 문구 |
|---|---|
| 제목 | **접속 코드를 넣어주세요** |
| 안내 한 줄 | 부모님이 알려주신 **6자리 숫자**예요. |
| 입력칸 라벨 | **접속 코드** |
| 버튼 | **들어가기** |
| 오류 | **서버가 준 `error.message` 를 그대로 쓴다** — 새 문구를 짓지 않는다 |

**정한 근거 넷**

- **「접속 코드」를 아이 화면에서도 그대로 쓴다.** 더 부드러운 말을 지어내면 **부모가 「접속 코드 알려줄게」라고 말하는 것과 화면의 글자가 어긋난다.** 코드를 건네는 사람과 받는 사람이 **같은 말을 써야** 한다 (`용어사전.md` 7장에 등록)
- **버튼은 「들어가기」다. 「보내기」가 아니다.** 2.2 의 규칙(**누르면 무슨 일이 일어나는지 말한다**)을 그대로 적용한 결과가 다르다 — 묘사 입력에서 일어나는 일은 **보내는 것**이지만 여기서 일어나는 일은 **들어가는 것**이다. 같은 규칙이 다른 답을 낸다
- **「6자리 숫자」를 안내에 넣는다.** 무엇을 넣어야 하는지 모양을 알려주면 **아이가 엉뚱한 것을 넣고 401 을 보는 일이 준다.** 오류를 나눠 말할 수 없으므로(아래) **미리 막는 것이 유일한 수단**이다
- **오류를 나눠 말하지 않는다.** 서버가 **없는 코드·만료된 코드·이미 쓴 코드를 전부 같은 401** 로 준다 — 구분하면 **코드를 찍어보는 쪽에 신호가 샌다.** 화면도 그대로 따른다

**성공하면 화면을 하나 더 만들지 않는다. 바로 모험 화면으로 보낸다.**
「환영합니다」류를 두지 않는 이유는 **환영은 가이드 몫**이기 때문이다 — 앱 목소리로 맞이하면 **아이가 처음 만나는 것이 가이드가 아니라 앱**이 된다. 가이드는 모험 화면에서 인사한다.

### 3.4 학부모 자녀 관리 화면 (E-4)

**아이에게 건넬 접속 코드가 여기서 나온다.** 학부모 화면 계열 — **존댓말 · 전문 용어 없음.**

**자녀 만들기**

> **아이가 쓸 이름을 정해주세요.**
> 실명 대신 **별명**으로 지어주세요. 실명·학교 이름은 저장되지 않고 걸러집니다.

**접속 코드를 보여줄 때**

> **아이에게 이 숫자를 알려주세요.**

> 아이 기기에서 **홈 화면에 추가한 앱**을 열고 넣어야 해요.

> 경고: **새 코드를 받으면 아이가 지금 쓰고 있는 기기에서 로그아웃됩니다.**

**정한 근거 넷**

- **실명 금지를 먼저 말한다.** 서버가 걸러내지만(E-2), **거절당한 뒤에 아는 것보다 넣기 전에 아는 것이 낫다.** 「저장되지 않고 걸러집니다」로 **막는 게 아니라 안 남는다**는 것을 말한다 — 학부모의 불안은 「거절」이 아니라 「어디에 남나」다
- **「24시간·한 번만」을 코드 옆에 붙인다.** 학부모가 **나중에 다시 열어보려 하는 것**이 실제 실패 모드다. 코드를 본 그 순간에 말해야 한다
- **「홈 화면에 추가한 앱에서」를 여기서도 말한다.** 아이 화면(3.2)이 막아주지만, **학부모가 먼저 알면 아이가 그 벽을 안 만난다.** 같은 사실을 두 화면에서 말하는 것이 여기서는 중복이 아니라 **앞뒤 방어**다
- **재발급 경고는 버튼 옆에 둔다. 누른 뒤에 말하지 않는다.** 재발급이 `token_version` 을 올려 **아이가 쓰던 태블릿이 끊긴다** (`api/공통규약.md` 「폐기」). **모르고 누르면 아이가 못 들어오고 학부모가 다시 불려온다** — 이 화면이 만드는 유일한 되돌릴 수 없는 실수다

## 4. 열린 자리

- **서버 오류 문구 하나가 두 화면에 나간다.** `error.message` 는 아이 화면 계열로 썼는데 **학부모 화면도 같은 값을 그대로 보여준다** (`web/src/app/parents/signup/page.tsx`). 지금 열 중 아홉은 양쪽에서 읽혀도 어색하지 않지만 **`CONSENT_REQUIRED`(「부모님 확인이 먼저 필요해요」)만은 학부모가 읽으면 어긋난다.** 문구를 나누려면 **API 계약이 바뀌므로** W4 에서 `ApiError.childMessage` 이름 정리와 **함께** 본다. 지금 조용히 고치지 않는다
- **`_결과대사`** — 결과 연출(A0-3)이 서는 W4. 1.3 참조
