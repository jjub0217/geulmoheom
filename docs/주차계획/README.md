# 주차 계획

`MVP_PRD.md` 8장의 마일스톤을 주 단위 실행 계획으로 쪼갠 문서들. PM이 `/plan-week W1` 로 만든다.

- **8장이 상위**다. 여기 문서가 8장과 어긋나면 8장을 고치거나 여기를 고친다 — 방치하지 않는다
- 범위는 전부 `백로그.md`의 항목 코드로 추적된다. 코드가 없는 항목은 백로그에 먼저 등록한다
- 「하지 않는 것」 절을 비우지 않는다. 그 절이 범위가 조용히 늘어나는 것을 막는다
- **여기는 계획, 진척은 `api/tasks/`·`web/tasks/`.** 한 파일을 둘이 체크하면 push가 자주 거부된다. PM 항목만 이 문서에서 직접 체크한다. 둘이 갈라지면 **계획이 맞다**
