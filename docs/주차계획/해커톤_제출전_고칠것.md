## 3. ⛔ 그 전에 — 한 판을 걸어본다

**우리는 운영에서 「부모 가입부터 끝까지」를 한 번도 안 해봤다.** 09-17 완료 판정 회차는 **모험 안쪽만** 봤다.

**① 이 그 증거다 — 코드를 뒤져서 찾았고, 걸어봤으면 1분이었다.**

**⛔ 1번이 틀렸다 — 2026-09-17 프론트가 잡았다. 고친 뒤의 순서다**

~~**20~30분 서버를 놀린다** — 요금제가 먹었는지가 같이 확인된다~~ **← 이 검사는 이제 아무것도 안 말한다.**
**오늘 오전에 헬스 체크 경로를 대시보드에 걸었다**(`ad55787`). 그래서 **Render 가 `/healthz` 를 5초마다 영구히 두드린다** — 배포 로그에 연속으로 찍혀 있다. **우리가 손을 떼도 서버는 5초마다 요청을 받는다.**
**⛔ 그러니 30분을 기다려 빨라도 그게 요금제 덕인지 헬스 체크 덕인지 못 가른다.** **통과해도 아무 말도 안 하는 검사**다 — **핸드오프 4장 ①(「검사가 있다」와 「검사가 돌았다」는 다르다)의 사촌**이고, **이번엔 「검사가 돌았는데 아무것도 안 잰다」**다.
**⭐ 그리고 애초에 기다릴 필요가 없었다 — 요금제는 Render 대시보드에 그냥 적혀 있다.** `$7 / 0.5 CPU / 512 MB` 인지 보면 끝이다. **마감 하루 앞에 30분을 쓸 자리가 아니다.**

**⚠ 다만 하나는 진짜로 남는다 — 「배포 직후의 첫 요청」.** 요금제가 막는 것은 **잠드는 것**이지 **배포 직후가 느린 것**이 아니다. **기다릴 대상은 「30분」이 아니라 「마지막 배포」**다.

**순서**
1. **Render 대시보드에서 요금제를 눈으로 본다** (`$7 / 0.5 CPU / 512 MB`). **0분**
2. **마지막 배포가 끝난 것을 확인한다** — ②·UI 가 다 올라간 뒤여야 한다. **이게 1번 자리를 대신하는 진짜 조건이다**
3. 부모 가입 → 자녀 만들기 → 6자리 코드
4. 코드로 아이 화면 → 세 장 → 「모험 떠나기」 → 10턴 → 완결 → 책
5. **보는 것은 「되나」가 아니라 「처음 보는 사람이 막히나」** — 말·시간·그림·끝·**되돌아갈 길 없이 갇히는 데**

## 4-2. ⛔ 정정 — `822e639` 의 「브라우저 e2e 60건」은 근거가 아니다 (2026-09-20)

**커밋 `822e639`(web 화면 다듬기 마무리분) 메시지에 「브라우저 e2e 60건(프론트, 다섯 뷰포트)」이 적혀 있다. 그 줄을 근거로 쓰지 않는다.**

**무슨 일인가** — 프론트가 「60 passed」로 보고했고 PM 이 그것을 커밋 근거로 썼는데, **프론트가 그 뒤에 스스로 철회했다.**
- **같은 두 파일이 `--list` 로는 174건**(뷰포트 둘 × 87)이고 **두 번째 실행은 44건**이었다. **`test.skip`·`only` 는 0건**이라 건너뛸 이유가 없다
- **「실패 0 · 종료 0」은 사실이되 「몇 건이 실제로 돌았나」를 모른다.** 유력한 원인은 **출력을 `tail` 로 잘라 앞부분(건너뜀 줄 포함 가능)을 버린 것**이다

**⛔ 오늘 세 번 짚은 그 부류가 네 번째로 났다 — 「통과했는데 아무것도 안 잰 검사」.**
**프론트가 아침에 `check-copy` 를 두고 「가장 위험한 실패는 아무 말 안 하는 초록」이라고 적어 놓고 그 초록을 근거로 넘겼고, PM 이 그것을 커밋에 실어 한 번 더 번졌다.** **혼자 틀리는 것보다 나쁘다** — **왕복이 있으면 「물어봤다」가 근거가 된다**(핸드오프 4장 ④).

**✅ 되돌리지 않는다. 근거만 바꾼다.** 확실한 것이 남아 있다 — **`typecheck` 통과 · `eslint` 0 · 단위 108 통과 · `check-copy` 0 · `git diff --check` 깨끗**, 그리고 **`822e639` 에 변경이 다 들어갔다.**

**⏳ 남은 것 — 브라우저 e2e 는 미검증이다.** 자르지 않고 다시 돌려 **실행·통과·건너뜀·실패 네 숫자를 그대로** 받는다. **막는 것은 포트다** — `next dev`(3004)가 떠 있고 **오늘 이 포트로 세 번 부딪혔다.** 사용자와 비울 시점을 잡는다.

**⭐ 축으로 세운다 — 검사 결과를 옮길 때 「무엇이 몇 건 돌았나」를 같이 옮긴다.** 「초록이었다」만 옮기면 **안 잰 검사와 통과한 검사가 같은 말이 된다.**

## 5. ⛔ 이 기간에만 다른 규칙 둘

**① `main` push 를 다시 연다.** 핸드오프 0-3 이 심사 기간 push 를 막았는데, **그 규칙이 막으려던 것은 「심사 중에 배포가 돌아 첫 요청이 느려지는 것」**이다. **지금 고치는 것은 심사 전이다** — 0-3 자신이 **「지금이 심사 중보다 낫다」**고 적어 뒀다.
