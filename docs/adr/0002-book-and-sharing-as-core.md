# 0002 — 책과 공유를 핵심으로, 단 안전망 → 서재 → 연재 순서

날짜: 2026-08-29 · 상태: 채택

## 맥락
초기 문서는 "아이가 스스로 쓰게 만드는 엔진"을 핵심에 두고 책·공유를 결과로 뒀다(PDF P1, 공유 P2). 창업자가 핵심을 "창작 책을 만들어 모든 사용자와 공유"로 확정했다.

## 결정
- 비전 2장에 책과 독자를 목적으로 명시. 쓰기 엔진은 수단
- 책 빌드·PDF·가족 공유를 Stage 1(A-7)로, Stage 0 앨범을 "내 책" 프레임으로
- 또래 공유 서재를 P1 1순위로. 순서는 S-0 안전망 → S-1 서재 → S-2 연재로 고정
- 아이 입력 원문은 로그가 아니라 창작물 — 책 콘텐츠로 보관, 로그·APM 미기록, 라벨링 활용만 동의 (PRD 1.1b)

## 근거
- 아이가 쓰는 이유(동기)가 P2에 있으면 Stage 0·1 사용자에게 "왜 쓰지?"의 답이 없다
- 그래도 공유가 P0가 아닌 이유: 초기 30명 규모에선 서재가 비고, 안전망이 먼저 서야 하며, 엔진 검증 전 공유는 AI 대필본 공유가 된다(비전 원칙 ②)

## 경계 (위배 방지)
- 책 문장은 아이 원문 그대로. AI 보정 금지
- 공유 반응은 세션 안에서만. 푸시 알림 금지 — 조회수 확인하러 켜는 앱이 되면 실패
- 자유 댓글 없음. 정형 칭찬·스티커·별점만
