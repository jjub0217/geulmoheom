# 0018 — 무료 Postgres 가 30일 만에 만료되어 유료 요금제로 올린다

날짜: 2026-10-12 (월) · 상태: **실행됨** (사용자가 Render 대시보드에서 전환) · **`adr/0012` 「감수하는 것 ②」와 `adr/0016` 결정 표의 `geulmoheom-db` 줄을 대체한다**

## 맥락

**`adr/0012` 와 `adr/0016` 은 무료 Postgres 가 「90일 뒤 삭제된다」고 적었다. 이 숫자가 틀렸다.**

Render 공식 문서(`render.com/docs/free`, 2026-10-12 확인)의 실제 규칙은 이렇다.

- **무료 Postgres 는 만든 지 30일 뒤에 만료된다.** 만료되면 접속할 수 없다
- **만료 뒤 14일 안에 유료로 올리지 않으면 데이터베이스와 데이터가 모두 삭제된다**
- **무료 Postgres 는 백업을 지원하지 않는다.** 만료된 뒤에는 접속이 안 되므로 데이터를 따로 내려받을 수도 없다

**그래서 실제로 일어난 일:**

| 날짜 | 일어난 일 |
|---|---|
| 2026-09-10 | `geulmoheom-db` 를 무료 요금제로 만들었다 |
| 2026-10-10 밤 | 30일이 지나 만료됐다. Render 가 「14일 안에 올리지 않으면 삭제한다」는 메일을 보냈다 |
| 2026-10-10 ~ 10-12 | **운영 서비스가 데이터베이스에 붙지 못했다.** `/healthz` 는 200 이었지만 `/readyz` 는 503 (`postgres: down` · `cards: down`) 이었다 |
| 2026-10-12 | 사용자가 유료로 올렸다. 몇 분 뒤 `/readyz` 가 200 (`postgres: up` · `redis: up` · `cards: up`) 으로 돌아왔다 |

**그대로 두었다면 2026-10-24 무렵에 아이들이 쓴 책이 모두 삭제될 뻔했다.** `0012` 가 「아이 책이 사라지는 종류의 사고」라고 적어 둔 바로 그 일이고, 예상한 12월 중순보다 두 달 가까이 일찍 왔다.

## 결정

**`geulmoheom-db` 를 가장 작은 유료 요금제로 올린다.**

| 서비스 | 요금제 | 달라진 것 |
|---|---|---|
| `geulmoheom-db` (Postgres) | free → **월 $6** (0.1 CPU · 256 MB RAM) | 사양은 무료와 같다. **만료와 삭제가 없어진다** |
| `geulmoheom-api` (web) | 월 $7 그대로 (`0016`) | 바뀌지 않았다 |
| `geulmoheom-cache` (Key Value) | free 그대로 | 바뀌지 않았다 |

**돈 — 월 $6 ≈ 약 8,400원** (환율 1달러≈1,400원 대략값). `0016` 의 api 값과 합치면 **월 $13 ≈ 약 18,200원**이다.

**워크스페이스 요금제는 Hobby($0) 그대로다.** 바꾸는 곳은 데이터베이스 화면의 `Plan → Compute → Edit` 이고, 화면 맨 위의 `Upgrade` 는 계정 등급이라 누르지 않는다 (`0016` 「요금제가 두 층이다」).

## 근거

- **유료 전환이 데이터를 살리는 유일한 방법이었다.** 백업이 없고 만료 뒤에는 접속도 안 된다
- **`MVP_PRD.md` 가 책 콘텐츠를 유지하기로 정해 뒀다** — 파일럿 2 재참여 집단의 기준 자료다
- **무료로 새로 만드는 것은 답이 아니다.** 데이터가 사라지고 30일 뒤에 같은 일이 또 온다

## 아직 안 정한 것

- **계속 유료로 둘 것인가.** 내리는 길은 「다른 곳으로 데이터를 옮긴 뒤 닫는다」뿐이다. 무료로 되돌릴 수는 없다. **`0016` 의 「심사 뒤에 api 를 내릴 것인가」와 같이 본다**
- **저장 공간 값이 따로 붙는지 확인하지 않았다.** Render 청구서에서 본다
- **유료 요금제의 백업 기능을 실제로 켜고 되살려 보지 않았다**

## 따라오는 것

- `render.yaml` 의 `databases` 에 적힌 `plan: free` 는 **기록일 뿐 적용되지 않는다** (`0016` 「실행은 대시보드다」). 값은 그대로 두고 주석에 실제 요금제를 적었다
- `미룬것.md` 의 「무료 Postgres 90일 삭제 대비」 줄을 닫았다
