# ADR — 결정 기록

"왜 이렇게 했지?"에 답하는 문서. 한 결정 = 한 파일. 번호 순서대로 늘어난다.

형식: `NNNN-짧은-제목.md` — 맥락 / 결정 / 근거 / 대안 / 결과. 결정을 뒤집을 때는 지우지 말고 새 ADR로 "0003은 0007로 대체됨"을 남긴다.

- **0017** — [본편은 직접 쓰기로만 진행](0017-direct-writing-only.md)(2026-09-19 사용자 요청). 선택지 화면·제출 허용을 폐기하고 직접 쓴 글로만 진행한다. 과거 기록과 GM 내부 응답 필드는 보존한다.

- **0016** — **심사 기간 동안 api 만 유료 요금제**(2026-09-17). AI 해커톤 심사자가 직접 써 보므로 **콜드 스타트 30~50초를 돈으로 푼다**(월 약 9,800원). **`0012` 「감수하는 것 ①」을 대체한다.** ⏳ **심사 뒤에 내릴지는 안 정했다**
