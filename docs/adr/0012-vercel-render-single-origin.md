# 0012 — 배포: web=Vercel · api=Render(무료) · **한 오리진 프록시**

날짜: 2026-09-10 · 상태: 채택 · **대표 판정** · **`adr/0007` 의 결정 2·3(호스트 배치·레지스트라)을 대체한다.** 결정 1(정적 빌드)·4(이미지 최적화 끄기)는 **그대로 산다**

## 맥락

**`adr/0007` 은 「Cloudflare Pages + Cloudflare Registrar + 3단 호스트」로 정했고 Vercel 을 근거를 들어 기각했다.** 그런데 **도메인이 끝내 등록되지 않았다** — 09-08 에 대표가 「테스트 단계에는 무리」로 보류했고, **09-11 에 파일럿을 열어야 하는데 배포처가 없는 상태가 이어졌다.**

**그 사이에 조건이 둘 바뀌었다.**
- **도메인을 안 사기로 했으므로 「등록가능 도메인을 맞춘다」는 0007 의 설계 전제가 성립하지 않는다.** 무료 서브도메인으로는 **흉내 낼 수 없다** — `vercel.app` 도 `onrender.com` 도 **Public Suffix List** 에 있어 **서브도메인끼리도 남남(cross-site)** 이다
- **파일럿 일정이 09-20 판정으로 압축됐다.** 등록·DNS 전파·인증서에 쓸 2~3일이 없다

**대표가 배포 조합을 검토해 왔다** (2026-09-10): 프론트 Vercel · **백엔드 Render** · 무료 플랜. **이 ADR 은 그것을 우리 제약에 맞춘 것이다.**

## 결정

**셋이다.**

### 1. web 은 Vercel, api 는 Render — 둘 다 무료 플랜

**대표 판정 (2026-09-10): 무료로 간다.** 감수하는 것은 아래 「감수하는 것」에 적었다.

**api 가 서버리스에 못 올라간다는 것이 Render 를 부른 이유다.** FastAPI 컨테이너이고 **Postgres 와 Redis 를 물고 있다** — Redis 는 접속 코드 속도 제한(`child_auth_limit.py`) · 비용 추적(`cost.py`) · 되묻기(`scaffold.py`)에 쓰여 **빼면 안전 장치가 같이 빠진다.** 컨테이너를 받는 곳이 필요했고 `adr/0007` 도 업체가 아니라 **「Fly.io / Railway **급**」**으로 적어 두었다.

### 2. ⛔ 한 오리진으로 세운다 — `vercel.json` 의 `rewrites`

**브라우저에게는 Vercel 호스트 하나만 보인다.** `/api/*` 를 Vercel 이 Render 로 넘긴다. **Render 주소는 브라우저에 노출되지 않는다.**

**이것은 선택이 아니라 필수다.** 안 하면 **로그인 자체가 안 된다.**

| 안 했을 때 | 왜 |
|---|---|
| **로그인이 안 된다** | 우리 쿠키는 `SameSite=Lax` 다. **Lax 는 cross-site fetch 에 안 실린다** — 아이가 접속 코드를 넣어도 다음 요청에 인증이 안 붙는다 |
| **그림이 0% 다** | `GET /artworks/{id}/image` 는 `<img>` 서브리소스다. 쿠키가 안 실리면 **한 장도 안 뜬다.** 잘림(43% 보임)보다 나쁘다 |
| **30일이 무너진다** | iOS ITP 의 cross-site 제약. `공통규약.md` 가 이미 「cross-site 였다면 자녀 토큰 30일이 성립하지 않는다」로 적어 뒀다 |

**⚠ CORS 로는 안 풀린다.** CORS 는 **「응답을 읽어도 되는가」**를 정하고, 쿠키가 실리는지는 **`SameSite` 가** 정한다. **다른 층이다** — 대표가 검토해 온 문서의 1·2번(CORS 설정)만 하고 3번(프록시)을 「선택 사항」으로 두면 **여기서 막힌다.**

**⛔ 자리는 `vercel.json` 이다. `next.config` 가 아니다.** web 이 **정적 빌드(`output: "export"`)**라 **Next 의 `rewrites()` 가 동작할 서버가 없다** — `next.config.ts` 주석이 이미 「`headers()`·`redirects()`·`rewrites()`·미들웨어를 못 쓴다」로 못 박고 있다. **`vercel.json` 의 `rewrites` 는 Vercel 플랫폼이 처리하므로 정적 빌드와 무관하게 동작한다.**

**발판은 이미 서 있다** (`7fdb693`) — `destination` 만 Render 주소로 채운다.

### 3. CORS 설정을 새로 열지 않는다

**한 오리진이면 브라우저가 cross-origin 요청을 아예 안 만든다.** `CORS_ORIGINS` 는 **로컬 개발용으로만 남긴다** — 운영 오리진을 거기 넣는 것은 **프록시가 하는 일을 이해 못 했다는 신호**다.

## 근거 — `adr/0007` 이 못 풀던 것을 오히려 닫는다

**0007 은 30일 토큰을 「보장이 아니라 목표」로 남겨 뒀다.**

> Safari 16.4+ 는 **응답을 준 서버의 IP 가 최상위 프레임 호스트의 IP 와 앞 절반이 다르면** 서브리소스 `Set-Cookie` 를 7일로 깎는다. **이 검사는 등록가능 도메인을 아예 보지 않는다.** 완화는 `api.` 도 Cloudflare 프록시 뒤에 두는 것이고, **배포 후 `dig` 실측 전까지는 확정이 아니다.** (`공통규약.md` 「수명」)

**한 오리진에서는 이 검사가 성립하지 않는다.** 응답을 주는 것도 Vercel 이고 최상위 프레임 호스트도 Vercel 이다 — **같은 IP 다.** Render 는 Vercel 뒤에 있어 **브라우저가 보지도 못한다.**

**그래서 0007 의 후속 작업 하나가 없어진다** — 「`app.`/`api.` IP 대역 `dig` 실측」(`api/미결.md` 후속 표). **잴 대상이 사라졌다.**

**0007 이 Vercel 을 기각한 근거 넷 중 셋도 무력해졌다.**

| 0007 의 기각 근거 | 지금 |
|---|---|
| 「Cloudflare 는 남의 원본도 프록시할 수 있고 Vercel 은 자기 배포물 앞에만 선다」 | **그 성질이 필요 없어졌다.** `api.` 를 따로 세우지 않으므로 프록시할 남의 원본이 없다 |
| 「DNS 작업이 두 곳으로 나뉜다」 | **도메인을 안 산다.** DNS 작업 자체가 없다 |
| 「R2 와 계정이 갈린다」 | **여전히 갈린다** — 유일하게 살아남은 근거다. 다만 **삽화는 api 가 프록시**하므로(미결 11-7) R2 는 브라우저에 노출되지 않아 **계정이 갈리는 비용이 배포 형태에 걸리지 않는다** |
| 「벤더가 하나 더 는다」 | **여전히 참이다.** Vercel + Render 두 곳이 된다 |

## 감수하는 것 — **무료라서 치르는 값 셋. 파일럿에 실제로 간다**

### ⛔ ① Cold Start 30~50초 — **아이가 맞는다**

**Render 무료 인스턴스는 15분간 요청이 없으면 잠든다.** 파일럿은 **아이 10~30명이 하루에 띄엄띄엄** 쓰므로 **15분 무요청이 계속 일어난다.**

- **아이가 앱을 열면 첫 화면이 카드를 부른다.** 거기서 **30~50초를 기다린다**
- **삽화 폴링은 15초 타임아웃이다**(`Stage0.md` 5절). 잠들어 있으면 **첫 아이는 그림을 못 받고 기본 에셋으로 떨어진다** — **보상 축이 그 아이에게만 꺼진다**

**⚠ 이것은 잠금 조건 ①(아이가 못 쓴다)에 닿는다.** 그래서 **완화를 항목으로 세운다** — 아래 「따라오는 작업」 ②. **완화가 서지 않으면 파일럿 첫 아이가 30초를 기다린다.**

### ⚠ ② 무료 Postgres 는 90일 뒤 삭제된다

**파일럿 9일 안에는 안 걸린다.** 그런데 **`MVP_PRD.md` 는 「파일럿 1 종료 시 라벨링 사본만 파기, 책 콘텐츠는 유지 — 파일럿 2 재참여 코호트의 베이스라인」**으로 정해 뒀다. **90일이 지나면 그 책이 사라진다.**

**아이 책이 사라지는 종류의 사고**라 **09-20 판정 뒤에 반드시 다시 본다** (`미룬것.md`).

### ⚠ ③ 무료 Redis 는 영속성이 없다

**재시작하면 비어 있다.** 우리가 Redis 에 두는 것은 **속도 제한 카운트 · 비용 누적 · 되묻기 횟수**다.

- **속도 제한이 리셋된다** — 접속 코드를 찍어 보는 것을 막는 장치가 재시작마다 풀린다. **파일럿 규모(아는 아이 10~30명)에서는 감당된다**
- **비용 누적이 리셋된다** — `adr/0010` 의 한도를 세는 값이다. **삽화를 안 굽기로 해서 이번 주에는 셀 것이 거의 없다**
- **되묻기 횟수가 리셋된다** — 아이가 되묻기를 한 번 더 받을 수 있다. **아이에게 나쁜 방향이 아니다**

**셋 다 파일럿 규모에서 감당되지만, 규모가 커지면 ①이 진짜 문제가 된다.**

## 따라오는 작업 — **이것들이 안 서면 배포가 서도 안 돈다**

| | 무엇 | 누가 |
|---|---|---|
| **①** | **삽화 주소를 상대 경로로 고친다.** `api/app/api/v1/artworks.py` 의 `삽화주소()` 가 **`request.url_for()` 로 절대 주소**를 만들고 **그 주석이 0007 의 3단 호스트를 근거로 든다.** 한 오리진에서는 **그 근거가 뒤집힌다** — 안 고치면 `<img>` 가 Render 호스트로 직접 나가 **쿠키가 안 실리고 그림이 0%** 다. **`--proxy-headers` 로는 안 풀린다**(`X-Forwarded-Host` 를 안 본다) | 백엔드 |
| **②** | **Cold Start 완화.** 후보는 **외부 무료 모니터링(UptimeRobot·cron-job.org 급)이 5~14분 간격으로 `/healthz` 를 때리는 것**이다. **GitHub Actions 로 하지 않는다 — CI 가 결제 문제로 09-09 부터 안 돈다.** **`/healthz` 는 인증이 없고 DB 도 안 보므로 때려도 안전하다** | 백엔드 |
| **③** | **`vercel.json` 의 `destination` 을 Render 주소로 채운다.** 지금은 일부러 안 도는 값(`API_HOST_를_아직_안_정했다`)이다 | 프론트 |
| **④** | **`--proxy-headers` 로 scheme 이 https 로 잡히는지 확인한다.** 프록시 뒤라 api 는 http 로 받는다 — 안 잡히면 **`Secure` 쿠키를 안 굽는다** | 백엔드 |<br>**✅ 2026-09-12 — 닫혔다. 고쳐서가 아니라 잴 것이 없어져서다** (백엔드 실측). **코드가 scheme 을 아무 데서도 안 읽는다** — `request.url.path` 둘뿐이고 쿠키 `Secure` 는 하드코딩이다. **종전 유일한 의존처가 `삽화주소()` 의 `url_for()` 였는데 ①에서 상대 경로로 바뀌며 없어졌다**(`ba6131c`).<br>**⛔ 즉 위 「안 잡히면 `Secure` 쿠키를 안 굽는다」는 ① 이전의 전제이고 지금은 성립하지 않는다.** **한 항목이 다른 항목의 근거를 없앤 자리**라 적어 둔다 — **①을 되돌리면 이 전제가 되살아난다.**<br>**플래그 자체는 그대로 둔다** — 로그의 클라이언트 IP 가 그것에 걸려 있다.
| **⑤** | **넣어 둔 `legendary` 18장을 Render 인스턴스에 올린다.** `api/out/` 도 `.artworks/` 도 **`.gitignore`** 라 **컨테이너에는 없다.** 안 올리면 **60조합이 전부 기본 에셋으로 나가는데 아이 화면은 안 멈춘다** — **그림만 통째로 기본이 되고 아무 데도 빨간불이 안 뜬다.** 키가 `JWT_SECRET` 에서 유도되므로 **넣는 환경과 서버의 비밀이 같아야 한다** | 백엔드 |

## 되돌릴 때

**되돌리는 비용이 지금은 0 이다** — 발판만 서 있고 아무것도 안 올라갔다.

**도메인을 사기로 하면 `adr/0007` 의 3단 호스트로 돌아갈 수 있다.** 그때 바뀌는 것은 **삽화 주소(①의 반대)** 와 **CORS 를 다시 여는 것**이고, **쿠키 계약은 그대로다** — 0007 도 same-site 를 전제했으므로 `__Host-` · `Lax` · `Domain` 미부착이 양쪽에서 같다. **인증을 다시 짜지 않아도 된다.**
