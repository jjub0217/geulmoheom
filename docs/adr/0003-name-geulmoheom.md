# 0003 — 제품명 「글모험」, 초기 작업명 "AI 퀘스트 메이커" 폐기

날짜: 2026-08-29 · 상태: 채택

## 맥락
작업명 "AI 퀘스트 메이커"는 AI를 주인공으로 세우고, "메이커"의 주어가 AI로 읽히며, 아이에게 공부 냄새를 준다. 학부모의 학습 대행 불안을 이름이 먼저 건드린다.

## 결정
제품명 **글모험 (Geul Moheom)**. 코드네임 `geulmoheom`. 아이 최상위 칭호 「문장술사」.

## 근거
- "글을 써서 떠나는 모험" — 초5도 학부모도 설명 없이 이해
- 순우리말이라 검색·상표 여지가 큼. 행동형·서사형 두 원형 모두에 중립
- 비전 5장에 "이름에 AI를 앞세우지 않는다"를 원칙으로 추가

## 대안
문장술사(칭호로 채택), 잉크퀘스트(글로벌명 후보로 보류), 내책연구소(학원 어감), 여백의 숲(태그라인 후보)

## 결과
- 파일럿 아동 설문에 "'글모험'이 뭐 하는 앱 같아?" 이름 이해도 1문항 (측정만)
- 영어권 이름·상표·도메인은 제품명 확정 시점에 별도 검토
