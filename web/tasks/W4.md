# W4 — 프론트 진척

계획: `docs/주차계획/W4.md` 「작업 쪼갬 · 프론트」 · **선행·완료 조건은 계획의 「범위」 표에 있다**
**범위를 여기서 바꾸지 않는다.** 계획이 틀렸으면 PM에게 말한다.

> **이 주차는 W3 과 겹쳐 돈다.** W3 잔여는 `web/tasks/W3.md` 에서 센다 — 한 항목을 두 파일에 적지 않는다.
> **대표 판정(「W4 를 지금 여는가」)이 아직 안 왔다.** 되돌리기 비싼 것부터 치지 않는다 — 화면·프론트 단독이 먼저, **계약·스키마는 판정 뒤**.

- [ ] **1. W3 에서 넘긴 넷** — **선행 없음. 여기서 시작한다**
  - [ ] ① 서비스워커를 `public/sw.js` 로 — **`output: "export"` 와 반드시 같은 커밋**
        (따로 넣으면 둘 중 하나만 들어가고 그때 배포가 깨진다. 지금 `scope: "/"` 가 Next 헤더에 기대고 있다)
  - [ ] ② `standalone` 설치 안내
  - [ ] ③ 폼 입력 칸 최대 너비 — 학부모 화면 첫 장이라 **다음 장들과 함께 잡는다**
  - [ ] ④ `ApiError.childMessage` 이름 — **마지막에.** 계약이 바뀌므로 **대표 판정 뒤**
    - [ ] 대표에게 직접 말했다 — API 계약 변경(루트 `CLAUDE.md` ①)

- [ ] **2. 결과 연출 (A0-3)** — **선행: B-3** · **이 주차 최대 조각. 하위마다 세션을 나눈다**
  - [ ] 등급 → 삽화 해금
  - [ ] 가이드 표정 — 서버 `guide.expression` → PNG 매핑만
  - [ ] 감지된 묘사어 하이라이트 — 서버가 **부분 문자열을 보장**한다는 전제 위에 선다
  - [ ] 목소리 규칙 — `error.message` 와 `guide.line` 이 겹치면 **`guide.line` 만**
        (`guideLineOf(detail) ?? e.childMessage` 가 이미 그 모양이다)
  - [ ] **테스트에 문구를 문자열로 박지 않았다** — 상수를 import (`[보안 필터]` 여섯 군데의 재발 자리)

- [ ] **3. 삽화 (B-3) 프론트 몫** — **선행: B-1 ✅ · E-1 (W3 잔여)**
  - [ ] 생성 대기 6~8초 동안 **「삽화 대기」 대사** — 폴링 규약은 `docs/api/Stage0.md` 5절
  - [ ] **등급을 미리 흘리지 않는다** — 그림 전에 결과를 알면 보상의 순간이 죽는다
  - [ ] **대기를 메우는 것이지 붙잡는 것이 아니다** — 연출을 늘리지 않는다 (비전 원칙 ③)

- [ ] **4. 내 책 (A0-4)·일일 제한 (A0-5) 프론트 몫**
  - [ ] 내 책 — **선행: A0-3** · 책 페이지 프레임으로 재열람 · 티어 배지
  - [ ] 내 책 — **문장은 아이 원문 그대로**(마스킹 뒤 텍스트). 요약·교정하지 않는다
  - [ ] 일일 제한 — **선행: 백엔드 A0-1 잔여** · 소진 시 409 에서 **`guide.line` 만** 띄운다

## 메모

- **문구는 `docs/문구.md` 가 SSOT 다. 화면에서 지어내지 않는다.** `_결과대사` 가 **마지막 남은 잠정 문구**이고, 화면이 서면 PM 이 확정해 내려준다 — **A0-3 이 대사를 지을 유혹이 가장 큰 자리다**
- **착수 신호는 `make contracts-check`** — `make contracts` 는 서버가 죽으면 **거짓 초록**이다. 그리고 **기계 통과가 착수 허가가 아니다**: 백엔드가 커밋한 **뒤** 한 번 더 돌려 드리프트 0 인 것이 신호다
- **개발 서버는 백엔드 세션이 띄운다** — 포트 8000 충돌. 「connection refused」는 끊긴 것이지 고장이 아니다
- **PM 에게 짚을 것** — 「진행 현황」 표는 GM 대사 세트(C-1)를 **공동**으로, 「범위」 표는 **PM(문안)+백엔드(배선)**로 적는다. 어느 쪽도 프론트를 지목하지 않아 이 체크리스트에는 안 넣었지만 **두 표가 갈려 있다**
