## ⛔ 별건으로 갈린 것 — 삽화 파일이 저장소에서 안 지워진다

**이번 커밋에 안 섞었다** (사용자 지시). **백엔드 몫으로 보인다.**

DB 행은 전부 지워지는데 **S3·로컬의 삽화 이미지 바이트가 남는다.** 지우는 코드가
저장소 전역에 0건이다. 정책(`MVP_PRD.md:324` 「즉시 파기」 · `페인_가이드라인정책.md`
DLP-03 「24시간 내 파기」)과 어긋난다.

조사는 끝났다 — 여덟 항목 답이 **`docs/미룬것.md` 와 PM 세션 대화**에 있다. 핵심만:

- **⛔ 함정** — Stage 0 캐시 적중 경로가 **공용 조합 키를 그 아이 행의 `r2_key` 에 그대로 적는다**
  (`api/app/artwork_store.py:102`). 「그 아이 행이 가리키는 키」를 다 지우면
  **다른 아이들이 같이 쓰는 전설 삽화 18장이 날아간다.**
  기준은 행이 아니라 **`artworks/시도/` 접두어**여야 한다
- 큐·워커·스케줄러가 **하나도 없고** Redis 는 무영속, `render.yaml` 은 적용조차 안 된다
  → **응답 전 동기 + 베스트에포트**가 현 구조에 맞다. 자리는 이미 있다
  (`parents.py` 가 커밋 뒤 Redis 뒷정리를 그렇게 한다)
- **IAM 에 `s3:DeleteObject` 가 없다.** 정책 문서가 「목록·삭제가 없어 키가 새도 지울 수 없다」고
  스스로 적어 뒀다 → **대표 판정**
- 못 지운 키를 로그에 남길지도 **대표 판정** (키에 `artwork_id` 가 들어 있다)
- `api/tests/test_erasure.py` 는 **파일을 전혀 안 잰다.** 행 개수만 센다
- 부수 — `페인_가이드라인정책.md` 가 가리키는 **`adr/0013` 파일이 없다**(0012 다음이 0014).
  S3 전환 결정이 ADR 로 안 남았다. **PM 몫**

## 검사 돌리는 법 (⚠ 함정 둘)

```
NODE_OPTIONS="" pnpm typecheck && NODE_OPTIONS="" pnpm lint && NODE_OPTIONS="" pnpm test
node infra/check-copy.mjs          # 저장소 루트에서
```

**⛔ 모든 node·pnpm 앞에 `NODE_OPTIONS=""` 를 붙인다** — 이 환경에서 그 변수가 깨져 있다.

브라우저 검사는 **떠 있는 3004 에 붙어** 돈다. 붙는 설정은 세션 스크래치패드에 있고,
없으면 `playwright.config.ts` 를 베껴 `webServer` 를 빼고 `baseURL` 만 3004 로 바꾼다.

**⛔ 서버를 직접 띄우면 `NEXT_PUBLIC_API_BASE_URL=/api/v1` 을 반드시 준다.**
다른 오리진을 주면 JSON 요청 앞에 preflight 가 붙고 `page.route` 가 못 가로채
**화면이 통째로 「못 닿음」이 되어 검사가 무더기로 죽는다.** 2026-09-21 에 8건이 그랬다.
**숫자를 말할 때는 `--workers=1`** — 여럿이면 같은 가짜 서버 상태를 나눠 쓴다.
