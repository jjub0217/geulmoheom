# W5 — 프론트 진척

계획: `docs/주차계획/W5.md` 「작업 쪼갬 · 프론트」 · **선행·완료 조건은 계획의 「범위」 표에 있다**
**범위를 여기서 바꾸지 않는다.** 계획이 틀렸으면 PM에게 말한다.

> **완료를 말하기 전에 상위 체크박스를 본다.** W4 에서 두 번 났다 —
> 하위를 다 채우고 「끝났다」고 보고했는데 상위만 `[ ]` 로 남았고 둘 다 PM 이 잡았다.
> **상위 체크박스가 완료 조건 되짚기의 마지막 칸**이다 (계획 W5 축 ⑬).

> **이 주차는 파일럿 1을 열 수 있는 상태를 만드는 주차다. 가설을 판정하지 않는다.**
> 계획 자체가 PRD 8장을 고치면서 열렸고 대표 판정은 사후다 — **기다리며 멈추지 않는다.**
> **프리테스트(W4·PM) 결과가 이 주차 범위를 뒤집을 수 있다.** 뒤집히면 그것이 1번보다 앞선다.

- [ ] **1. 서버까지 붙는 E2E + CI — web 쪽 몫** (계획 「진행 현황」 1번 · 공동) — **선행 없음. 주 첫날에 친다**
      **세 번째로 미룰 수 없다.** W3·W4 에서 두 번 미뤘고 다음 자리는 파일럿 안이다
  - [ ] 서버까지 붙는 갈래를 **따로** 세운다 — **지금 122개를 건드리지 않는다.**
        그것들은 화면을 재는 검사라 빠르다. 섞으면 매 push 마다 느려지고 **느려지면 또 미룬다**
  - [ ] 갈래 하나가 한 줄로 통과한다 — 아이가 들어와(E-3) 카드를 받고 문장을 보내
        등급을 받고(B-2) 그림이 구워져(B-3) 책에 쌓인다(A0-4). **넓히는 것보다 CI 가 먼저다**
  - [ ] CI 에 붙어 push 마다 돈다
  - **api 를 진짜로 태우는 발판·유료 호출 가짜 앞단·`GEMINI_API_KEY` 무력화·`alembic check` 은 api 세션 몫이다** — 여기서 세지 않는다

- [ ] **2. 자녀 삭제 화면 (E-4 후속 · COPPA)** (계획 「진행 현황」 4번) — **선행: 서버 ✅**
      **서버는 도는데 화면이 없다.** COPPA 축이라 **파일럿 전에 서야 한다**
  - [ ] **문구가 `문구.md` 3장(학부모 화면)에 서 있는지 먼저 본다** — 없으면 PM 세션에서 내려준 뒤에.
        **화면에서 짓지 않는다** (W4 에서 셋이 지어질 뻔했다)
  - [ ] 되묻는다 — **재발급보다 무겁게.** 재발급은 기기가 끊기고 이건 **아이 책이 사라진다**
  - [ ] **무엇이 함께 사라지는지 말한다** — 문장 · 그림 · 책
  - [ ] 대표에게 직접 말했다 — **안전·프라이버시 경로**라 「대표 몫」이다. 커밋 전 `git diff` 검토도 같이

- [ ] **3. 책 제목 바꾸기 — 화면 몫** (계획 「진행 현황」 5번 · 공동) — **선행: A0-4 ✅**
      `Stage0.md` 6절 **SHOULD**
  - [ ] 제목 고치는 자리
  - [ ] **가린 뒤 값이 그대로 보인다** — 카드 화면과 같은 규칙. **여기서 새 분기를 만들지 않는다**
  - **`PATCH /book` 저장과 제목 PII 검사는 api 세션에서 이어서 한다** — 지금은 저장을 안 한다

- [ ] **4. 확인 장치가 없는 자리 훑기 — ⓪·⑬** (계획 「진행 현황」 6번 · 전원) — **선행 없음**
      **완료 조건은 「훑었다」가 아니라 「무엇을 훑었고 무엇이 나왔는가」다**
  - [ ] **⓪ 완료 판정 문장을 항목으로 되짚는다** — 계획 W5 의 「범위」 표와 「하지 않는 것」을
        **한 줄씩** 읽고 **담당 없는 동사**를 찾는다
  - [ ] **⑬ 요약이 확인을 대신하지 않는다** — 되짚은 자리와 나온 것을 **목록으로** 남긴다.
        나온 게 없으면 **어디를 봤는지**가 산출물이다
  - **⑧·⑪ 는 api 세션 몫이다**
