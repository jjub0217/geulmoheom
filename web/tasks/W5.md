## 훑기 산출물 (4번)

**「훑었다」가 아니라 무엇을 봤고 무엇이 나왔는가다.** 나온 게 없으면 어디를 봤는지가 산출물이다.

### ⑭ 기대값의 출처가 대상인가

**본 것** — `e2e/*.spec.ts` 일곱 파일의 값 import 전부(타입 import 제외).

| 무엇 | 판정 |
|---|---|
| 문구 계열 (`copy.ts`·`children-copy`·`leave-copy`·`artwork-copy`·`tier-badge` …) **대부분** | **import 가 맞다.** 우리가 정하는 값이고 `문구.md` 가 SSOT 라 **바뀌면 검사도 따라가야 한다** |
| 삽화 비율 | **틀렸다 → 고쳤다** (`c7bb68e`). 상수를 4:3 으로 바꿔도 검사가 따라가 초록이었다 |
| 나이 선택지 개수 (`나이선택.length`) | **틀렸다 → 고쳤다.** 선택지를 넷으로 늘려도 초록이었다. 계약 값(`10\|11\|12`)을 다시 적었다 |
| 폴링 숫자 셋 (3초·2초·15초) | **이미 맞았다.** `src/lib/artwork.test.ts` 가 계약 값을 **다시 적어** 지키고 있다 — **축이 생기기 전에 이미 그 모양이었다** |
| `폴링상한` 을 e2e 가 import 하는 것 | **맞다.** 기대값이 아니라 **기다리는 예산**이고, 값 자체는 위 단위 검사가 지킨다 |

**열린 것 하나** — **`문구.md` ↔ `copy.ts` 사이에는 기계 검사가 없다.** 문구를 import 하는 것은 맞지만
**그 SSOT 가 문서**라, 코드가 문서에서 어긋나도 **아무도 안 본다.** 오늘 3.9 가 화면보다 먼저 내려온 것은
**사람이 지킨 것이지 장치가 아니다.** 고칠지는 PM 판단.

### ⓪ 담당 없는 동사

**본 것** — 계획 W5 「범위」 표 11행 · 「하지 않는 것」 6행. **셋 나왔다.**

1. **「파일럿 전에 배포가 서면 그날 바로 본다」 — 배포에 담당도 항목도 없다.**
   W5 계획에서 「배포」는 **「하지 않는 것」 표 안 한 곳**에만 나온다. 그런데 **완료 판정 5(파일럿 모집이
   열려 있다)와 파일럿 1 자체가 배포 없이 안 선다.** 「배포 뒤에만 되는 것 셋」이 배포를 기다리는데
   **그 배포를 누가 언제 하는지가 어디에도 없다.** **가장 조용한 자리다**
2. **`.github/workflows/ci.yml` 을 어느 세션이 고치는지가 없다.** 1번이 「공동」이고 백엔드·프론트 양쪽에
   각각 「CI 에 붙인다」가 적혀 있는데 **파일은 하나**다
3. **화풍(B-5) 「사람이 본다」의 주어가 비어 있다** — 담당은 백엔드지만 C-2 는 아동 4명에게 물었다.
   **백엔드 몫이라 그쪽에 넘긴다**

### ⑬ 되짚기의 단위

**본 것** — `tasks/W4.md` 의 「뒤집어 확인했다」 넷.

- **넷 다 무엇을 뒤집었는지까지 적혀 있다** — ⑬ 이 요구하는 형태다. 그 자체는 통과다
- **다만 항목 단위이지 단언 단위가 아니다. 오늘 그 틈에서 하나가 샜다** — 액자 검사는
  「뒤집어 확인」을 통과했는데 **두 단언 중 하나(비율)는 헛돌고 다른 하나(`object-fit`)만 물었다.**
  항목 단위로 보면 **빨간불이 떠서 「문다」로 읽힌다**
- **고칠 것 — 뒤집기는 단언마다 확인한다.** 오늘부터 그렇게 했다
