- **`EVALUATOR_MODEL` 은 채워졌다** (2026-09-07 확인, `gemini-3.1-flash-lite`). 파일 값과 프로그램이 실제로 읽는 값이 일치하는 것까지 봤다고 한다. 비어 있으면 평가가 **폴백으로 전부 G1 이 되고 조용히 그렇게 돈다** — 결과가 계속 같으면 여기를 먼저 의심한다
- **Postgres·Redis 가 떠 있다** (`geulmoheom-postgres` 5433 · `geulmoheom-redis` 6381). 되묻기 횟수가 Redis 에 쌓이므로 **`X-Mock-Outcome` 없이 `네가 정해` 같은 입력으로 진짜 `scaffold` 를 볼 수 있다.** `docker` PATH 는 `~/.zshrc` 에 들어갔고 **새 터미널에서만 적용**된다
- **결과 연출 대사는 `api/app/api/v1/attempts.py` 의 `_결과대사` 에 잠정으로 있다.** 대사 세트(C-1)가 W3 이라 확정 문안이 아직 문서에 없다. **서버가 주는 것을 그대로 쓰고 문구를 프론트에 복사하지 않는다** — W3 에 바뀐다
- **`highlights` 는 아이 문장에 실제로 있는 조각만 담긴다** (백엔드 2번). 모델이 원형(「캄캄한」)을 주는데 아이는 활용형(「캄캄했지만」)으로 쓰기 때문이다. **부분 문자열 매칭이 서버 쪽에서 보장된다** — 하이라이트를 문장 위에 겹치는 것은 W3(A0-3)이지만 그때 이 전제를 쓴다
- **목 서버는 아직 `Authorization: Bearer` 를 본다** (`api/app/api/v1/deps.py` — 존재 여부만 확인). 계약은 이미 HttpOnly 쿠키인데 서버가 안 따라온 상태라, `src/lib/api.ts` 에 **개발 환경에서만** 붙는 임시 헤더(`mockAuthHeader`)를 뒀다. **`credentials: "include"` 는 항상 붙는다** — W3 E-3/E-4 에서 서버가 쿠키로 바뀌면 **그 함수만 지운다**
- **`next/image` 는 `images.unoptimized: true` 다** (`adr/0007` 결정 4, `next.config.ts`). 끄면 원격 호스트를 `remotePatterns` 에 등록할 필요가 없어 **R2 도메인이 정해지기 전에도 그림이 뜬다.** 지금 목 서버가 주는 `https://r2.example/...` 는 실제로 안 열리므로 **스케치는 못 불러오는 것이 정상**이고, 빈 액자로 떨어진다
- **`useEffect` 안에서 `setState` 를 동기로 부르면 lint 가 막는다** (`react-hooks/set-state-in-effect`, Next 16 기본 규칙). 효과 본문에서 로더 함수를 부르는 것도 걸린다 — **`.then()`·`.catch()` 콜백 안에서 상태를 바꾸면 통과**한다. 화면마다 걸릴 자리다
- **인증 타입이 옛 형태지만 이 화면은 무관하다** — 인증 엔드포인트를 안 쓴다. `types.gen.ts` 재생성은 W3 E-3/E-4 때다
- **클라이언트 PII 마스킹(E-2)은 W3 다.** 이번 화면은 입력을 그대로 보낸다. 목 서버라 괜찮지만 **실서버 붙기 전에 반드시 얹는다** — 잊으면 아이 실명이 그대로 나간다
- **한글 웹폰트가 아직 없다** (W1 메모). Geist 가 라틴만이라 한글은 OS 글꼴로 떨어진다. **이 화면이 한글 본문이 처음 많이 나오는 화면**이니 기기마다 인상이 갈리는 게 눈에 띄면 여기에 적는다 — C-2 확정 때 같이 본다
- 카드 상황문은 **대표 검수 반영본**이다(`cacda91`). 6장이 바뀌었으니 예전에 본 것과 다르다
