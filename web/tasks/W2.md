  - **인증 화면이 생겨야 할 수 있는 넷** — **3상태(확인 중/로그인됨/로그아웃됨)** · 로그아웃 **서버 호출** · **401 공통 처리** · `display-mode: standalone` 설치 안내. **지금은 인증 상태라는 개념이 프론트에 아예 없다** — W3 2번(학부모 동의)·3번을 칠 때 같이 선다
  - **3상태를 2상태로 만들지 않는다.** 첫 페인트에 로그인 화면이 깜빡인다 — 조사 노트가 짚은 그대로다
  - 남은 하나(**iPad 실기기로 쿠키 `Expires` 실측**)는 배포 뒤다. **30일이 실제로 30일인지의 유일한 확정 증거**다
- **서비스워커 배치 — 지금 그대로 두면 정적 빌드에서 깨진다** (`adr/0007` 결정 5, 프론트 몫)
  - 지금은 `src/lib/service-worker.js` 를 번들해 등록하고 **`scope: "/"` 가 Next 가 붙여주는 `Service-Worker-Allowed: /` 헤더에 기대고 있다**. 정적 빌드(`output: 'export'`)에는 그 헤더를 붙일 자리가 없다 — **Cloudflare Pages 에 올리는 순간 등록이 실패한다**
  - **`next.config.ts` 에 `output: "export"` 가 아직 없다.** 그래서 지금은 안 터지고, **배포를 켜는 날 터진다**
  - **`public/sw.js` 로 옮기는 쪽을 권한다** — 오리진 루트에서 서빙되면 헤더가 아예 필요 없다. `_headers` 는 Cloudflare 전용이라 호스트를 옮기면 **조용히 무효**가 된다. 파일은 이미 순수 JS 라 번들을 벗어나도 잃는 것이 없다
  - **W3 범위가 아니다.** 배포를 켜는 주차에 함께 정한다 — PM 에게 알렸다
- **`EVALUATOR_MODEL` 은 채워졌다** (2026-09-07 확인, `gemini-3.1-flash-lite`). 파일 값과 프로그램이 실제로 읽는 값이 일치하는 것까지 봤다고 한다. 비어 있으면 평가가 **폴백으로 전부 G1 이 되고 조용히 그렇게 돈다** — 결과가 계속 같으면 여기를 먼저 의심한다
- **Postgres·Redis 가 떠 있다** (`geulmoheom-postgres` 5433 · `geulmoheom-redis` 6381). 되묻기 횟수가 Redis 에 쌓이므로 **`X-Mock-Outcome` 없이 `네가 정해` 같은 입력으로 진짜 `scaffold` 를 볼 수 있다.** `docker` PATH 는 `~/.zshrc` 에 들어갔고 **새 터미널에서만 적용**된다
- **결과 연출 대사는 `api/app/api/v1/attempts.py` 의 `_결과대사` 에 잠정으로 있다.** 대사 세트(C-1)가 W3 이라 확정 문안이 아직 문서에 없다. **서버가 주는 것을 그대로 쓰고 문구를 프론트에 복사하지 않는다** — W3 에 바뀐다
- **`highlights` 는 아이 문장에 실제로 있는 조각만 담긴다** (백엔드 2번). 모델이 원형(「캄캄한」)을 주는데 아이는 활용형(「캄캄했지만」)으로 쓰기 때문이다. **부분 문자열 매칭이 서버 쪽에서 보장된다** — 하이라이트를 문장 위에 겹치는 것은 W3(A0-3)이지만 그때 이 전제를 쓴다
- **Playwright 를 넣었다** (`pnpm e2e`, 스펙 1개 · 화면 넷 × 태블릿 가로/모바일 세로). **범위는 여기까지다** — CI 연결·스위트 확대·시각 회귀는 안 한다 (PM 확정 2026-09-07)
- **E2E 는 서버를 안 탄다.** 브라우저에서 응답을 가로채 고정 JSON 을 돌려준다. ① 「못 닿음」 화면은 api 를 내려야 만들어지는데 그러면 테스트가 자기 전제를 부수고 ② 묘사 평가는 실제 유료 호출이라 매번 태우면 돈이 나가고 결과가 흔들리며 ③ 목 픽스처 문장이 정본으로 고쳐질 때 스펙이 같이 깨지면 안 된다. **고정 JSON 은 `types.gen.ts` 타입으로 못 박아** 계약이 갈라지면 `tsc` 가 깨진다
- **W3 에 할 것 둘 — 같이 지운다/붙인다.** ① `mockAuthHeader` 삭제(서버가 쿠키로 바뀔 때) ② **서버까지 붙는 진짜 E2E** 를 `ci.yml` 계약 검증 TODO 와 함께. 그때 `X-Mock-Outcome` 을 쓴다. **「지금은 서버를 안 탄다」가 조용히 잊히는 것이 위험이다**
- **E2E 에서 `NEXT_PUBLIC_API_BASE=/api/v1` 로 같은 오리진을 만든다.** cross-origin 이면 `Authorization` 헤더 때문에 브라우저가 **preflight(OPTIONS)** 를 먼저 보내는데 `page.route` 가 그건 못 가로챈다 — 가로채기가 걸리기도 전에 요청이 죽는다
- **헤더 값에 한글을 넣으면 `fetch` 가 요청을 보내지도 못하고 TypeError 를 던진다** (ISO-8859-1). 화면에는 「서버에 못 닿음」으로만 보여 원인이 안 보인다. **개발용 목 토큰이 `mock-token-개발용` 이라 실제로 이걸로 막혀 있었다** — E2E 를 붙이지 않았으면 사람이 브라우저를 열 때까지 몰랐다. 유닛 테스트로 회귀를 막아 뒀다
- **표정 4종을 2판으로 갈아끼웠다** (`bc12804`). 파일명·크기 그대로라 코드 변경 없음. `default` 는 나침반이 **조용한** 쪽이 채택됐다 — 후보 2 는 `default` 부터 빛나서 입력 중 나침반 빛과 뜻이 겹쳤다
- **입력창 테두리가 시안이 되는 것은 포커스 링이다** (`focus-visible:`). 글자 수에 반응하는 것이 아니다 — 반응하게 만들면 「보낼 수 있음」으로 읽혀 A0-2 MUST 를 우회하는 셈이 된다. **바꾸지 않는다**
- **`retry_of` 는 이번 주 항상 `null` 이다** (PM 확정 · `Stage0.md` 4절). 일일 카운트가 이 값에 걸려 있어 **되묻기를 거친 카드에 채우면 그 카드만 하루 5장에서 안 빠진다.** H2 도 같다 — 되묻기 전 짧은 입력을 별도 회차로 세면 **되묻기가 잘 될수록 회당 평균 글자 수가 내려간다.** 채우는 것은 결과를 받은 뒤 같은 카드를 다시 풀 때뿐이고 그건 **W4**
- **`result` 뒤에 「다음 장면」을 두지 않았다.** 막다른 화면인 것은 맞지만 그 버튼의 집은 **결과 연출(A0-3, W4)** 이고 지금 만들면 거기서 다시 만든다. **소진(409)을 실제로 확인하는 것도 지금은 안 된다** — `today` 가 목 고정값이고 소모 이력이 W4 다. 프리테스트도 W4 초로 옮겨져 이번 주에 그 막다름에 부딪히는 아이가 없다
- **되묻기·차단·전송 중 셋 다 쓴 문장을 지우지 않는다.** 같은 규칙이고 이유도 같다 — 사라지면 아이는 날아간 줄 안다. 차단은 더 세다: 「나쁜 말」 피드백을 안 주기로 한 마당에 **이유도 모른 채 공들여 쓴 글이 사라지면 그것 자체가 벌**이다
- **입력창을 오른쪽 절반에 가두지 않는다** (PM 확정). 태블릿 가로에서 칸이 좁아지면 줄이 짧아지고 **짧은 칸은 짧게 쓰게 만든다** — H2 합격선이 회당 150자다. 화면이 아이에게 「이만큼만 쓰면 돼」라고 말하는 셈이 된다
- **캐릭터를 원형으로 자르지 않고 둥근 액자에 담았다** (배경 회색 단색 그대로, 태블릿 176px). 알파본을 새로 뽑는 대신 이번 주는 이렇게 넘긴다 — **목적은 알파가 깨끗한 것이 아니라 아동이 고른 이유(고글·크로스백·스카프)가 화면에 보이는 것**이고, 원형만 벗기면 달성된다. 알파는 W3 이고 **`compass_bright` 는 빛이 배경으로 번져 있어 키 아웃으로는 안 되고 재생성이 필요할 수 있다**
- **「보내기」는 임시 문구다.** 용어사전에 없고 프론트가 지어낸 것이라 **W3 대사 세트(C-1)에서 PM 이 확정한다** — `_결과대사`·`CHILD_MESSAGE` 와 같은 처리다. 방향은 「아이는 탐험가이고 그 버튼은 자기 행동을 선언하는 자리」이며 메신저 말투와는 다르다
- **캐릭터가 원형으로 잘려 고글·크로스백·스카프가 안 보인다.** 아동 4명이 2판을 고른 이유가 정확히 그 셋이라, 화면에서 사라지면 **확인받은 것이 제품에 없는 셈**이다. **다섯 번째 조각(태블릿/모바일)에서 잡는다** — 태블릿 가로의 빈 오른쪽에 캐릭터를 크게 두면 두 문제가 한 번에 풀린다
- **E2E 첫 실행이 코드 수정 직후면 애매하게 실패한다.** Next 가 그 화면을 처음 컴파일하는 시간과 겹친다. `expect.timeout` 을 10초로 뒀다 — 다시 돌려서 통과하면 그건 컴파일 대기였지 회귀가 아니다
- **빛은 아무것도 잠그지 않는다. 이게 유지 조건이다** (PM 확정 2026-09-07). 나침반은 `aria-hidden` 이라 스크린리더에 안 읽힌다 — 읽어주려면 「거의 다 찼어요」가 필요하고 그건 숫자를 지운 자리에 **말로 진행바를 세우는 것**이다. 잠그지 않는 장식이라 안 읽혀도 기능이 빠지지 않는다.
  **그래서 조건이 붙는다 — 제출이 글자 수로 잠기면 그건 장식이 아니라 관문이고, 그때는 반드시 읽혀야 한다.** 빛이 「보낼 수 있음」을 뜻하게 되는 날에도 같다
- **30자는 「공백 포함 원문 길이」다.** 로그의 `char_len` 과 **같은 정의로 통일**한다 — 그 값이 H2 판정(2주차 평균 80자·150자)에 쓰이므로 **화면이 세는 것과 로그가 세는 것이 갈리면 가설 판정이 흔들린다.** 띄어쓰기로 채워도 서버는 묘사를 보고 되묻기를 낸다
- **첫 스크린샷에서 결함 둘이 나왔다.** ① **0자일 때 입력창이 안 보였다** — 배경색만으로 칸을 나타내서 밝은 배경에 묻혔다. 항상 보이는 테두리를 넣었다 ② 빛이 SVG 상자에 잘려 **원이 아니라 네모**로 보였다. 좌표계에 여백을 줬다. **둘 다 화면을 그려보지 않으면 안 보이는 것들이다**
- **나침반 빛을 표정 PNG 위에 좌표로 얹지 않았다.** 독립된 SVG 다 — 캐릭터 그림이 C-2 2판으로 바뀌면 그림 속 나침반이 몇 픽셀 움직이고, 좌표로 얹었으면 빛만 엉뚱한 데 남는다. 2판이 와도 **이 파일은 안 건드린다**
- **표정 4종이 2판으로 바뀐다** (아동 4명 확인이 12표 6:6 동률 — 장비 근거는 신규, 얼굴 근거는 기존이라 **장비는 두고 얼굴만 되돌린다**). **파일명·개수·크기가 같아 코드는 안 바뀐다** — `web/public/guide/` 를 갈아끼우고 여백·정렬만 다시 본다. `compass_bright` 의 빛이 세지지만 그건 제출 후 화면(W3)이다
- **표정 4종을 `web/public/guide/` 에 복사했다** (3.2MB). 파일명이 곧 `guide.expression` 값이라 프론트는 문자열을 경로에 끼우기만 한다. **정본은 `docs/캐릭터/표정/` 이고 C-2 로 그림이 바뀌면 다시 복사한다** — 두 벌이 되는 것이 이 방식의 대가다

- **목 서버는 아직 `Authorization: Bearer` 를 본다** (`api/app/api/v1/deps.py` — 존재 여부만 확인). 계약은 이미 HttpOnly 쿠키인데 서버가 안 따라온 상태라, `src/lib/api.ts` 에 **개발 환경에서만** 붙는 임시 헤더(`mockAuthHeader`)를 뒀다. **`credentials: "include"` 는 항상 붙는다** — W3 E-3/E-4 에서 서버가 쿠키로 바뀌면 **그 함수만 지운다**
- **`next/image` 는 `images.unoptimized: true` 다** (`adr/0007` 결정 4, `next.config.ts`). 끄면 원격 호스트를 `remotePatterns` 에 등록할 필요가 없어 **R2 도메인이 정해지기 전에도 그림이 뜬다.** 지금 목 서버가 주는 `https://r2.example/...` 는 실제로 안 열리므로 **스케치는 못 불러오는 것이 정상**이고, 빈 액자로 떨어진다
- **`useEffect` 안에서 `setState` 를 동기로 부르면 lint 가 막는다** (`react-hooks/set-state-in-effect`, Next 16 기본 규칙). 효과 본문에서 로더 함수를 부르는 것도 걸린다 — **`.then()`·`.catch()` 콜백 안에서 상태를 바꾸면 통과**한다. 화면마다 걸릴 자리다
- **인증 타입이 옛 형태지만 이 화면은 무관하다** — 인증 엔드포인트를 안 쓴다. `types.gen.ts` 재생성은 W3 E-3/E-4 때다
