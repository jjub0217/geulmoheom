### ⛔ 6번이 결함 하나를 잡았다 — **공용 브라우저에서 아이가 못 들어간다** (잠금 조건 ①)

**부모가 로그인한 채로 코드를 받아 아이에게 넘기는 것이 정상 흐름인데**(`adr/0014` 결정 3),
그 브라우저에는 **부모 쿠키가 살아 있어 `/child/me` 가 `403 FORBIDDEN_ROLE`** 로 답한다.
화면이 그걸 **거절 화면**으로 그려서 **「여기는 지금 들어갈 수 없어요」만 뜨고 코드 입력칸이
아예 안 나온다** — **아이가 들어갈 길이 없다.**

**실측으로 확정했다** — 부모 쿠키를 들고 `/child/me` 를 부르면 403, 쿠키 없이 부르면 401.

**고쳤다** — 이 화면에서는 **401 과 403 이 같은 것을 뜻한다**: 「이 브라우저는 아직 들어온
아이가 아니다」. **`역할이다르다` 구분 자체는 그대로 둔다**(`lib/api.ts`) — 이 한 화면에서만
같이 받는다. **부모 쿠키는 코드를 넣는 순간 서버가 지우므로**(결정 3) **덜 안전하지도 않다.**

**⭐ 이 부류는 가로채는 갈래가 원리적으로 못 잡는다.** 픽스처는 **한 쿠키만 있는 세상**을
그리는데, **실물은 둘이 같이 산다.** 서버까지 붙는 갈래를 세운 첫 실행에서 나왔다.

### ⚠ 단언이 재는 **시점**이 값이 정해지기 전 (2026-09-14)

**난 자리** — `pressable` 의 초점 표시 검사. **「색만 안 먹는다」로 보였는데 CSS 는 맞았다.**

`.pressable:focus-visible` 이 `outline-color: var(--color-brass)` 를 제대로 내고 있었고
`--color-brass` 도 `:root` 에 멀쩡히 있었다. **빌드 산출 CSS 를 뜯어보고서야 그걸 확인했다.**

**원인은 `transition-colors` 다.** 그 전이 목록에 **`outline-color` 가 들어 있어서**,
`Tab` 직후에 한 번 읽으면 **전이 시작값인 `currentColor`**(버튼 글자색)가 잡힌다.
**같은 파일의 `hover` 검사는 `expect.poll` 이라 통과했고**, 한 번 읽는 쪽만 빨간불이었다.

**축 ⑰ 여덟째와 한 줄기지만 축이 다르다** (PM 판정) — **⑰ 은 「어느 상태를 재나」이고
이건 「언제 재나」**다. **한 축의 두 축**이다.

**고친 것** — 폴링으로 바꿨다. **전이가 붙은 값은 한 번 읽지 않는다.**

### ⚠ 뒤집기에서 내 검사 넷이 안 물었다 (2026-09-14)

**같은 날 같은 부류를 넷 잡았다. 셋은 고쳤고 하나는 원리상 못 물어서 적어 뒀다.**

| 무엇 | 왜 안 물었나 | 어떻게 했나 |
|---|---|---|
| `pressable` 초점 색 | **재는 시점이 값이 정해지기 전** — `transition-colors` 가 `outline-color` 도 전이시킨다 | 폴링으로 |
| 로그인 오류 문구 | **픽스처 `message` 가 매핑 문구와 글자가 같았다** — `e.서버문구` 를 그대로 써도 통과 | 픽스처를 **아이 목소리**로 갈라 뒀다 |
| 로그인 성공 이동 | **주소만 봤다** — `/parents` 는 **404 인데 URL 단언은 통과**한다 | 도착 화면까지 본다 |
| 로그인 `credentials` | **같은 오리진이라 원리상 안 문다** — `fetch` 기본값이 `same-origin` 이다 | **못 문다고 적어 뒀다** |

**넷째가 특히 중요하다.** 계획이 **「`credentials` 가 빠지면 200 인데 로그인이 안 된 상태가 된다」**고
경고했고 **그 말은 맞다 — 다만 api 가 다른 오리진일 때다.** 운영은 **한 오리진 프록시**(`adr/0012`)라
**`credentials` 를 빼도 쿠키가 실린다.** 뒤집어 보고서야 알았다.
**검사는 남겼다** — `NEXT_PUBLIC_API_BASE_URL` 을 절대 주소로 되돌리는 날 **진짜 관문이 된다.**
