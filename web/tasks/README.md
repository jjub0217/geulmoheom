# web/tasks — 프론트 진척 체크리스트

주차별 파일 하나. 프론트가 **직접 만들고 직접 체크한다.** PM 승인 없이 쓴다.

```
cd web && claude
> /my-week W1
```

계획에서 자기 몫만 뽑아 체크리스트를 만든다. 이미 있으면 덮어쓰지 않고 차이만 알려준다.

## 여기는 계획이 아니다

**계획은 `docs/주차계획/`에 있다.** 이 폴더는 그 계획의 **진척만** 표시한다.

- 범위를 여기서 늘리거나 줄이지 않는다. 계획이 틀렸다면 PM에게 말하고 `docs/주차계획/`을 고친다
- 항목 번호는 주차 계획과 맞춘다. 갈라지면 주차 계획이 맞다
- 세부 순서·메모는 자유롭게 적는다. 그건 여기 것이다

## 왜 나눴나

`docs/주차계획/W1.md`를 두 개발자가 같이 체크하면 `main` 직접 push 체제에서 push 거부가 잦다.
각자 자기 패키지 파일을 쓰면 그 마찰이 없다. `api/tasks/`가 짝이다.

PM 작업은 `docs/주차계획/W1.md` 안에 그대로 있다 — PM이 그 파일 소유자라 겹치지 않는다.
